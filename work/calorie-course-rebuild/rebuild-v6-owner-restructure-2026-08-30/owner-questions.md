# Лог решений и вопросов владельцу

## Решено 30.08.2026

- Архитектура: четыре этапа по рабочему пути клиента.
- Первый этап: пять материалов в точной последовательности владельца.
- Полные текстовые оригиналы приоритетнее видео; видео используется только для женского примера энергобаланса.
- Вернуть Exercise Snacking, расчёт повторений, тренировочную компенсацию и исходные рабочие лимиты.
- Вернуть окно голода как эксперимент по поиску личной границы, блоки питания и правило 80% насыщения.
- Не возвращать физиологический экскурс об аутофагии, гормоне роста, инсулине и микробиоме.
- «Как назначить себе дефицит» сохраняется максимально близко к полному текстовому оригиналу.
- Внутреннее открытие этапов: 48 часов после последнего материала плюс выполненные задания.
- Самостоятельный доступ: 7 дней после Мастер-класса с предложением консультации; затем автоматическое открытие.
- Максимальный тариф с консультацией: ручное открытие Сергеем после обращения.

## Discoverable, закрыто без вопроса

- Нужное приложение рецептов уже реализовано в проекте и полностью соответствует описанию владельца.
- Разделение повторного использования приложения: обучение и накопление каталога в этапе 1; применение каталога для выхода из учёта в этапе 4.
