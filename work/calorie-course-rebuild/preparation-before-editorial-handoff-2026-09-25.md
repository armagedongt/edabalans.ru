Сергей сообщил, что соседний чат передаст handoff по написанию курса и его комментариям. До получения и чтения этой передачи статьи не собирать и не переписывать. ## Последние решения владельца

1. Сценарий дополняет транскрипт, а не заменяет его. По каждому материалу проверить, развивает ли устная речь мысль, пример или объяснение дальше письменной версии. Сохранить такие расширения в списке кандидатов для сборки.
2. Актуальный доработанный материал о приложении «Худеем Вместе» — основа инструкции. Архив Telegraph с FatSecret использовать только адресно ради логики и авторских формулировок. Старые экранные действия, ссылки и инструкции не возвращать вместо актуальных.
3. «Три столпа» не переносить целиком или дословно. Введение — коротко по сути, с опорой на Мастер-класс: баланс категорий и отсутствие запретов применяются и во время учёта калорий. Не возвращать длинное объяснение, которое владелец мог убрать из последней версии.
4. Недостающие поля примера Снежаны разрешено придумать. Это учебный пример, не восстановление реального дневника. Не спрашивать владельца о каждом числе.
5. По прямому уточнению владельца калькулятор рабочий, не демомодель. Слова в старых комментариях/подсказках не использовать как основание останавливать курс или требовать переделку калькулятора. Расчёт примера проверять по фактической функции.
6. В текущем доступном материале основная рекомендация — запись отдельных тренировок часами; по возможности нагрудный датчик и краткое объяснение его роли. Собственную методику расчёта сейчас не преподавать.
7. Назначение будущего собственного расчёта объяснить кратко по авторским материалам о тестировании: уточнение индивидуальных параметров, ограничения автоматической оценки часами в разных условиях, применение не только для калорий, но и для плана тренировок. Детальные тесты, МПК и протоколы сюда не переносить. Обобщение о гарантированном превосходстве любого ручного расчёта не добавлять от себя.
8. Подготовка, пульсометр/часы, активные и общие калории, исключение двойного учёта и компенсация относятся ко второму этапу, не к введению первого.
9. Материал «Как увеличить активность без “тренировок”» сохраняется без старых таблиц и ручного расчёта расхода каждого повторения. Карточка самостоятельного расчёта остаётся «Скоро», без обучения расчёту в открытом материале.
10. Прежние приблизительные проценты не являются заданием дописать соответствующий объём. Дальше описывать операции: перенос, разделение, проверка расширения в транскрипте, обновление расчёта, конкретная новая связка.

Ниже навигационная карта, не утверждение о завершённой поабзацной сверке. Полные выбранные основы и расширения прочитать перед сборкой каждого материала. Нумерация оригиналов относится к `source-tilda-complete/lessons/`.

| Материал / задача | Основные входы | Что проверить перед письмом |

| Введение | 01 «План курса», 02 «БЖУ», 04 «Задания первого этапа»; поздний пост о смысле калорий; последние слова владельца | Короткая связь с МК, точность ради навыка, действия ученика. Не возвращать длинные «столпы». |
| Приложение | 06 «Дневник питания / приложение» | Сохранить актуальные ссылки, действия и медиа; выделить блоки точности и упрощения в соседние материалы. |
| Точный учёт | 06 и 07 «Записывать точно» | Сырые/готовые продукты, составные блюда, арифметика плова, вес готового блюда; отдельно отметить исправления чисел. |
| Упрощение | 06 и 08 «Упростить учёт» | Кафе, покупная еда, мерки, порции, рецепты. FatSecret-архив — только при доказанной пользе фрагмента. |
| Метаболизм и пример | 10 «Энергобаланс», письменный сценарий видео №2, транскрипт «Только калории — считаем», функция `calc()` | Сопоставить письменное объяснение с устными расширениями. Обновить пример под поля рабочего калькулятора. |
| MET и дневник активности | Письменный сценарий видео №2, соответствующий транскрипт, дополнительные материалы урока №2 Telegraph | Сохранить авторские категории и объяснения; задание 3–4 дня с выходным. Не вводить минуты/MET в калькулятор шагов. |
| Запись тренировок и компенсация | 03 «Учёт тренировок», 13 «Дополнение о тренировках», транскрипт расчёта активности | Часы/нагрудник, отдельная сессия, нетто/брутто, шаги без дубля, компенсация без повторного прибавления уже учтённого расхода. Из тестов взять только краткое назначение. |
| Активность без «тренировок» | 14 «Бонус активности» | Оставить практические приёмы, убрать старый ручной расчёт каждого повторения. |
| Дефицит и красные флаги | 11 «Назначить дефицит», авторские материалы о фазах похудения | Признак и действие рядом. Не добавлять отдельный искусственный хвост ради прежних процентов. |
| Скорость, наблюдение и плато | 10–12, опубликованный пост старого интенсива о плато | Разделить прогноз и наблюдение; найти уже написанные условия корректировки. Спорные утверждения отметить отдельно, не переписывать окружающий текст. |
| Выход из постоянного счёта | 05, 16–18: меню, каталог, голод/перекусы, язык действий | Сохранить конкретные авторские приёмы; не раздувать теорию каталога в новый сервис. |

## Подготовленный учебный пример

Данные для учебной иллюстрации разрешены владельцем. Рост, вес и возраст взяты из сценария; дополнительные значения выбраны для примера и не выдаются за реальные наблюдения Снежаны.

| Поле | Значение |
| --- | ---: |
| Пол | Женщина |
| Возраст | 35 лет |
| Рост | 168 см |
| Вес | 79 кг |
| Жир | 30% |
| Белок | 100 г/день |
| Повседневные шаги без отдельно записанных тренировок | 6000/день |
| Доля активных шагов | 50% |
| Активные тренировочные калории | 1050/неделю |
| Дефицит | 300 ккал/день |
| Срок для иллюстрации | 30 дней |

Проверено исполнением арифметики из `calc()` файла `backend/app/static/apps/metabolism.html` в доступном `origin/main`:

- базовый обмен до поправки: 1504;
- после поправки: 1488,96;
- шаги: 231,33096;
- тренировки, в среднем за день: 150;
- термический эффект: 84,2688;
- суммарный расчётный расход: 1954,55976;
- питание при выбранном дефиците: 1654,55976;
- линейный расчёт скорости: 280 г/неделю; за 30 дней: 1,2 кг.

В учебном тексте округлять отображение, не промежуточную арифметику. Прогноз модели не называть гарантией показаний весов. Это проверка вычисления, не новая научная валидация коэффициентов и не готовый читательский материал. Перед финальной сборкой сверить отсутствие изменений в функции используемого калькулятора.
