# Полная локальная копия Калорийного курса из Tilda

Статус: `источник до редактуры`  
Дата фиксации: 2026-08-28  
Tilda: курс `425521` — «Калорийный» курс.

## Что здесь сохранено

- 18 опубликованных текстовых лекций в `lessons/`;
- 3 опубликованные видеолекции в `videos/`;
- исходный порядок блоков каждой статьи;
- заголовки исходного уровня, списки, жирное/курсивное начертание, ссылки, цитаты и плашки;
- 58 изображений, скачанных с Tilda CDN и подключённых к исходным местам относительными ссылками;
- машинная копия блочной топологии и исходного HTML каждого смыслового блока в `raw-blocks.json`;
- исходные HTML-поля над и под видео, Tilda ID, Boomstream ID, длительность и карточка каждого видео в `raw-video.json`.

## Структура одной текстовой лекции

```text
lessons/<номер>-<slug>--<tilda-id>/
├── source.md             — читаемая Markdown-копия в исходном порядке
├── raw-blocks.json       — ID, тип, исходный HTML и порядок каждого блока Tilda
├── assets-manifest.json  — соответствие CDN-адреса локальному файлу
└── assets/               — локальные изображения, если они есть
```

`source.md` не является новой редакцией урока. В нём не исправлены опечатки, старые цифры, ссылки, интерфейсы и методические утверждения. Это слепок источника, который разрешено анализировать только после успешной проверки сохранности.

## Видеолекции

Старые видео не назначены форматом новой версии Калорийного. Здесь сохранены карточки и связанные тексты, чтобы видео оставались источником фактуры и могли быть сопоставлены с транскриптами. Весь смысл возможного будущего видео сначала должен существовать как полноценный текст.

## Жёсткая граница

Нельзя писать новые уроки по старой папке `source-tilda/`, аналитическим картам или транскриптам вместо этой копии. Порядок работы:

```text
полная копия Tilda
→ проверка сохранности
→ анализ актуальности и методики
→ решение «оставить / углубить / объединить / убрать / написать заново»
→ новая программа
→ тексты будущего курса
```

Результат проверки находится в `verification.md` и `verification.json`.
