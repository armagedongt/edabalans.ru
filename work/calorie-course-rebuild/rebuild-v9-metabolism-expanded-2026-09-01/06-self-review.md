# Второй прогон v9: не написана ли хуйня

Статус: `completed internal review`

## Что было проверено

- У каждого материала есть собственное действие ученика.
- Подзаголовок существует ради решения, примера или ошибки, а не ради ровного оглавления.
- Авторские оригиналы v0 не заменены общей нейросетевой теорией.
- Границы с Мастер-классом и Тренировочным курсом не превращают Калорийный курс в рекламную прокладку.
- Исследование не породило отдельные уроки только потому, что нашлись интересные факты.

## Почему осталось 12 материалов

| Материал | Уникальный результат | Если удалить |
| --- | --- | --- |
| 1.1 Приложение | Человек умеет получить отчёт | Нельзя выполнить весь курс. |
| 1.2 Точный подсчёт | Убраны систематические ошибки дома | Исходная неделя недостоверна. |
| 1.3 Приближённый подсчёт | Неизвестная еда не исчезает из отчёта | Курс работает только в лабораторной кухне. |
| 2.1 Расход | Понятна модель и её ограничения | Калькулятор становится магическим числом. |
| 2.2 Калькулятор | Есть два сохранённых личных сценария | Теория не превращается в данные человека. |
| 2.3 Движение | Активность учтена без двойного счёта | Курс игнорирует крупный рычаг расхода. |
| 3.1 Исходная неделя | Формула сверена с жизнью | Главный пробел v8 остаётся. |
| 3.2 Дефицит | Назначено одно проверяемое изменение | Измерение не приводит к решению. |
| 3.3 Плато | Есть порядок диагностики и коррекции | Любой шум провоцирует случайную резку еды. |
| 4.1 Окна и блоки | Калорийность воспроизводится ритмом | Выход из счёта остаётся абстрактным. |
| 4.2 Каталог действий | Есть личные готовые решения | Человек снова решает всё с нуля. |
| 4.3 Отключение | Есть правила выхода и возврата | Курс заканчивается призывом «считайте меньше». |

Количество получилось `3 + 3 + 3 + 3`, но ни один материал не добавлен ради этой симметрии. Отдельный третий материал этапа 4 оправдан самостоятельным решением: когда прекращать и когда возобновлять измерение. В v8 это решение было спрятано внутри каталога.

## Что схлопнуто после проверки

- Исследования точности — во вступительное видео, не отдельная лекция.
- Средняя калорийность — объяснение в метаболизме и применение в отчёте, не отдельная тема.
- Скорость похудения — часть назначения дефицита.
- Фазы и периодизация — часть назначения и пересмотра режима.
- Exercise Snacking — блок внутри активности.
- Вода, цикл и шум веса — часть чтения тренда и диагностики плато.
- Рецепты — технический мост к существующему продукту, не новый кулинарный раздел.
- БЖУ, качество и насыщение — только необходимые напоминания со ссылкой на Мастер-класс.

## Что исправлено по сравнению с v8

- Этап 2 больше не состоит из двух коротких инструкций. Теория метаболизма, практика калькулятора и активность разведены по разным действиям.
- Введена обязательная калибровка расхода по исходной неделе и тренду массы.
- Плато перенесено из общей теории в этап, где уже есть собственные данные.
- Пример 50 ккал защищён от ложного линейного прогноза.
- Формулировка о силовых уточнена: не основной инструмент непосредственного расхода, но отдельная ценность остаётся.
- Зафиксировано, что калькулятор нужно переделать до производства урока.

## Оставшиеся риски

1. Числовые правила дефицита пока не фактчекнуты. Это сознательный блокер готового текста, но не структуры.
2. Короткая исходная неделя не всегда позволяет надёжно вычислить расход по тренду массы. В тексте потребуется честный диапазон и возможность продлить наблюдение.
3. Два перехода в Тренировочный курс могут стать повторной рекламой. Они должны отвечать на разные вопросы и появляться только после полезного блока.
4. Материал 2.1 легко раздуть физиологией. Ограничитель: объяснять компонент только до решения, которое принимает ученик.
5. Материал 4.1 может повторить Мастер-класс. Ограничитель: оставить только применение окон и блоков к уже измеренной калорийности.

## Вердикт

Структура не пустая и не требует новых материалов до просмотра Сергеем. Следующий полезный шаг после его замечаний — не расширять оглавление, а:

1. утвердить или поправить 12 материалов;
2. переделать калькулятор;
3. во втором авторском прогоне подбирать полные исходные блоки и писать тексты;
4. после каждого текста повторять проверку «какое решение теперь может принять человек».
