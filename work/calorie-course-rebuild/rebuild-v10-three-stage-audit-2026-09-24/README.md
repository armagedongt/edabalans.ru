## Почему здесь три модуля

Три модуля лучше четырёх. Расчёт расхода и его проверка по фактической жизни —
не две самостоятельные учебные темы, а один цикл:

```text
формула → фактическая неделя → дефицит → проверка → коррекция
```

Разрывать этот цикл отдельной границей модуля неудобно: человек получает число,
но ещё не знает, можно ли ему верить. Поэтому бывшие этапы «расход» и
«калибровка» объединены. Это не трёхдневный курс: модуль 2 намеренно большой.

## Что делать дальше

1. Не полировать восемь красных файлов. Сначала заново собрать их из дословных
   авторских блоков v0 и транскриптов; новые связки оставить только там, где в
   источниках действительно есть пробел.
2. После этого повторить процентную и нейрослоп-проверку. Для базового материала
   целевой признак — не абстрактная «похожесть на голос», а видимое происхождение
   каждого крупного блока.
3. Перед финализацией материалов модуля 2 переделать калькулятор: отделить
   стартовую формулу от проверки по фактическому потреблению и тренду массы.
4. Только после авторского просмотра синхронизировать трёхмодульную программу с
   runtime, привязать статьи к стабильным ID и включать публикационный контур.
