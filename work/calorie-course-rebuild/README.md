## Текущий порядок

Каждый активный материал перенесён из Tilda целиком: текст, ссылки, изображения,
порядок и типы блоков. Проверка 18/18 пройдена без ошибок. После source-based
ревизии отдельно исследованы фактический порядок, задания и педагогическая логика
Мастер-класса. На этом основании программа v4 предлагает первую гипотезу из пяти
этапов без календарных дней и недель. Количество этапов и шагов будет меняться по
мере полной раскладки источников; ориентир 2–5 шагов на этап не является
ограничением. Версии v2 и v3 сохранены как
история работы и не являются действующей программой.

Калорийный сейчас является следующим продуктом внутри прохождения Мастер-класса. Финальная периодизация остаётся В Мастер-классе, а Калорийный получает более глубокий слой БЖУ. Первая версия курса строится как текстовая; старые видео остаются источниками фактуры и возможными будущими слотами.
