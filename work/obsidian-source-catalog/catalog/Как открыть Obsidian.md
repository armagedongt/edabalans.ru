# Как открыть в Obsidian — пошагово

## Проект, модули, стили и интенсив

1. Запустите Obsidian. Нажмите название хранилища/переключатель внизу слева.
2. Выберите «Управление хранилищами / Manage vaults». Другой путь: Ctrl+P →
   «Открыть другое хранилище / Open another vault».
3. У «Открыть папку как хранилище / Open folder as vault» нажмите «Открыть».
4. Вставьте в адресную строку окна выбора папки:
   C:\Users\Segey\Documents\ChatGPT\edabalans.ru
   Нажмите Enter → «Выбрать папку / Открыть».
5. После открытия нажмите Ctrl+O → введите «Старт».
6. Выберите work/obsidian-source-catalog/catalog/Старт.md.
7. Перейдите по ссылке к нужному разделу.

Это открытие настоящей папки, не копирование в D:\Обсидиан. Индексация может быть
большой: root содержит рабочие копии. Пока не перетаскивать и не переименовывать.
Настройки .obsidian создаются программой при открытии. Сторонние plugins для
навигации не требуются; не включайте незнакомые плагины.

не долгосрочная целевая схема. В будущей миграции убираем вложенность.

## Чего не делать

Не создавать новое пустое vault с копией проекта. Не переносить старые заметки.
Не переименовывать worktree/source-папки. Пока допускаются отдельные vault;
единое физическое размещение — следующий этап.

[Официальная инструкция Obsidian](https://obsidian.md/help/manage-vaults).
UI вашей программы в этой сессии не просматривался; названия могут различаться
по языку/версии, поэтому даны английские варианты. Регистрация vault не выполнена.
