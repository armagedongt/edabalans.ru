# Channel-first: выпуск согласованной воронки

## Основание

Сергей последовательно подтвердил маршрут и выпуск, последний раз командой
«делай»19.10.2026. Точные решения и ответы — decisions.md. Исследование существующих
контуров — code-research.md. Этот документ не разрешает массовую рассылку или migration.

## Результат и границы

Два понятных предложения: бесплатная статья вместе с каналом и платный мастер-класс.
Сайт: общий редактируемый блок внутри статьи, popup и на главной; конечная CTA статьи
продаёт мастер-класс. Бот: навигация → существующий старый video_note → текст статьи.
Нынешнее обычное видео сохраняется для другого случая. Новую14-дневную рассылку
не писать и не запускать. Канальные закрепы Сергей меняет позже вручную, их тексты
не являются блокировкой технической реализации.

## Проверяемые критерии

- [x] Один версионный документ владеет двумя текстами и двумя URL общего блока.
- [x] Счётчика подписчиков и его настроек нет; внешний вид карточки сохранён.
- [x] Главная использует общий блок вместо своего прежнего поля без потери правок главной.
- [x] Покупатели исключены; >75%+подписка скрывает, >75% без подписки даёт короткий текст.
- [x] from=tg|max сохраняет согласованную отдельную политику источника, не создаёт identity.
- [x] Статьи завершаются CTA МК с названием активного каталога, авторский текст сохранён.
- [x] Найденный tpl_entry_circle возвращён; обычное видео не конвертируется и не теряется.
- [x] Новый конструктор в общей админке, старый сохранён доступным архивом.
- [x] Площадка, название/пост и цель хранятся за одним стабильным коротким кодом.
- [x] По умолчанию запрос write access, переключатель выключает его; оба ответа ведут в канал.
- [x] События входа, наблюдения разрешения и перехода связаны с проверенным Telegram identity.
- [x] Отчёт по датам/площадкам/ссылкам учитывает Mini App посетителей без Start.
- [x] Доставки, членство и чтение остаются фактическими событиями, неизвестность видна явно.
- [x] После готовности нашей части Direct/VSL получают handoff для разметки обновлённой статьи.

## Реализация

Использовать существующие managed_documents, tracking links/events, CRM user_id,
редакционный vault, движок отправки и административный каталог. Не создавать второй
кабинет, Telegram-движок, библиотеку или редактор. Существующие рекламные landing
сохраняют browser/yclid через tracking session; новая промежуточная страница не нужна.
MAX разрешение писать не имитировать; неизвестное членство не считать отказом.

## Проверка

Backend: матрица узнавания/покупки/чтения/from, безопасный редактор/конкурентные версии,
совместимость активной главной, общий текст/URL. Node: реальный script контекста,
clone/popup/homepage и ошибки. Вёрстка: изменённый блок360/430/768/1440 и границы900.
Конструктор: auth, входные данные/код/цель, неизменность старых ссылок, факт подписи
Telegram, dedup событий и отчёт без выдуманной атрибуции. Бот: три отправки, повтор,
дубликат webhook, stop/покупка, сбой между отправками, сохранение старого видео.

## Отложено

Новая14-дневная редакционная рассылка и её расписание; новые тарифы; автоматическое
число подписчиков. Новые тексты канала — ручная работа Сергея.
