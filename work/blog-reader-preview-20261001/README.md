# Локальный образец читательских вставок

Модуль: `platform.blog`. Дата: 01.10.2026. Статус: локальный прототип,
не выпуск в production. Источник — существующая статья Японии `11927800`.
Авторский Markdown, каталог публикаций и действующая оболочка не изменены.

## Открыть

Из корня рабочей копии: `python work/blog-reader-preview-20261001/serve.py`.
Адрес: http://127.0.0.1:8771/articles/pochemu-yapontsy-hudye-a-ty-net
Сервер слушает только loopback; страницы имеют noindex/nofollow и no-store.
Никаких записей в БД, публикационного API или реальной авторизации.

## Что показано

- Две карточки: привычки после окружения, растения после разнообразия.
- Существующий подписной текст и фото автора; popup и вставка скрыты у гостей
  и подписчиков. Переключатель наверху — только демонстрация трёх состояний.
- Автоматический popup после 50% авторского материала, раз за 24 часа.
  Ручная тестовая кнопка обходит интервал, но не проверку демонстрационного состояния.
- Конечная плашка интенсива. Только в примере: действующее назначение статьи
  на Мастер-класс и нативный текст автора не менялись.
- Правое оглавление при ширине >1360; нижнее меню телефона при ширине <=900.
  На промежуточной ширине работает прежнее содержание. Старое не удалено.
- Нижняя панель содержит ссылки текущей навигации и контакты, затем оглавление.

## Проверки и ограничения

`node --test work/blog-reader-preview-20261001/gate.test.cjs` — четыре проверки:
правило показа, timestamp, интервал 24 часа, прогресс без вставок.
Проверены браузером ширины 360, 430, 768, 900, 901, 1360, 1361, 1440 при высоте 900:
нет горизонтального переполнения; проверены меню, контакты, Escape и возврат фокуса.
Снимки вне Git: `D:\CodexPrivate\blog-reader-evidence-20261001`.

Не подключены реальные identity/channel membership и события Метрики.
Редкий сбой записи localStorage при успешном чтении не гарантирует сохранение
интервала после перезагрузки. Это известное ограничение прототипа, не готовый
production-механизм. Перед выпуском нужно выбрать надёжное хранение частоты;
не добавляем новый пользовательский вход ради демонстрации.
