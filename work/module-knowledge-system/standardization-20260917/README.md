Статус: `draft`
Назначение: фактический checkpoint текущей работы, не новый канон и не backlog.

## Что изменено

- Единый вход модуля остаётся его существующей карточкой: сценарий → источник
  факта → инструкции/skills/инструменты → проверка/выпуск. Подробные инструкции
  не дублируются внутри большого агентского файла.
- Разведены стратегия предложения, текст Писаря, редакционный каталог продукта,
  цена/оплата/право, подбор допродаж МК и юридический маршрут.
- DQS, силовые тренировки и метаболизм остаются независимыми владельцами своих
  формул, состояния и функций при общей сессии/API.
- Общий стандарт и AGENTS требуют обновить изменившийся канон до завершения.
- В CHAT_WORKSTREAMS записаны защищённые задачи и требование отдельной команды
  владельца перед удалением веток/worktree или архивированием.

Каноны находятся в `docs/knowledge-base/MODULE_DEVELOPMENT_STANDARD.md`,
`docs/CHAT_WORKSTREAMS.md` и затронутых карточках; этот checkpoint их не заменяет.
Код приложений, юридические тексты и платёжные настройки этим проходом не менялись.

## Что проверено по рабочим деревьям

Снимок [worktrees.json](worktrees.json) содержит 84 зарегистрированные копии:
HEAD, уникальные коммиты относительно принятого main, число локальных изменений
и ignored-файлов. Это состояние на момент проверки, не постоянные статусы.
Каталогизация не включала приватное хранилище владельца или содержимое медицинских
данных. Корневые большие числа включают вложенные рабочие копии и не равны
числу уникальных несохранённых материалов.

Из 28 копий без уникальных коммитов и рабочих изменений нельзя автоматически
удалять все: есть защищённое использование, неизвестные ignored-файлы и ошибки
доступа. На основании прежней команды был начат проход удаления десяти проверенных
копий. После нового запрета владельца команда прервана; шесть уже удалённых копий
восстановлены с прежними ветками, путями и HEAD. Все десять целей теперь на месте
и проверены без tracked/untracked изменений. Python/pytest-кэши удалявшихся шести
копий не восстанавливались. Задачи не архивировались и не удалялись.

  marketing-attribution/max-one-shot-chain с уникальными остатками.

Эти сообщения подтверждают только владение, не полную память задач и не отсутствие
чужого использования. Не выдавать их за полный аудит проекта.
