# Редакторский handoff: пакет из восьми статей

Статус пакета: Markdown собран, медиа локализованы, машинные validation/review — `pass`. Публикация в блог не выполнялась. Научная фактура не переписывалась без решения владельца; открытые вопросы перечислены в `factcheck-notes.md`.

## Общие правила переноса

- Режим: `full_source`, бережная структурная адаптация.
- H1 хранится только в metadata; в теле используются H2, абзацы и списки.
- В тело не добавлены CTA, HTML, JavaScript и компонентные директивы.
- Обложка хранится в `hero` и не повторяется первой картинкой в теле.
- Все доступные изображения скачаны из выбранной версии источника, уменьшены до ширины не более 1600 px и сохранены в WebP quality 82.
- Исходные URL каждого изображения и его локальный путь записаны в `manifest.json`.
- Suggested CTA и три related-кандидата находятся только в metadata/manifest, не в авторском тексте.
