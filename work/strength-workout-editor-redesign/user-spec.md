# Мобильный редактор силовых тренировок

## Модель

- У аккаунта один каталог упражнений, общий для всех тренировочных шаблонов.
- Новый и существующий аккаунт получает 25 базовых упражнений. Окончательные
  русские названия и медиа утверждает владелец до публикации справочника.
- Пользователь может добавлять собственные упражнения. Собственное упражнение
  можно переименовать или убрать из каталога; уже записанная история не удаляется.
- «Шаблон 1/2/3» хранит только выбранный состав и порядок. История принадлежит
  упражнению и объединяет выполнения из всех шаблонов.
- Конкретная тренировка остаётся сессией выбранного шаблона с номером и датой.
  Пустое упражнение и пустой подход не образуют историческую точку.

## Редактор шаблона

Одна кнопка «Редактировать шаблон» заменяет дублирующие «Упражнение» и
«Порядок». Она открывает общий каталог аккаунта:

- у упражнения вне шаблона есть действие «Добавить»;
- у упражнения в шаблоне — «Убрать» и стрелки вверх/вниз;
- базовое упражнение нельзя удалить из каталога;
- у собственного упражнения дополнительно есть «Изменить» и «Удалить»;
- внизу можно ввести название и добавить своё упражнение;
- изменения остаются черновиком до «Готово»; «Отмена» и нажатие вокруг окна
  закрывают его без сохранения;
- прокручивается содержимое окна, а страница под ним заблокирована.

Упражнение также можно убрать из текущего шаблона крестиком в карточке после
подтверждения. История при этом сохраняется.

## План и выполнение

- В режиме «Редактировать план» показываются прошлые выполнения, редактируемый
  план, факт и комментарий. Выбранный прошлый факт переносится в план только по
  отдельной кнопке.
- В режиме выполнения прошлое скрывается, план становится нередактируемым, а
  факт остаётся доступным.
- Галочка подхода работает только при заполненном плане, копирует отсутствующие
  значения плана в факт и может быть снята без стирания факта.
- По умолчанию четыре подхода; общие кнопки добавляют либо удаляют последнюю
  строку.
- Поле комментария растёт по содержимому и показывает весь текст.

## Справка

- В шапке приложения постоянно доступна ссылка «Как пользоваться» с кратким
  пошаговым туториалом.
- Рядом с названием базового упражнения находится иконка `i`. Она открывает
  задействованные мышцы, 2–3 базовые подсказки и демонстрацию движения.
- До production-публикации демонстраций владелец утверждает список 25 упражнений,
  а для каждого медиа фиксируются источник, автор и разрешённая лицензия. Чужие
  изображения или GIF из коммерческих приложений не копируются.

## Мобильная компоновка

- Названия упражнений и основные управляющие подписи крупнее, чем в прежней
  версии; числовые поля не увеличиваются за счёт рабочей ширины.
- На ширинах 360 и 430 px нет горизонтального переполнения.
- Липкое переключение «Редактировать план / Начать тренировку» сохраняется;
  текущая механика завершения тренировки в этом пакете не меняется.

## Проверка

- API возвращает один и тот же набор каталога для всех трёх шаблонов, но разный
  флаг включения и порядок.
- Новый аккаунт получает ровно 25 базовых упражнений без миграции схемы БД.
- Добавление, переименование и удаление собственного упражнения доступны и
  пользователю, и администратору.
- После перезагрузки состав шаблона и общий каталог сохраняются.
- Модальное окно проверяется на реальном мобильном viewport: прокрутка внутри,
  фон неподвижен, выход по пустому месту работает.
