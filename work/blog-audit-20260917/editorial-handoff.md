## Концовки: применено / записано / отложено

Применено: убран старый бот-тест; сохранены баннеры; текущая плашка не
перерисована. Записано: правило одобренного компонента и ручного подбора
related в `BLOG_EDITORIAL_WORKFLOW.md`, feedback в private correction memory
`correction:e6e4c87f865cbd89`.

Отложено для выбора владельца:

- «Японцы»: новогодний постер рядом с «Актуально 365 дней в году» и внешнее
  Dropbox видео — кандидат на несезонную замену/снятие. Историческое медиа
  самостоятельно не удалено.
- «15 советов»: авторский «Совет №16» — нативный продуктовый мост, а не случайный
  площадочный хвост; вместе с конечной плашкой может повторять продажу. Сокращать
  только конкретно согласованный блок, не переписывать весь материал.
- «Вода» и «Брайан Джонсон»: сейчас manifest выбирает Telegram-плашку, а не один
  из двух основных продуктовых вариантов. Рекомендация — при следующей
  редактуре выбрать интенсив для воды, Мастер-класс или интенсив для Брайана;
  эти назначения в этом узком медиа-проходе не менялись.
- «Мёд»: скриншоты обсуждения — фактура самого аргумента, не просьба читателю
  перейти в комментарии. Не стирать их только из-за прежней площадки.
- «30 растений» и «Весы»: содержательные переходы к Мастер-классу уместны;
  согласованная психологическая часть «Весов» защищена дословно.
- «Сроки»: финальный вывод работает без старого бот-теста; расчётная таблица
  остаётся иллюстрацией исходного аргумента, не персональным прогнозом.

Медицинские утверждения этим проходом не обновлялись. Старые численные/научные
риски остаются в fact-check handoff предыдущих публикаций: универсальность
оценок срока/веса, наблюдательные данные о микробиоме, устаревшие параметры
Blueprint и оговорки о РПП. Их нельзя считать закрытыми от сжатия изображений.

## Что действительно сделано для SEO

У всех девяти статей: отдельные title и description из manifest, self-canonical,
Open Graph article/hero, JSON-LD Article с автором Сергеем, один H1 и структурные
H2/H3, стабильные slug, sitemap и открытый robots.txt. Картинки локальные,
alt сохранены; hero eager/fetchpriority high, остальные lazy/async. Новые
версии медиа уменьшают объём загрузки; шрифты локальные. HTML использует
единую безопасную сборку Markdown.

Не добавлены datePublished/dateModified без надёжной даты блоговой публикации;
Search Console и позиции не проверялись, обещания роста трафика отсутствуют.
Canonical чужих страниц Pikabu/Telegraph этим выпуском не изменён. Наличие
схожих внешних версий требует выбора первичной блоговой редакции, а не
обещания, что технический canonical на нашем сайте устраняет все внешние дубли.

## Related и подвал

Related — три вручную назначенных published source_id, не рекомендации по
просмотрам. Правило: продолжение вопроса → практический следующий шаг →
смежный полезный ракурс; без себя, дублей и неопубликованных статей.
Текущие девять наборов перечислены в `active-media-audit.json`, назначения
не менялись. При маленьком корпусе ближайшие полезные темы неизбежно повторяются.

Подвал не отдельный блоговый: подключён общий публичный `site-footer.js`.
Тёмное оформление принадлежит общей оболочке и сохранено; блоговая цветовая
схема не является разрешением создать другую юридическую/контактную копию.
