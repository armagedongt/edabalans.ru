# Продолжение Писаря: площадочная адаптация

Статус: `draft`
Модуль: `platform.content`
Дата: 17.09.2026
Назначение: checkpoint реализации, не второй нормативный документ.

## Поручение и граница

Продолжить существующие разборы Писаря, сделать условную адаптацию для каналов,
бота, сайта, уроков и рекламы внутри общего писательского контура.
Голос, права редактуры и канон оформления не переписываются.
Изменяются только инструкции, schema и routing/ownership модуля.
Никакой записи пользовательских данных, миграции, публикации курса, отправки
сообщений или изменения действующей рекламы нет. Откат — обратный Git-коммит
своего изолированного diff и установка соответствующей версии навыка.

## Продолженные источники

- Предыдущие восемь проходов связаны в `content/author-voice/README.md`;
  не создаём второй аудит вместо их решений.
- `writer-contract-v1.md`, разделы 7–9: голос, площадки, продажи и ограничения.
- `editorial-linking-v1.md`: CTA, прямой вход в интенсив, бот, перелинковка.
- Telegram `MESSAGE_CONTENT_AUTHORING.md` и `LINKS_AND_ATTRIBUTION.md`, §0.1:
  контентный слот отдельно от сценария; прямые переходы между ботом и каналом.
- MAX `START_AND_ATTRIBUTION.md` и карточка: общий Welcome, замены Telegram-
  навигации на MAX, ограничения транспорта. Не копируем список URL в Писаря.
- Существующий Pikabu skill и структурный адаптер; последние содержательные
  итоги задачи «Исследовать сообщество Пикабу» подтверждают ручной запуск
  дополнительного адаптера. Общий Писарь остаётся обязательным.
- `YANDEX_DIRECT_CREATIVE_TESTING.md` — draft, только адресный контекст связки;
  `YANDEX_DIRECT_OPERATIONS.md` — владелец действий с рекламой.
- Прочитаны адресные последние итоги «Я.Директ!» и доступная недавняя страница
  «VSL». Они преимущественно об атрибуции/оформлении, не устанавливают новых
  правил голоса. Полная история всех чатов не исследована и не объявляется каноном.

Knowledge MCP недоступен в инструментах текущего чата. Использованы известные
канонические файлы и read_thread; серверная регистрация использования не заявлена.
Личные здоровье/Нейроцех и полный приватный корпус не сканировались.

## Реализация

`content/author-voice/platform-adaptation-v1.md` — внутренний условный маршрут;
подключён к обязательному SKILL, README и карточке `platform.content`.
`delivery_platform` — необязательная редакционная метка schema, не настройка
Python-публикатора. Используются уже поддержанные поверхности.
Не создаются отдельные skill для MAX, рекламы, урока или пары коротких поправок.
Расширенный Markdown остаётся в своей прежней draft-границе, renderer не изменён.

Основная папка проекта остаётся чужим грязным рабочим checkout с активным дизайном
и блогом. Не обновляем её поверх текущей работы и не выдаём за свежий main.
При принятии пакет Писаря устанавливается из свежей принятой копии, не из старого
root. Проверка до реализации обнаружила старый глобальный пакет 2.5.2 вместо
принятого 2.6.0; собственных новых правок в этой старой runtime-копии не найдено.
