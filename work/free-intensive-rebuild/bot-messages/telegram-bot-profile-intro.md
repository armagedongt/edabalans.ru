# Карточка бота до нажатия Start

Это не сообщение исполняемой цепочки. Telegram показывает эту карточку человеку,
когда он впервые открывает пустой чат с ботом, ещё до нажатия **СТАРТ**.

Текущая аватарка проверена по production Telegram 3 сентября 2026 года: квадратная
фотография Сергея в синей рубашке и очках, на светлом фоне. Сам файл в Git не
сохраняется.

## Имя

Тренер по питанию 🍌 Сергей Воронцов

## Короткое описание

Пишу об адекватном отношении к питанию и похудению так, чтобы вы менялись!

## Вступительное описание

Меня зовут Сергей, я тренер по питанию — но я не буду заставлять вас есть меньше, я научу вас насыщаться больше!

👉 Жмите «СТАРТ» и в этом боте вы сможете:

✅ Подписаться на мой тг-канал

✅ Прочитать бесплатный интенсив «Последнее похудение»

✅ Узнать о моем Мастер-класс по изменению питания и пищевых привычек

Нажимая СТАРТ, вы соглашаетесь на обработку данных,  получение образовательных материалов и предложений о моих программах. Остановить сообщения: /stop Политика: app.edabalans.ru/docs

## Команда и меню

- `/start` — «Главное меню»;
- отдельная Web App-кнопка меню не настроена, используется стандартное меню команд.

## Ссылка на политику

В карточке показан адрес `app.edabalans.ru/docs`. Сейчас он перенаправляет на
каноническую Политику обработки персональных данных:
`https://go.похудение-это-есть.рф/legal/privacy`.

## Что требует решения

- вступление повторяет навигацию и описание интенсива, которые человек получает после Start;
- фраза «Узнать о моем Мастер-класс» содержит ошибку согласования;
- перечисление канала, интенсива и Мастер-класса размывает главное первое действие;
- юридическую приписку и ссылку нужно сохранить по смыслу, но отдельно решить,
  оставлять ли короткий redirect или показывать канонический адрес политики;
- аватарка актуальная и проверена по production Telegram 3 сентября 2026 года;
- отдельную картинку над вступительным описанием Telegram настраивает через
  **Edit Description Picture** в BotFather; Bot API не возвращает её вместе с
  текстом карточки, поэтому этот снимок фиксирует подтверждённую аватарку профиля.
