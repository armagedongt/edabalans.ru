# Решения: blog-seo-workbench-20261004

## Предложения отдельно от публикации

**Что решили:** публичные metadata сохранить неизменяемым снимком; варианты и два поля выбора владельца держать в одной рабочей Markdown-карте. Пустое поле не означает согласования. H1 и текст статьи не меняются из-за предложения SEO title.
**Почему:** решение Сергея — сначала выбирать формулировки, затем переносить их в статьи.
**Отклонение от user-spec:** нет.

## Wordstat без нового расхода

**Что решили:** использовать подтверждённый существующий бесплатный Direct v4 Wordstat в квотах. Первый успешный отчёт сохранён целиком; не повторять эти запросы без причины. Платный Cloud fallback без отдельно установленного бюджета не запускать.
**Почему:** маршрут даёт данные без нового SDK, ключа, платного запроса или изменения рекламы.
**Отклонение от user-spec:** нет.

## Рекомендации и даты

**Что решили:** внутри статьи 0–1 смысловой блок; три нижние карточки отдельно. 04.10.2026 — дата только действительно выполненных обновлений, не замена исходной даты.
**Почему:** ограничение владельца и запрет изображать свежесть неизменённого текста.
**Отклонение от user-spec:** нет.

## Частичная готовность карты

**Что решили:** предложения готовить по полной текущей основе пачками с writer validation/review pass. Следующие материалы явно неподготовлены; предложения по одному заголовку не сочинять. Ручные поля сохранять при продолжении.
**Почему:** сниппет не должен обещать отсутствующее содержание.
**Отклонение от user-spec:** нет.
