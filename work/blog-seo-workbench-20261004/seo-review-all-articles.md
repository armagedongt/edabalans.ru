# Заголовки и description всех статей блога

Снимок сайта: 04.10.2026. Материалов: 62. Это рабочая карта, не команда публикации. Текущие поля получены из публичного HTML, а не из черновиков. «В поиске сейчас» ниже означает HTML title страницы, не проверенный заголовок конкретной поисковой выдачи.

## Как редактировать

В каждом материале заполните только два поля «Мой SEO title» и «Мой description»: скопируйте предложенный вариант либо напишите свой. Пустое поле означает оставить действующее значение, а не автоматически выбрать мой вариант. H1 пока отдельно не меняем. Варианты не опубликованы.

Ориентир: title 45–65 символов с пробелами, description 120–170. Это удобные редакционные диапазоны, а не лимиты Google/Яндекса. Можно выходить за них ради смысла; важное ставьте первым. Не обещайте калькулятор, если есть только формула, и не повторяйте ключ несколько раз. Поисковик может показать другой заголовок или фрагмент текста.

SEO title — содержимое HTML title: один из источников заголовка результата поиска, а не команда поисковику показать именно эту фразу. Description — предложенное краткое описание; поисковик может взять другой фрагмент под запрос. Их смена не означает автоматическую ротацию или доказанное улучшение позиций. [Правила Google для заголовков](https://developers.google.com/search/docs/appearance/title-link?hl=ru), [правила описаний](https://developers.google.com/search/docs/appearance/snippet?hl=ru).

На [показанном примере Молянова](https://molyanov.ru/blog/kak-rabotat-s-ii-agentami-chtoby-oni-ne-tupili) проверка HTML 04.10.2026 показала разные формулировки: title «Два правила работы с ИИ-агентами: контекст и самопроверка», H1 «Как заставить ИИ-агента не тупить: минимум контекста и субагенты-проверяльщики». Это два названия одной темы, не две разные статьи. По одному HTML нельзя установить, какие варианты он тестировал раньше или какой работает лучше.
