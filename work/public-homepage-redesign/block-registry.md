# Реестр блоков новой главной

Обновлено: 01.09.2026
Текущая точка: мобильная цепочка из принятых блоков опубликована как noindex-preview; цены читаются из базы, checkout подключён только для закрытого preview, часто меняемые тексты вынесены в Markdown/API. Общая подложка «Дымка» принята для всей страницы, включая область общего подвала. Следующая единица приёмки — механика истории Ани.

| ID | Блок | Статус | Следующее решение |
|---|---|---|---|
| `page-surface` | Общая подложка | `accepted` | использовать светлую неравномерную голубую «Дымку» на всей высоте; секции не создают второй общий фон, подложка продолжается под подвалом |
| `header` | Шапка и меню | `revision` | desktop: широкая синяя pill-шапка в логике Нейроцеха с названием, ссылками `Блог`, `Бесплатный интенсив`, `Мастер-класс`, `Контакты` и спокойным входом в ЛК; mobile: только уменьшенный полупрозрачный синий hamburger |
| `hero` | Первый экран | `revision` | плашка `Мастер-класс · 21 день` вынесена в самый верх и повторяет белую карточку с оранжевой точкой и синим текстом; display-заголовок не менять без отдельного запроса, затем близко поставлен вертикальный внешний VSL с мягким ореолом и небольшой тенью |
| `vsl` | Видео и текстовый маршрут | `accepted` | внешний режим: muted autoplay, первый клик по плашке сбрасывает видео на начало, включает звук и анонимную аналитику; на паузе остаётся обычный Play, оглавления и перемотки нет; прогресс-бар идёт по плавной кривой `boost = 7` |
| `main-argument` | Основной текстовый аргумент | `pending` | разложить дословный текст текущей главной без переписывания |
| `before-after-method` | Похудение до/после Мастер-класса | `accepted` | включить готовый scroll-компонент в сборку главной на этапе интеграции |
| `recognition` | Узнаваемая интерактивная шутка | `accepted` | проверить принятый scroll-компонент в составе реальной главной и отдельно написать финальные боли через `platform.content` |
| `method` | Проблема старого подхода и метод Сергея | `revision` | первый отдельный четырёхшаговый синий маршрут отклонён; вернуться к блоку только в контексте основного текстового аргумента |
| `skills` | Области навыков | `pending` | состав и bento-композиция |
| `masterclass` | МК как первый вход | `pending` | отдельный продуктовый маршрут v1 отклонён как не соответствующий заданной последовательности страницы; вернуться только в предусмотренном основном контентном блоке |
| `program` | Программа МК | `revision` | вернуться после hero, метода и автора; светлая v3 остаётся рабочей версией, раскрытие всех 21 дней сохраняется |
| `inside` | Как Мастер-класс выглядит внутри | `pending` | собрать реальные видео и скриншоты, затем выбрать slider или gallery |
| `result` | Результат мастер-класса | `revision` | синий паттерн закреплён только за результатом; финальные пять строк писать после принятия программы, чтобы убрать повторы |
| `products` | Продуктовая система | `deferred` | пока оставить текущие стоковые иконки ЛК; собственное семейство не разрабатывать без новой задачи владельца |
| `consultation` | Консультация | `pending` | человеческий сценарий разговора |
| `author` | Об авторе | `deferred` | цветная v1 и спокойная нейроцеховская v2 отклонены; не продолжать без нового цикла и иной композиционной идеи |
| `reviews-inline` | Сквозные отзывы | `pending` | расставить реальные одиночные отзывы по ходу аргумента |
| `anya-story` | История Ани | `revision` | вертикальное видео — первый слайд; управление только swipe, стрелки и счётчик удалены; сравниваются три компактные подсказки жеста, после выбора заменить временные медиа реальными |
| `reviews-featured` | Сильные фото- и видеоотзывы | `pending` | определить набор главных кейсов |
| `reviews-wall` | Полотно «Больше отзывов» | `deferred` | первая версия сохраняет реальные изображения |
| `pricing` | Тарифы | `accepted` | основной v32 сохраняется; большая вводная заменена компактной плашкой `Выберите тариф`; цены и скидки только из active pricing v3, checkout серверный; таймер и синяя заливка минимального существуют только как query-форки до выбора |
| `guarantee` | Гарантия | `revision` | добровольное окно до дня 4 и согласование оферты/runtime |
| `faq` | Частые вопросы | `accepted` | основной цвет полного открытого блока остаётся нежно-красным; отдельный зелёный форк синхронизирует поверхность с гарантиями и плашками доверия; изображения только сверху и только при необходимости |
| `telegram` | Всплывающее приглашение | `deferred` | момент показа и текст |
| `cookie-notice` | Уведомление о cookie | `revision` | сохранить для финального выбора два направления: белая карточка №1 и цельная синяя №4; desktop — ширина примерно до середины экрана, текст и короткая кнопка в одной строке; mobile — компактная карточка по центру, кнопка не растягивается; текст обычным начертанием, ссылкой является только слово `Политику`; перед production сверить однокнопочную механику с фактическими счётчиками и юридическим решением |
| `decision-help` | Сомневаетесь? Как определиться? | `pending` | объединить два близких раздела в один маршрут выбора |
| `contacts` | Задать вопрос | `pending` | прямые ссылки Telegram и MAX |
| `final-cta` | Финальный выбор | `accepted` | использовать v17 с котом: светлые Telegram/MAX, базовая оранжевая CTA, VIP-градиент при наведении, жирное `Всем отвечаю лично`; footer остаётся отдельным блоком |
| `footer` | Подвал | `accepted` | подключать только общий `site-footer.js`; на светлой «Дымке» он остаётся прозрачным и наследует тёмный текст, отдельный редизайн проводить позже своим модулем |
