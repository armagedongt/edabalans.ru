# Реестр блоков новой главной

Обновлено: 01.09.2026
Текущая точка: цепочка из принятых блоков опубликована как noindex-preview; цены читаются из базы, checkout подключён только для закрытого preview, часто меняемые тексты вынесены в Markdown/API. Основной стандарт текста — `content-frame` 600/620/760 px; визуальные исключения имеют собственные именованные режимы, а не случайные локальные ширины. Общая подложка «Дымка» принята для всей страницы, включая область общего подвала. Следующая единица приёмки — наполнение истории Ани реальными изображениями и подписями.

Точный порядок и адреса редактируемых полей живут в
`content/public-site/homepage/block-map.json`. Текущая цепочка:
`hero-label` → `hero-title` → `hero-intro` → `hero-video` → `hero-outro` →
`recognition-title` → `recognition-intro` → `recognition-scene` → `approach` →
`before-after` → `anya-heading` → `anya-intro` → `anya-slider` → `anya-outro` →
`pricing-heading` → `pricing-cards` → `pricing-trust` → `pricing-program` → `faq` →
`final-cta` → `reviews-after-cat` → `footer`.
