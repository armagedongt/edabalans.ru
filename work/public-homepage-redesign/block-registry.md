# Реестр блоков новой главной

Обновлено: 02.09.2026
Текущая точка: авторская редакция из `2026-09-01-homepage-copy-master.md` сопоставлена с runtime; служебные заметки исключены, новые смысловые узлы получили адресные `block_id`, а четыре скриншота Мастер-класса собраны принятой плиткой 2×2. Цены читаются из базы, checkout подключён только для закрытого preview, часто меняемые тексты вынесены в Markdown/API. Основной стандарт текста — `content-frame` 600/620/760 px; визуальные исключения имеют собственные именованные режимы, а не случайные локальные ширины. Вертикальный ритм сведён к пяти общим уровням, и каждой границей владеет только один из соседних блоков — верхний и нижний отступы больше не складываются. Общая подложка «Дымка» принята для всей страницы, включая область общего подвала.

Точный порядок и адреса редактируемых полей живут в
`content/public-site/homepage/block-map.json`. Текущая цепочка:
`hero-label` → `hero-title` → `hero-intro` → `hero-video` → `hero-outro` →
`recognition-title` → `recognition-intro` → `recognition-scene` →
  `recognition-explanation` → `approach` → `before-after` → `inside` →
  `inside-gallery` → `experience-proof` → `free-intensive` →
`reviews-featured-heading` → `reviews-voice-1` → `reviews-voice-2` → `reviews-featured` → `method-proof` →
`pricing-heading` → `pricing-cards` → `pricing-trust` → `pricing-program` →
`anya-heading` → `anya-intro` → `anya-slider` → `anya-outro` → `anya-cta` → `author` → `faq` →
`final-cta` → `reviews-after-cat` → `reviews-wall` → `footer`.
