# Локальный просмотр финансов

Статус: ограниченная реализация принята к выпуску 22.10.2026. Этот помощник
остаётся только локальным просмотром с вымышленными данными за сентябрь–октябрь2026.
Полный будущий контур этим не утверждён.

Из корня этой рабочей копии:

```powershell
python work/finance-actuals/preview_server.py
```

Открыть `http://127.0.0.1:8768/finance`. Есть «План», «Факт · месяц»,
«Факт · всё время», ввод месячных расходов и переходы в демонстрационные CRM-карточки.
Прямой пример месячного экрана: `/finance?preview_mode=month`, общего: `?preview_mode=all`.

База по умолчанию — `D:/Codex/temp/finance-fact-preview/demo.sqlite3`, вне Git.
Можно выбрать отдельный `--data-dir` и `--port`. Сервер всегда слушает только
127.0.0.1, даёт локальную demo-сессию и явно помечает ответ `X-Finance-Demo: 1`.
Другие операции записи CRM заблокированы; нет фоновых ботов, отправки писем,
копии настоящих контактов/оплат или подключения к production.

Для проверки рабочего сценария:

```powershell
$env:FINANCE_QA_BASE_URL='http://127.0.0.1:8768'
node backend/tests/browser/finance-facts.e2e.mjs
```

Playwright берётся из обычных зависимостей проекта либо `CODEX_NODE_MODULES`.
Проверка отказывается писать, если сервер не loopback/demo. Она меняет только
вымышленные расходы в локальной базе.

API и расчётная агрегация — обычный код приложения; demo-подпись, автоавторизация
и заполнение SQLite находятся **только** в этом локальном скрипте. Его не включают
в production и не используют вместо общей админской авторизации.

## Проверка локального прототипа · 22.10.2026

40 профильных Python-проверок прошли; браузерный сценарий проверяет три режима,
выбор месяца, повтор после ошибки, расходы (неизвестно / ноль), денежные расчёты,
изменение суммарной конверсии, прежние планы и счётчик сопровождения в CRM.
Общий браузерный тест административной оболочки и проверка ownership прошли.

Две волны ревью: исправлены потеря рекламного источника у двух наблюдений одного
вступления и слишком узкие карточки факта на 761/768 px. Добавлены проверки
расчётных дохода, комиссий, стоимости времени и маржи, включая числовое значение
и отсутствие данных. Аудит изменённых границ безопасности — без находок.

Визуальные свидетельства вне Git: `D:/Codex/evidence/finance-fact-local-20261022`.
План проверен на 360, 430, 619, 620, 621, 759, 760, 761, 768 и 1440 px;
обновлённый факт — на 360, 430, 760, 761, 768, 1099, 1100, 1101 и 1440 px.
Блок CRM проверен отдельно на 360, 430, 768 и 1440 px; вся карточка CRM
целиком не проходила визуальное ревью.

Первый результат сохранён в ветке `codex/finance-fact-local` без публикации.

базу; этот helper и его демонстрационная база в production не используются.
