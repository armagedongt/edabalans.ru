## Прогресс курса хранится по stable material ID

**Что решили:** до перестановки карточек первого дня перенести существующий
`MasterclassStepProgress` с авторитетного `step_index` на `step_id`. Версия правил
курса фиксируется в `UserCoursePolicy`; активная runtime revision из
`managed_document_versions` фильтрует messenger material по этой версии. Порядок
редактируется в `content/masterclass/editorial/program.md` и попадает в runtime
штатной публикацией; `course.json` остаётся только seed. Старым участникам
назначается версия 1, новым доступам после cutoff — версия 2.

**Почему:** сейчас завершение хранится по номеру позиции. Перенос скрытой карточки
с пятого места на третье без migration способен обозначить уже пройденным другой
материал. Stable ID сохраняет фактический прогресс при перестановке, скрытии и
добавлении карточек, а policy version не навязывает новый обязательный шаг старым
участникам.

**Отклонение от user-spec:** уточнение после финальной проверки реализуемости.
Принятое продуктовое решение «старых участников не менять» сохранено; добавлен
обязательный технический backfill, который оставляет каждый completion на том же
материале.
