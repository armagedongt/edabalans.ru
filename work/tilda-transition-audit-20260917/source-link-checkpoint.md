# Источники и постоянные ссылки — 17.09.2026

Статус документа: `current`. Состояние реализации: `in_development`.

## Согласованный результат

- Telegram/MAX используют персональную ссылку на главную; источник принадлежит
  ссылке даже без известного email или при пересылке. Покупатель и права остаются
  определяемыми отдельно по email, подписанному callback и обычным правилам.
- Текущие метки канала имеют приоритет. Без меток и контекста прямая покупка
  остаётся без источника, прежние старты по совпавшему email не подставляются.
- Новые персональные `/m/<код>` и `/p/<номер>/<код>` используют существующий
  go-поддомен. Ранее выданные ссылки продолжают работать. Дни интенсива остаются
  серверными: новые страницы Тильды для дней не создаются.
- Обычные ссылки кабинета в ботах и письмах используют постоянный `/lk` на
  похудение-это-есть.рф. WebApp/внутренние API остаются серверными.

## Границы

Миграций, импорта, новых сервисов и настройки магазина нет. Для существующего
публичного LK потребуются только два несекретных runtime override:
ACCOUNT_PUBLIC_URL и MASTERCLASS_ACCOUNT_URL. Откат — исходные значения и
предыдущая ревизия. Контрольная покупка, отправки людям, DNS и изменения Тильды
не входят в этот выпуск. Metrika offline upload требует yclid; UTM сами по себе
сохраняют источник заказа, но не являются идентификатором посетителя Метрики.
