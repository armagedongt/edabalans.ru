# Решения: браузерный путь

## Условия владельца — 08.10.2026

Связь visitor с контактом включается до принятия уведомления; остальные новые
браузерные события — после принятия. Cookie и техническая история — 365 дней.
Наблюдаемый контакт не подменяет покупателя, вход и права. Пересланная ссылка
допускается как погрешность. Ускорение Tilda и доменный перенос не входят в выпуск.

## Проверки и ревью

Implementation wave1: code/test/docs выявили локальные разрывы в generic /go,
programmatic CTA дня4, CRM при новом email, маркировке контакта и защищающих tests;
исправляются в согласованном объёме. Security/infrastructure: clean.
Layout: добавлена контекстная evidence; новая карточка занимает всю строку сетки,
чтобы сохранить размещение прежних карточек. Mobile overflow окружающей CRM на
360/430 присутствует в baseline и не расширяет эту задачу.

Проверенный после исправлений набор: backend120 tests, TG/MAX50 tests; SDK двух
корней, реальная подготовка ссылок управляемой посадки, реальная форма checkout.
Новый browser-journey regression включён в действующий CI browser step рядом с homepage/intensive tests; новых сервисов/зависимостей нет.

Wave2 выполнена тем же полным составом: code/security/test/layout/infrastructure clean; documentation clean. Третья волна не запускается.
