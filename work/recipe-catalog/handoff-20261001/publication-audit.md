Полные авторские тексты и реальные экспорты не следует массово заливать на
сервер «для сохранности»: они остаются в приватных локальных папках.

выгрузки. Для другого компьютера потребуется явный перенос локального пакета.

## Как удостовериться в передаче

README этого пакета — единственный вход новому чату; он ссылается на сохранённые
карты, а не копирует библиотеку. Документационный выпуск доставляется штатным
commit/push/CI/deploy. Серверная запись recipe-catalog-routing получает новую
версию с repo-ссылкой и поштучным режимом. После выпуска проверяются серверный
Git HEAD, доступность handoff на диске сервера и прочитанная обратно карта.
Только после этих проверок сообщать, что документация передана на сервер.
