# Проверка переноса HTML в Markdown

Рабочая реализация использует существующие версии материалов и renderer.
Обратный рендер проверяет полное DOM-дерево, включая все атрибуты, кроме
не влияющего на содержание `img.decoding`. Первое принятие оставляет HTML
побайтно прежним. Известный полный исходник восстанавливается только по
совпадению рендера; остальные исходники получают SHA HTML-предка в блоке версии.

Пробная конверсия постоянной папки: 61 непустая статья представима текущими
компонентами; один пустой неопубликованный материал не переносится.
Известные полные MD-кандидаты: два. Текст пользователя не переписывается.

Набор проверок: обычная разметка, DQS/slider/spoiler/audio/video, неизвестный
HTML отклоняется целиком, byte-exact HTML и история, последующая MD-правка,
restore старого HTML, version/hash conflict, нативный Калорийный курс,
профиль полной шапки, отсутствие записи при preview, lost response без второй
версии, сохранение существующего/одновременного черновика, auth/Origin.

Production-перенос и установка клиента выполняются после проверки выпуска.
Тренировки исключены; специальные Git/рецептурные оригиналы не конвертируются.
