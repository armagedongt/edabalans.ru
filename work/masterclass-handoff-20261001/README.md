но сама по себе не доказывает реализацию. Не выдавать ручной переключатель за
автоматическую блокировку, не менять покупки/доступы реальных людей ради текста.

Если механика реализована другим потоком, проверить её свежую версию, затем
выпустить принятый финал штатным маршрутом. Иначе вернуть Сергею именно эту
