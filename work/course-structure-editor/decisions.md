# Решения: редактор структуры курсов

Статус: approved владельцем 25.08.2026 после трёхсторонней проверки.

1. Редактор структуры отделён от редактора тел материалов.
2. Первая реализация — для `masterclass-21` внутри общей `/admin`.
3. Сохранение сразу публикует цельную валидную ревизию.
4. PostgreSQL — runtime-источник; `course.json` — seed/export.
5. Материалы и системные шаги нельзя переставлять через UI.
6. Добавлять, удалять и переставлять материалы через UI нельзя. Эти изменения
   выполняются отдельной задачей через чат. Скрывать и возвращать можно обычные и
   системные шаги без изменения их позиций.
7. Пункты задания имеют стабильные ID и могут переставляться.
8. Открытие/завершение дня необратимо; снятие галочки после завершения допустимо.
9. Новая обязательность применяется только к тем, кто ещё не открывал день.
   Скрытый элемент сразу исключается из условий у всех; после возврата снова
   обязателен только в незавершённых днях.
10. Крупные структурные изменения владелец передаёт Codex отдельной задачей.
11. Хранятся последние 20 ревизий; active не удаляется.
12. Старый статический `masterclass-course-preview.html` удаляется, URL редиректит.
13. Первая версия использует общий механизм версионируемых управляемых документов,
    но реализует только схему структуры курса и не создаёт будущие справочники.
14. Прогресс материалов остаётся на существующем `step_index`: в первой версии
    редактор не выполняет операций, которые могли бы сдвинуть индекс.
15. Явный возврат скрытого элемента снова делает его обязательным для всех
    незавершённых дней; завершённые дни не пересчитываются.
16. Исторические числовые галочки сопоставляются текущему active baseline по индексу;
    неизвестная прежняя редакция чек-листа не восстанавливается догадкой.
