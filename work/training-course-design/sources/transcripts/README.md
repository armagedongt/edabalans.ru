# Транскрипты тренировочного направления

Статус документа: `current`  
Состояние: навигация по каноническим и служебным исходникам  

## Состав

- `training-streams-raw-merged.txt` — исходный слитный файл: сначала полный эфир, затем с начала повторяется короткая запись.
- `training-stream-2025-notes-cp1251.txt` — исходные таймкоды и рабочие заметки в Windows-1251; внутри есть не относящиеся к эфиру фрагменты, поэтому этот файл нельзя автоматически считать чистым конспектом.

Единственные дома отдельных транскриптов находятся в
`content/training/reference/transcripts/`. Полный эфир также зарегистрирован как
`knowledge://resource/training.stream-full.raw`, короткая резервная запись — как
`knowledge://resource/training.stream-short.raw`. Их бывшие побайтные копии в
этой папке удалены 31.08.2026.

Основной источник содержания — полный транскрипт 2:47:57. Короткая запись не
содержит второго самостоятельного эфира и повторно не анализируется. Слитный raw
тоже не является третьим источником: это техническая упаковка тех же двух
текстов.

## Контрольная точка повтора

В слитном транскрипте с 3803-й строки заново начинается вступление эфира. Это соответствует резервной записи 51:41.

## Производственное решение

Старый эфир не ставится в курс целиком. Из него берутся авторские истории, вопросы, примеры и исходные тезисы. Основные методические видео записываются заново после утверждения числовых протоколов.
