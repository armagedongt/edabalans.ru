## Источники и сохранность

Прямой публичный HTTP-снимок каждой Tilda-страницы получен 17.09.2026. Page ID и project ID 9532923 сверены с HTML. Сохранены исходные UTF-8 snapshots и record-by-record карты переноса. HTML не является публикуемым каноном и в Git не добавляется. Хеши snapshots находятся в `semantic-transfer-audit.json` и manifest. Текущие body/manifest до изменения сохранены вне Git для rollback; прежние медиа не удалены.

У `/starts` обнаружен JS-redirect на `https://telegra.ph/Plan-06-26-5`. Через официальный Telegraph getPage API проверены название и наличие полного материала (94 content nodes). Для переноса выбрана полная текущая Tilda-страница с тем же названием и собственными record IDs; redirect не принят за отсутствие исходника.

Библиотекарь применён как навигационный маршрут. Knowledge MCP tools в этой сессии недоступны: использован безопасный fallback по текущим опубликованным авторским источникам. После восстановления MCP требуется зарегистрировать фактическое использование пяти Tilda snapshots и разрешённой версии Мастер-класса; отдельная локальная библиотека не создана.

Перенос — механическая семантическая пересборка `full_source` / `structure_only`, не новый авторский текст. Сохранены порядок, примеры, числовая фактура, смысловые bold, списки и исходные подзаголовки. Tilda-плашки преобразованы в Obsidian NOTE; accordion-справки — в обычные H3 и текст. Перекрывающиеся italic+bold сведены к bold в нескольких местах, поскольку текущий ограниченный renderer не поддерживает эту вложенность; слова и смысловое выделение сохранены. H1 находится в manifest, не в body.

## Разрешённые изменения и служебные хвосты

- Не переносились общий Tilda header, cookie banner, footer, editor scaffolding, popup/form и кнопочные блоки. Глобальные header/footer/navigation блога не изменены.
- Удалены рекламные навигационные хвосты «перейти в канал / вернуться в бота», инструкция по кнопке над текстом, самопрезентационный Pikabu-хвост и обещания «пришлю на днях / проверьте в боте». Содержательные упоминания Мастер-класса и авторский финал сохранены.
- У «Японцев» оставлены все шесть принципов и весь абзац про руку с ложкой, чипсы и сухарики; галерея отзывов перенесена как три последовательных изображения. Ссылка на «Похудение начинается…» направлена на существующий адрес в этом блоге.
- В весах исправлена арифметическая опечатка: 80 кг минус 1 кг = 79 кг, а не 79,5. По явному решению Сергея психологический раздел взят **дословно** из production API `masterclass-21/day-01-article-03`, опубликованная версия 5, updated_at `2026-09-17T03:54:34.126241+00:00`. Не использована предложенная редактором новая оговорка.
- По одной существующей `blog_cta` добавлено интегратором после чистого авторского body: starts — intensive; остальные четыре — masterclass. У каждой статьи три связанных опубликованных материала.

Примеры сохранности/изменений:

1. «Принцип №5. Достаточно времени» из Tilda стал H2 с теми же словами; абзац про ложку остался после примера скорости еды.
2. «Ваш истинный вес теперь стал 79,5кг» → «Ваш истинный вес теперь стал 79кг» — только арифметика.
3. «Короче, если у вас РПП…» → точный раздел текущей версии 5, включая «Если у вас негативное отношение к взвешиванию…» — только явно разрешённый источник.
4. Tilda slider с тремя отзывами → три обычных Markdown-изображения с локальными URL в исходном порядке.

## Медиа и SEO

Сохранены 45 файлов: starts 14; jpn 15; blits 9; растения 5; весы 2. В том числе два исходных GIF и постер видео. Бинарные файлы не перекодированы. Hero — первое изображение источника, в body не повторяется. Card выбран отдельно: у «Японцев» и растений исходные 16:9; у блица близкий к 16:9 мем; у starts широкая иллюстрация «Сначала изменения…». У весов в источнике только две почти квадратные картинки — сохранена отдельная оригинальная card без изготовления новой иллюстрации. Размер карточки задаёт существующая оболочка.

Видео сохранено как локальный постер и исходная внешняя ссылка MP4 без HTML/JS. Публикация и внешний хостинг самого MP4 не изменялись. Alt описывает фактическое изображение, provenance сохраняет original Tilda CDN URL.

Применён текущий SEO-контракт runtime: title, excerpt/meta description, self-canonical, OG, JSON-LD Article с автором Сергеем Воронцовым, sitemap, robots Allow. У двух обновлений прежние slugs сохранены, дублей не создано. Noindex/nofollow с legacy Tilda не перенесены. Новые адреса: `vesy-instrukciya-po-primeneniyu`, `15-sovetov-tem-kto-hudeet`, `pravilo-30-rasteniy`.
