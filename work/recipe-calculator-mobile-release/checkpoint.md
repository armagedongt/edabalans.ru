# Калькулятор: телефон, оригиналы, примечания и обучение

## Согласованный результат

Название вместо заголовка с редактированием иконкой; каталог слева, сохранение
справа. Заголовок таблицы «Продукты», узкая «Добавить строчку» между составом и
итогами. Крестик удаления внутри строки, выбор применяется сразу. Выход и
порция — выделенные клетки итогов, буквы в весах запрещены. Примечания сохраняют
порядок приготовления и кликабельную ссылку. Временные ПК/Телефон для обратной связи.

Оригиналы загружаются из опубликованных авторских материалов; сохранение создаёт
личную копию. Неполные БЖУ не выдумываются: шесть карточек неактивны. Первое
обучение обязательно до серверного подтверждения; далее доступно из footer и ?.
Новые возможности сверх запроса только предложить текстом.
