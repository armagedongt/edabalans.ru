# Проверка инструментов возобновления

Статус: `draft`; 26.09.2026.

Изменены только рабочие инструменты аудита, не код сервера:

- отдельная папка `full-review` не перезаписывает первый исходник и API baseline;
- выбор одного source_id ограничен выбранной пачкой;
- targeted-проход использует тот же writer gate и optimistic locking;
- HTTP 200 с несовпадающим телом/медиа/ссылками/заголовками больше не кэшируется
  как успешный снимок. Неизменившиеся совпавшие снимки сохраняются.

Проверено: `py_compile`; ошибочный source_id отклонён до сетевого обращения;
на реальном запуске несовпадающий снимок «Привычек» заменён совпадающим, другие
четыре снимка пачки переиспользованы. Все пять текущих снимков пачки 4 после
повторных сетевых попыток совпали с локальными текстом/медиа/ссылками/заголовками.

24 теста `test_blog_content.py` и `test_article_markup.py`, 6 subtests — pass.
Первый запуск из корня не нашёл модуль app; запуск из backend обнаружил закрытую
системную Temp-папку. Повтор с отдельной новой приватной временной директорией
прошёл. Права системной папки не менялись, чужие временные файлы не удалялись.

Две свежие волны code-review: clean, доказанных замечаний нет. Последняя включала
все четыре затронутых helper-файла. Новые тестовые файлы не создавались;
инварианты проверены существующими тестами и адресными CLI/HTML-проверками.

Найденный дефект нумерации разорванных списков обойдён в разметке статьи с
сохранением авторских цифр. Общий renderer не изменялся. Он остаётся отдельным
техническим наблюдением, не скрытой частью редакторского выпуска.
