# Буквальные звёздочки в авторской формуле

Статус документа: `current`. Дата: 03.10.2026.

Проверка статьи 13178972 показала: исходные знаки умножения `*` воспринимаются
как курсив, а добавленное `**` вокруг формулы выводится служебными символами.
В Markdown звёздочки формулы теперь экранированы `\*`; общий renderer защищает
их до разбора выделений, затем sanitizer выводит исходный знак. Числа и операции
не менялись. Разделённые пустыми строками пункты 1–3 также собраны в один список.

Независимые code-reviewer и test-reviewer: clean. Редакторское ревью второй волны
с release renderer: clean. Профильный прогон markup/content/description:
47 passed, 6 subtests passed. Проверены реальные renderer и sanitizer, обычные
выделения, literal-знаки, исходный script и подпись ссылки.

Scoped security audit: исходный HTML остаётся текстом; фиксированная сущность
`&#42;` не вводит тегов/атрибутов. Проверки script/img-onerror, исходной entity,
амперсанда и ссылки pass. Первая дополнительная проверка ошибочно ожидала
target/rel после default sanitizer: он снимал их и до правки; уточнённая проверка
подтвердила неизменные href и буквальную подпись. Зависимости не менялись,
dependency scan для этой локальной правки не требовался.

Коммит renderer `8f317a1` принят в main. Выпуск и публичная проверка ожидаются.
