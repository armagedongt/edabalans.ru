# Внесённые исправления: первые две пачки

26.09.2026. Текущая команда владельца разрешает немедленную корректуру и
площадочную адаптацию старых и согласованных новых статей. Не разрешает менять
авторские идеи, фактуру, цифры и научные выводы без отдельного решения.

## Применено

В десять файлов `content/blog/articles/` внесена 61 адресная замена из
`corrections.json`. Для каждого полный исходник и машинные task/pack сохранены
приватно: `D:/CodexPrivate/blog-quality-corrections-20260926/<source_id>/`.
Все десять получили отдельный writer review и validation pass для `proofread`.
Публичные receipts и хеши находятся в `applied-receipts.json`: именно они, а не
локальный diff, подтверждают выпуск. API выполняет проверку версии, не затирает
чужие черновики и сохраняет выбранную автором обложку.

Выпуск подтверждён для всех десяти: API version 2, повторный GET совпадает с
проверенным текстом. Публичные страницы повторно открыты: HTTP 200, видимый текст,
ссылки и изображения совпадают с локальной исправленной сборкой. Проверка
визуального оформления по скриншотам этим не подменяется.

Примеры:

- «как буд-то бы» → «как будто бы»;
- «не будет соотносится» → «не будет соотноситься»;
- «последний раз если бобовые» → «последний раз ели бобовые»;
- «БЫТЬКАЖДЫЙ» → «БЫТЬ КАЖДЫЙ»;
- «нахер сума сошел» → «нахер с ума сошел»: авторская резкость сохранена.

Не удалены шутки, повтор «АГА!!! (нет)», эмоциональные заглавные буквы, CTA,
изображения, научные ссылки и цифры. Формула, где 74 − 8 даёт 64, сознательно
не исправлялась: пользователь запретил тихие смысловые/численные изменения.

## Записано, но не считается выполненным

Оформление заголовков, восстановление отсутствующих ссылок и видео, научный
проход, SEO-доработка и аналитика остаются отдельными проверками. Прохождение
корректуры не превращает все эти проверки в pass. Предыдущие замечания сохранены
в `batches/01-review.md`, `batches/02-review.md` и `owner-review/`.

Новая статья A002 / 10123213 восстановлена из полного ранее показанного прототипа;
корректура и просмотр трёх изображений выполнены. Статус доставки — local,
публичного выпуска ещё нет. Подробности — `new/10123213/HANDOFF.md`.

- A049 «Фрукты… ограничивать…» исключить из подготовки: последнее прямое решение
  владельца — банк, несмотря на ошибочное присутствие в старой publish_next.
- A184 «Пост 2026» — черновик семьи уже опубликованного «Великого поста»;
  не выпускать отдельный дубль. Канонический внешний источник — Pikabu 13762311.
- Закрытые рецепты, учебный архив, банк, «на подумать» и спорные семьи в открытую
  очередь не возвращаются по умолчанию.

## Точка продолжения

1. Проверить receipts; повторять только неуспешный выпуск. Успешный выпуск
   повторный запуск распознаёт без дополнительной версии.
2. Закрыть структурные и навигационные замечания этих десяти, затем пачка 03.
3. Параллельно по очередности работы готовить следующие согласованные новые
   семьи; не ограничивать задачу 44 существующими статьями.
