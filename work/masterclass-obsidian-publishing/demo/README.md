Статус: draft. Владелец: временная работа products.masterclass.course/platform.content.

Актуально после корректировки владельца: `/material` и `/day-1` используют
настоящую оболочку курса ревизии f151218 — sidebar, мобильную sticky-шапку,
плавающее содержание и навигацию. В MD образца только h1+h2. Кнопка содержания
автоматически собирает h2, в Obsidian отдельный спойлер для неё не нужен.
Цитата/одноцветная плашка сохранены локальными стилями. Это **локальная проверка**,
не опубликованный материал ученикам; программа взята из seed, не live DB.

Актуальные соответствия: `>` — цитата, `[!NOTE]` — жёлтая плашка без отдельного
заголовка, `[!NOTE]- Заголовок` — закрытый спойлер. Пустая строка `>` разделяет
абзацы. Другие callout не подключены. Добавлены зачёркивание, подсветка,
комментарии, строчный код, отдельный блок с копированием, галочки и разделитель.
Сохранение файла не запускает публикацию.

- «01-99 — Тест переноса Markdown.md» — общий поддержанный текстовый набор и
  запрошенное прототипное преобразование прямой ссылки на картинку.
- «Возможности Obsidian — лаборатория.md» — дополнительные базовые возможности,
  которые нужно сравнить в Obsidian и отдельно согласовать для сайта.

- [Шпаргалка Markdown](Шпаргалка%20Markdown.md) — короткая таблица и примеры записи.

  Git-ревизии 99051db. Не обращается к БД, не публикует, не получает секреты,
  не сканирует vault, не отдаёт корень проекта и не изменяет настоящую программу.

  не production stylesheet. Действующий ARTICLE_STANDARD уже задаёт новое
  соответствие `>` → callout-red и исключения callout-green/blue; закреплённый
  обработчик стенда от него отличается. Подробности — в «Карте переноса.md».

  стили образца. Настоящая оболочка читается напрямую из Git, не копируется.
  Её inline-скрипты разрешены точными CSP-хешами; API соединения — только self,
  iframe/POST отсутствуют. DQS helper читается локально без изменения его кода.

Запуск из корня: python work/masterclass-obsidian-publishing/demo/serve_demo.py.
Нужны уже установленный Python с FastAPI, Git и существующая Git-ревизия выше.
Пакеты не устанавливались. Шрифты читаются из указанной Git-ревизии без копирования.

После изменения исходной демо-MD обновите страницу в браузере. В production
ничего не изменится. Перезагрузка компьютера/остановка процесса остановит стенд.
Встроенный браузерный просмотр не является настройкой пользовательского vault.

актуальной реализации и согласование правил — этот стенд не такая реализация.
