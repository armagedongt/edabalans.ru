# История карты переноса Markdown

Статус: `archived`. Ниже сохранена история предыдущей ревизии, **не текущие правила**.
Актуальный единственный контракт: [Markdown → материалы](../../../docs/knowledge-base/MARKDOWN_MATERIAL_TRANSFER.md).
Каталог: [общие компоненты](../../../content/article-components/README.md).
Исторические checkbox/inline-code/scroll-table/старый токен ниже больше не
описывают текущий образец. Новый список ✓/×, мобильные карточки и LINK — в контракте.

## Предыдущая карта (для provenance)

Статус: draft. Дата: 16.09.2026. Это временная проверочная карта, не новый
редакторский канон. Канон оформления остаётся в
../../../docs/knowledge-base/ARTICLE_STANDARD.md. Этот стенд не записывает БД,
не вызывает публикационный API и не меняет program.md настоящего курса.

## Два вида материала — решение владельца

1. **Статья:** заголовок из программы, затем текст и разрешённые вставки.
2. **Комбинированный материал:** заголовок из программы, индивидуальное вступление,
   метка серверного компонента, затем непубликуемое описание компонента:
   вопросы/ответы/порядок/подсказки/действия. Разметка такого описания ещё не
   утверждена; не превращать её в автоматическую схему анкеты без согласования.

Бывший третий вид «сразу открыть приложение» в новой концепции не используется:
приложению тоже предшествует материал с вступлением и нужными действиями.
Это согласованный целевой принцип, не утверждение о текущем production.

## Уточнение владельца: материал в оболочке ЛК

В демонстрационном материале оставлены `#` и `##`. Третий уровень `###`
убран по просьбе владельца; это пока изменение образца, не массовая переработка
существующих материалов. Одноцветная плашка и понравившееся оформление цитаты
сохранены в локальном `lk-preview.css`.

`/material` теперь открывает **существующую оболочку курса**, а не прежнюю белую
страницу: слева программа, внизу навигация, на телефоне закреплённая шапка и меню.
Разметка/поведение взяты без переписывания из
`backend/app/static/masterclass-first-days-preview.html`, ревизия
`f151218ee685857ffd32ae02dc75b915328093a9`. Плавающее содержание — функции
`ensureArticleToc`, `configureArticleToc`, `toggleArticleToc` в этом файле.

В Obsidian отдельный блок содержания **не пишется**. Нужные разделы обозначаются
`## Название`. Оболочка сама собирает заголовки h2; при трёх и более разделах
появляется кнопка: справа на компьютере, в шапке на телефоне. Кнопка раскрывает
popover, ссылка закрывает его и переводит к разделу; активный раздел отмечается
при прокрутке. Это уже существующее поведение курса, не новый дизайн стенда.

Последнее решение владельца: `>` — цитата; `[!NOTE]` — жёлтая акцентная плашка;
`[!NOTE]- Заголовок` — закрытый спойлер. Строки тела начинаются с `>`, пустая
строка `>` разделяет абзацы. NOTE без минуса публикует только тело: заголовок
callout не превращается в дополнительный заголовок сайта. Для видимой ключевой
фразы пишите жирное начало внутри тела. Другие типы callout и `[!NOTE]+` пока
не подключены. Это не содержание и не автоматическая публикация.

Короткая инструкция с примерами: [Шпаргалка Markdown](Шпаргалка%20Markdown.md).

Источник программы — Git seed, не live DB. В памяти локального сервера первый
день дополнен тестом; настоящие шаги заблокированы и их исходники не загружаются.
Файлы настоящего курса, DQS, прогресс учеников и production не меняются. Локальные
действия интерфейса сохраняются только в отдельном localStorage этого стенда.

Пока владелец редактирует Markdown, затем просит Codex выполнить ручной выпуск.
Кнопки Obsidian и новые API-автоматизации отложены его прямой командой.
DQS-материал и встроенный в него код исключены из изменений этой задачи.

## Проверка соответствий

Матрица описывает закреплённый обработчик 99051db с локальным адаптером, а не
production. Новые соответствия владельца `>`/NOTE/NOTE-minus и дополнительное
форматирование уже проверяются здесь. ARTICLE_STANDARD в этой рабочей ревизии
ещё содержит старое назначение `>` → callout-red и запрет спойлеров. Перед общим
выпуском его и актуальный публикационный обработчик нужно согласованно обновить;
параллельный канон и реальные исходники курса в этой локальной задаче не менялись.

| Элемент | Поведение закреплённого обработчика / локального стенда | Что видеть в Obsidian |
|---|---|---|
| Главный заголовок # | Стенд берёт из первой строки; настоящий курс — из программы | Заголовок заметки |
| ## и ### | Renderer понимает оба; выбранный образец использует только ##, штатная кнопка содержания собирает только h2 | Подзаголовки |
| Абзацы | Уже поддержаны; пустые строки не задают пиксельный отступ | Абзацы |
| **Жирное**, *курсив* | Уже поддержаны именно эти варианты записи | Выделения |
| Простые списки | Уже поддержаны | Списки |
| Ссылка с подписью | Уже поддержана; сама по себе не кнопка | Кликабельная ссылка |
| Многострочная цитата > | Уже поддержана одним блоком | Цитата |
| :::note [Важно] | Историческая плашка обработчика стенда, не актуальная редакторская инструкция | Без дополнительного расширения не обязана быть плашкой |
| Простая таблица | Уже поддержана; узкий экран прокручивает таблицу внутри её блока | Таблица |
| ![описание](https://…/image.jpg) | Уже поддержана; сохраняет место изображения | Картинка |
| Голая https-ссылка на image.jpg/png/webp/gif/avif | **Новое поведение только прототипа:** отдельная строка превращается в картинку | Ссылка, не картинка |
| Адрес картинки без понятного расширения | Не угадываем содержимое; пока использовать ![описание](адрес) | Зависит от разметки |
| Обложка блога | Отдельное поле каталога, не первая картинка тела | Пока не объединена с этим MD |
| > [!NOTE] | Жёлтая плашка без заголовка и иконки, фон через CSS-токен | Обычный callout Obsidian |
| > [!NOTE]- Заголовок | Закрытый article-spoiler с заголовком | Штатный сворачиваемый callout |
| Остальные callout | Пока без согласованного автоматического переноса | Цветные плашки Obsidian |
| - [ ] / - [x] | Галочки автора, только чтение; без связи с прогрессом учеников | Редактируемые локальные галочки |
| ####–######, вложенные списки | Не поддержаны как нужная семантика renderer | Показываются в Obsidian |
| ~~текст~~ / ==текст== | Зачёркивание / подсветка | То же форматирование |
| Код в обратных кавычках | Короткий буквальный фрагмент внутри абзаца | Строчный код |
| Блок в тройных обратных кавычках | Отдельный буквальный текст с кнопкой «Скопировать», сохранены переносы | Блок кода |
| --- отдельной строкой | Лёгкий короткий разделитель | Горизонтальная линия |
| Сноски, формулы, Mermaid | Пока без согласованного переноса | Возможности Obsidian |
| [[ссылка]], ![[заметка]] | Нужна явная трансляция; не отправлять сырые конструкции на сайт | Ссылки/вставки внутри vault |
| %%комментарий%% | Скрывается при переносе, кроме буквального текста внутри кода | Скрывается в режиме чтения |
| HTML-комментарий | Уже удаляется renderer | Техническая метка |
| PDF/audio/video/плагины | Не часть обычного текстового API | Возможности vault/плагинов |
| Кнопка, spoiler, галерея, форма | Только согласованный продуктовый компонент, не произвольный HTML | Отдельный контракт и будущий тест |

Неподдержанные элементы показаны в отдельной лаборатории, а не отправлены
существующему renderer с молчаливой порчей разметки. Это намеренная граница стенда.

## Изображения

Голый адрес распознаётся как картинка только отдельной строкой, по HTTPS и
расширению пути; query string допустима. Место строки определяет место картинки.
Стенд ничего не скачивает, не переносит и не загружает. Браузер загружает картинки
по исходным публичным URL. Доступность внешнего адреса не гарантирована.

Для публичного блога существующий контракт требует локализовать изображения
и объявить их в manifest. Прототип не отменяет это ограничение. Будущий ручной
выпуск должен отдельно проверить/перенести изображения по правилам поверхности.

## Визуал и содержание

Типографика стенда совпадает с базовыми значениями ARTICLE_STANDARD: Inter
400/600/800, основной текст 18px / 17px, h2/h3. Плашка и обработка `>` теперь
следуют новым решениям владельца для этого образца, как пояснено выше.
Это сравнительный технический образец, не полная реализация действующего
стандарта и не скриншот текущего ЛК. Оболочка курса/блога/интенсива может
отличаться; итоговая текстовая семантика должна оставаться общей.

Публикационный образец теперь использует штатное содержание только по h2;
подробности — в уточнении выше. Старый обработчик по-прежнему понимает h3,
но в образце он не используется. Якоря разделов уникальны, главное название
заметки не дублируется в списке. Интерактивность содержания взята из самого ЛК.

Задача «Дизайн» подтвердила временный жёлтый фон `#FFF6C9`, radius 16px,
padding 19px 22px, без рамки/иконки/заголовка, с типографикой статьи. Готового
канонического CSS-компонента пока нет. Стенд использует временный семантический
класс `article-note-accent` и токен `--article-note-accent-bg` в lk-preview.css.
До общего выпуска соответствия должны перейти в ARTICLE_STANDARD и актуальный
sanitizer/component CSS; текущие файлы канона параллельной работы не менялись.

В имеющейся оболочке есть `copyDqsLink` для копирования ссылки. Общий блок
копируемого текста в проверенных Git-источниках не найден; локальный md-copy.js
использует тот же Clipboard API, но копирует только textContent своего pre/code.
Действующий DQS-материал не изменён. Полный запрет копирования статьи этой задачей
не вводится: это отдельная политика, не техническая гарантия защиты текста.

Интенсив не изменён. Белые составные карточки остаются его специальным форматом:
для обычных материалов МК пока достаточно списка/NOTE/спойлера. Перенос сложной
карточки потребовал бы дополнительной семантической метки и здесь не внедряется.

## Запуск

после правки достаточно обновить браузер. Это просмотр, не публикация.
