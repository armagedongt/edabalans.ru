## Историческое соответствие

Статус: draft. Решения Сергея от 16.09.2026 реализованы в локальном образце,
не в production. Это памятка переходного прототипа, не второй канон проекта.
Общий канон: ../../../docs/knowledge-base/ARTICLE_STANDARD.md.

| В Obsidian | На сайте |
|---|---|
| `# Название`, `## Раздел` | Главный заголовок и разделы; содержание собирается из разделов автоматически |
| `**жирный**`, `*курсив*` | Жирный и курсив; также поддержаны `__жирный__`, `_курсив_` |
| `~~текст~~`, `==текст==` | Зачёркивание и подсветка |
| `%%комментарий%%` | Не публикуется; многострочный комментарий тоже скрыт |
| `- Пункт`, `1. Пункт` | Обычный и нумерованный список |
| `- [ ] Пункт`, `- [x] Пункт` | Галочки автора, только отображение, не прогресс ученика |
| `> Текст` | Цитата с боковой линией |
| `> [!NOTE]` | Жёлтая плашка без иконки и отдельного заголовка |
| `> [!NOTE]- Подробнее` | Белый закрытый спойлер |
| Строчный код в одиночных обратных кавычках | Короткий буквальный фрагмент внутри абзаца |
| Отдельный блок в тройных обратных кавычках | Текст с кнопкой «Скопировать»; переносы строк сохранены |
| Markdown-таблица | Таблица; на телефоне прокрутка внутри блока |
| `---` отдельной строкой | Короткий лёгкий разделитель |
| HTTPS-ссылка на картинку отдельной строкой | Картинка в этом месте; адрес должен оканчиваться jpg/png/webp/gif/avif |
| `![описание](https://…/image.jpg)` | Картинка видна также в Obsidian |

## Плашка, спойлер и цитата

```md
> [!NOTE]
> **Ключевая мысль.** Текст жёлтой плашки.

> [!NOTE]- Подробнее
> Первый абзац внутри спойлера.
>
> Второй абзац.

> Обычная цитата с боковой линией.
```

Между разными блоками — пустая строка без `>`. Внутри блока пустая `>`
разделяет абзацы. В NOTE можно не писать заголовок; если написали после
`[!NOTE]`, на сайте он не выводится. Нужный читателю текст пишите в теле.

## Код и копирование

Строчный: ``Сохраните значение `категория` в поле.``

Для копирования целого шаблона:

````md
```text
Название категории:
Мои наблюдения:
Что хочу изменить:
```
````

«Код» здесь может быть обычным шаблоном ответа, не программой. Разметка внутри
него показывается буквально, комментарии не скрываются. Кнопка забирает только
текст блока, без соседних абзацев. Цветная подсветка языка не подключена.

Сноски, формулы, Mermaid, вложенные callout и специальные карточки интенсива
в этот набор не входят. Оформление сайта не обязано пиксельно повторять Obsidian.
Сохранение MD не запускает публикацию. Для локальной проверки обновите браузер.

Базовая запись сверена с [официальной справкой Obsidian](https://obsidian.md/help/syntax)
и [справкой о callout](https://obsidian.md/help/callouts).
