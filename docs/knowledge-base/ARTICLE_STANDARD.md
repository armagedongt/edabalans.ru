# Единый стандарт статей

Статус: `current`  
Владелец: `platform.content`  
Зафиксировано: 26.08.2026

## 1. Область действия

Этот документ определяет структуру и оформление всех текстовых статей сайта:
материалов курсов, страниц интенсивов и следующих форматов статей. Продуктовая
оболочка может добавлять навигацию, служебную строку, прогресс и действия, но не
создаёт второй набор правил для текста статьи.

Специализированное приложение, анкета или интерактивная таблица не становится
статьёй только потому, что открыта внутри той же оболочки.

## 2. Базовая структура текста

- Заголовки и подзаголовки берутся из авторского текста: из заданной структуры
  либо из уже существующей фразы, выражающей смысл раздела. Новые заголовки только
  ради оформления или оглавления не придумываются.
- Один абзац раскрывает одну мысль. Сплошные полотна и искусственный перенос каждой
  фразы на новую строку не используются.
- Маркированный список нужен для равноправных пунктов, нумерованный — только когда
  важен порядок действий или этапов.
- Каждый пункт списка начинается с прописной буквы. Полные предложения
  заканчиваются точкой; короткие однородные формулировки используют одинаковую
  пунктуацию во всём списке.
- Вложенные списки по умолчанию не создаются. Иерархия сначала разделяется
  подзаголовком, затем отдельным списком.
- Изображение вставляется по заданной ссылке без обязательной отдельной подписи.
  Спойлеры и сворачиваемые части статьи не используются.
- Таблицы, формулы, сравнения «до/после», галереи и другие разовые элементы можно
  предложить для конкретного места, но нельзя вставлять без явного решения
  владельца.

## 3. Разрешённые выделения

В обычной статье используются четыре способа выделения:

1. **Жирное начертание** — ключевая фраза внутри абзаца. Оно сохраняет размер и
   цвет окружающего текста и не превращает каждый абзац в отдельный элемент.
2. **Ссылка** — заметный синий текст со смысловой подписью; голый URL в основном
   тексте не используется без необходимости.
3. **Плашка с карандашным мазком** — основной способ выделить самостоятельную
   мысль, ориентир или короткое важное пояснение. По умолчанию используется
   красный мазок. Зелёный мазок применяется только по отдельной просьбе Сергея.
   Синяя плашка без боковой полосы используется редко, когда Сергей прямо просит
   выделить конкретный спокойный блок.
4. **Цитата** — самостоятельная сильная фраза с вертикальной акцентной линией.
   Например: «Цель наблюдения — не оценить себя, а увидеть повторяющиеся решения,
   которые действительно влияют на питание».

Правило заголовка цветной плашки:

- если в статье повторяется один тип данных, в заголовке используется его
  фактическое название, например «Размер порций» в материалах DQS;
- если это разовое привлечение внимания, используется заголовок «Важно»;
- другой заголовок применяется только по явному указанию владельца;
- повторяющиеся элементы с одним смыслом получают одинаковый заголовок и один
  визуальный формат.

Этого набора достаточно по умолчанию. Новый постоянный тип выделения не создаётся
для одной статьи: сначала он согласуется и добавляется в этот стандарт.

## 4. Типографика и отступы

Статьи используют `Inter` и только насыщенности `400`, `600` и `800`.

| Элемент | Размер | Насыщенность | Цвет | Межстрочный интервал |
|---|---:|---:|---|---:|
| Основной текст и список | 18 px; на телефоне 17 px | 400 | `#252525` | 1.65 |
| `h1` | адаптивно 38–62 px | 800 | `#252525` | 1.05 |
| `h2` | 29 px; на телефоне 25 px | 800 | `#252525` | 1.2 |
| `h3` | 23 px; на телефоне 21 px | 800 | `#252525` | 1.25 |
| Жирное внутри текста | размер окружающего текста | 600 | `#252525` | как у текста |
| Ссылка | размер окружающего текста | 600 | `#1769D2` | как у текста |

Единые интервалы:

- между соседними абзацами — `18 px`;
- перед `h2` — `44 px`, после него — `14 px`;
- перед `h3` — `32 px`, после него — `10 px`;
- после `h1` до первого содержательного элемента — `28 px`, на телефоне `22 px`;
- у списка сверху и снизу — `20 px`, отступ маркера — `26 px`, между пунктами —
  `8 px`;
- после изображения или основного медиа — `28 px`;
- между двумя соседними плашками — `14 px`, между плашкой и обычным текстом —
  `24 px`.

## 5. Плашки и цитата

В статьях доступны только три централизованных типа плашек:

| Тип | Когда использовать | Визуальное правило |
|---|---|
| Красный мазок | По умолчанию для любого выделения | Светло-красный фон, неровный красный «карандашный» мазок слева, скруглённые углы. |
| Зелёный мазок | Только по прямой просьбе Сергея | Та же форма, но светло-зелёный фон и зелёный мазок слева. |
| Синяя плашка | Только по прямой просьбе Сергея и точечно | Светло-синий фон, скруглённые углы, без боковой полосы. |

Плашка не растягивается до произвольной фиксированной высоты: её высота определяется
содержанием. У неё нет декоративного заголовка по умолчанию; ключевую фразу можно
начать жирным внутри текста.

Цвет и форма назначаются централизованно, а не отдельным CSS в конкретной статье.
В редакторе и Markdown используются только три семантических имени: `callout-red`,
`callout-green`, `callout-blue`. Без явного имени редактор выбирает `callout-red`.
Произвольные новые варианты, семантические цвета «пример», «действие», «ошибка» и
другие отдельные стили не добавляются.

Цитата не имеет цветного фона. Слева используется линия `4 px` цвета `#C95B3D`,
отступ текста от линии `20 px`, текст `22 px / 600 / 1.45`, на телефоне `20 px`.
Текст цитаты сохраняет основной цвет `#252525`.

## 6. Техническое представление

Содержание и визуал разделены. Писатель или редактор передаёт Markdown либо
семантический HTML, а публикационный контур сохраняет только разрешённые элементы:
`h2`, `h3`, абзацы, списки, `strong`, `em`, ссылки, цитаты, три утверждённые
плашки, изображение и подпись. Главный `h1` берётся из карточки материала и не дублируется
в теле статьи. CSS-классы, размеры и цвета из присланного текста не становятся
источником дизайна; плашка всегда нормализуется к общему классу оболочки.

Скрипты, iframe, обработчики событий, произвольные стили и классы публикационный API
удаляет. Из классов плашек он сохраняет только `callout-red`, `callout-green` и
`callout-blue`; отсутствие класса нормализуется к `callout-red`. Это не
редакторская правка текста, а постоянная граница безопасности. Ссылки, жирное
начертание, уровни подзаголовков, списки, цитаты, утверждённые плашки, изображения,
alt и подписи при этом сохраняются.
