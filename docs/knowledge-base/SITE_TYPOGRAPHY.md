# Единая типографика сайта и приложений

Статус: `current`  
Владелец: `platform.web_design`  
Решение Сергея: 18.10.2026

## Источник истины

`backend/app/static/site-typography.css` — единственное место подключения шрифтов
и общих типографических переменных. Публичный адрес — `/assets/site-typography.css`.
Тексты, интерфейсы, кнопки, меню, оглавления, карточки, кабинет, приложения,
блог и обычные заголовки используют `--ed-font-body` (Manrope).
`--ed-font-hero` (Unbounded 800) разрешён только крупному hero-тексту первого
экрана публичной страницы. Название сайта, тарифы, цены, меню и заголовки
интенсива используют Manrope. Это заменяет прежнее разрешение Unbounded для бренда
и произвольных display-акцентов.

Геометрия кнопок, цвета, отступы и структура меню принадлежат своим компонентам.
Унификация типографики не превращает подпись, кнопку и заголовок в один размер.
Код и технические примеры сохраняют системный monospace; эмодзи используют
системные emoji-шрифты. Отдельный Noto Color Emoji не загружается.

## Подключение и загрузка

Manrope — локальный variable WOFF2 с начертаниями 200–800, Unbounded — локальный
800. Файлы и OFL-лицензии находятся в `backend/app/static/fonts/`.
Кириллица и латиница разделены через `unicode-range`, URL имеют версию `v1`
и годовой immutable cache. При замене файла нужна новая версия URL.
Локальных `@font-face`, Google Fonts, удалённых CSS и TTF в потребителях нет.
Старые файлы/адреса шрифтов остаются для совместимости архивных снимков,
но действующие страницы их не запрашивают.

Первый документ предзагружает оба подмножества Manrope; страницы с hero —
также Unbounded. `font-display:optional` не допускает поздней смены уже
показанного резервного начертания. При очень медленной или недоступной загрузке
браузер может оставить Arial/sans-serif на текущем просмотре; кешированный
Manrope используется при следующем открытии. Загрузчик кабинета не ожидает
`document.fonts.ready`, не добавляет искусственную задержку и не блокирует медиа.
Шрифт скачивает сам браузер; устанавливать его пользователю не нужно.

## Роли текста

Переменные семейства, основного текста, подписей, действий и оглавлений
редактируются в `site-typography.css`. Для статей и продуктовых описаний
единственный слой — `content/article-components/typography.css`
(`/assets/article-typography.css`, в блоге также совместимый `/blog/assets/…`).
Интенсив подключает этот же слой, без копии его правил.

| Роль | Стандарт |
|---|---|
| Интерфейс | Manrope, базовый размер 16 px, line-height 1.55 |
| Текст статьи | 18 px, до 620 px — 17 px, 400 / 1.65 |
| Выделение в статье | 600 |
| H1 статьи | адаптивно 32–44 px, 800 / 1.12 |
| H2 статьи | 29 px, до 620 px — 25 px, 800 / 1.2 |
| H3 статьи | 23 px, до 620 px — 21 px, 800 / 1.25 |
| Подпись / компактное действие | 14 px, вес действия 800 |
| Ссылки оглавления статьи | 14 px, 400 / 1.4 |

Публичный hero сохраняет собственный адаптивный размер и управляемые строки.
Навигационная группа курса и название темы могут выделяться 800; вложенные
ссылки статьи используют обычное начертание. Плотность интерфейсов и размеры
иконок остаются у компонентов, а не у типографики.

## Новые страницы

1. Подключить общий CSS в head (для embed-фрагмента — stylesheet link), до стилей
   страницы. В полном документе добавить font preload Manrope с `crossorigin`.
2. Использовать `var(--ed-font-body)`; для hero первого экрана —
   `var(--ed-font-hero)` и preload его двух подмножеств. В новых компонентах не
   объявлять собственные семейства/`@font-face` и не копировать файл шрифтов.
3. Для читательского тела подключить общий слой статьи и его существующий root
   `#article` либо `.edb-program-card`. Размеры и веса брать из общих переменных.
4. Проверить реальный текст и меню на мобильном и desktop: переносы, отсутствие
   горизонтального переполнения, доступность действий, холодный/тёплый кеш и
   недоступность font URL. Архивные именованные HTML-снимки не переписываются.
