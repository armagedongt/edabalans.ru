# Глобальный модуль «Welcome и первая часть интенсива»

Статус: `draft / следующий в разработке`  
Владелец содержания: Сергей Воронцов  
Проверено: 22.08.2026

## Граница

Модуль принимает управление только через зелёный выход `Запустить Welcome` из
модуля `start_attribution`. Сам `/start`, распознавание ссылок, first-touch,
проверка повторного входа и выбор покупательской ветки сюда не входят.

Первый внутренний шаг модуля — навигационный пост и попытка закрепить его. Затем:

1. навигационный пост и закреп;
2. видеокружок знакомства;
3. приветствие «Сделайте похудение проще» с кнопкой `Начать интенсив`;
4. проверка подписки при нажатии кнопки;
5. просьба подписаться и повторная проверка;
6. fail-open через пять минут даже без подтверждённой подписки;
7. первая редакция: ссылка на единый интенсив на сайте и четыре промежуточных
   сообщения в течение четырёх дней;
8. будущая редакция: День 1–4 и промежуточные сообщения между днями;
9. проверки покупки между материалами.

## Предварительные выходы

- покупка мастер-класса → модуль `postpurchase_masterclass`;
- первая часть интенсива завершена без покупки → модуль `prepurchase_nurture`;
- ожидание кнопки/delay → модуль остаётся активным;
- ошибка доставки/состояния → ручная проверка.

Точные тексты, интервалы, условные ветки и полная Mermaid-схема будут утверждены
при следующем проходе по этому модулю. Исходный подробный материал пока хранится в
`../../../plans/TELEGRAM_START_LINKS_SPEC.md`.
