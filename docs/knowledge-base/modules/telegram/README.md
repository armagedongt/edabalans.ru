## Назначение

Telegram-бот — канал общей messaging-системы edabalans.ru. Пользователи, покупки,
доступы и бизнес-теги общие с CRM; Telegram хранит только специфичные для канала
аккаунты, сообщения, цепочки и события.

## Порядок разработки модулей

Первым самостоятельным модулем выделен **«Первичный вход и атрибуция лида»**.
Его каноническая спецификация — `LINKS_AND_ATTRIBUTION.md`. Модуль должен быть
закончен, протестирован и отражён в админке до начала реализации следующего блока
welcome/покупки/закрепа.

## Правило актуальности

Для ссылок и атрибуции главным документом является
`LINKS_AND_ATTRIBUTION.md`. Для ещё не перенесённых подмодулей источники истины
перечислены в таблице выше. После изменения работающего кода одновременно
обновляются состояние реализации, таблицы/API и пользовательская инструкция.
