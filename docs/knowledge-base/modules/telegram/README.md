## Назначение

Telegram-бот — канал общей messaging-системы edabalans.ru. Пользователи, покупки,
доступы и бизнес-теги общие с CRM; Telegram хранит только специфичные для канала
аккаунты, сообщения, цепочки и события.

## Канонический порядок чтения

1. `MODULE_DEVELOPMENT_STANDARD.md` — обязательный процесс разработки каждого
   глобального модуля.
2. `MODULE_REGISTRY.md` — полный реестр глобальных модулей и их статусов.
3. Документ конкретного модуля — подробный текст, границы и Mermaid-схема.
4. Техническое ТЗ и `TELEGRAM_BOT_CURRENT_LOGIC.md` — реализация и фактическое
   production-поведение.

Ссылки и атрибуция не являются отдельным глобальным модулем: это начальная часть
единого модуля «Старт и атрибуция». Его зелёный выход передаёт управление в
отдельный Welcome. Навигационный закреп, кружок, приветственный пост, кнопка и
проверка подписки являются первыми блоками Welcome.

## Правило актуальности

Для ссылок и атрибуции главными документами являются подробные требования владельца
и техническое ТЗ. `LINKS_AND_ATTRIBUTION.md` сохраняется как ранняя проектная
проработка и не имеет приоритета над ними. Для ещё не перенесённых подмодулей источники истины
перечислены в таблице выше. После изменения работающего кода одновременно
обновляются состояние реализации, таблицы/API и пользовательская инструкция.
