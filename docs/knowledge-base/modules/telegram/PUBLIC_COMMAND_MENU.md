# Публичное меню Telegram-бота

Статус: `current`. Модуль: `messaging.telegram.attribution`.
Решение владельца: 18.10.2026. Область: личный диалог основного Telegram-бота;
MAX и будущая Mini App-аналитика этим изменением не подключаются.

## Команды и содержание

Публичный список команд содержит ровно пять пунктов. `/start` продолжает работать,
включая системную кнопку первого запуска Telegram, но отсутствует в списке меню.

| Пункт | Команда | Поведение |
|---|---|---|
| Статья «Как сделать похудение проще!» | `/guide` | Тот же существующий Start, с его покупательскими и стоп-исключениями; отдельной копии приветствия нет |
| Мастер-класс по изменению питания и пищевых привычек | `/mk` | Короткий пост с описанием программы и отзывами на сайте; активная персональная ссылка, без кнопок и превью |
| Открыть телеграм-канал | `/channel` | Полный актуальный навигационный закреп бота, без видео, кнопок и превью |
| Написать мне лично | `/contact` | Тот же полный навигационный закреп из единственного канонического источника |
| Остановить отправку сообщений в этом боте | `/stop` | Установить stopped, завершить запланированные runs этого контакта существующим механизмом и подтвердить остановку |

Навигационные команды исполняются до временного обработчика произвольного
личного сообщения, поэтому вместе с контактом/каналом не присылается статья.
Они не снимают stopped. Команды не обрабатываются для групп и сообщений ботов.

Скрытая `/resume`, доступная из текста подтверждения остановки, возвращает
контакту active и присылает подтверждение. Она не запускает Start, не переигрывает
завершённые runs и не снимает blocked контакта или CRM-пользователя.
Это разрешение будущих сообщений действующего движка, а не включение новой
14-дневной рассылки: временная общая пауза маркетинга и другие ограничения остаются.

## Владелец текста и проекция

Обе команды `/channel` и `/contact` используют общий с приветствием выбор
навигации: готовый слот `tpl_onepage_navigation_tg` подготовленной воронки,
а при его отсутствии или неготовности — `tpl_onepage_entry_navigation`.
Служебное значение `[[SKIP]]` также оставляет общий исходный закреп.
Правка этого закрепа меняет следующие ответы обеих команд; уже отправленные
сообщения автоматически не редактируются. Персональные ссылки подставляются
при отправке. Команды не закрепляют ответ повторно и не запускают видео.

Отдельные редактируемые слоты `tpl_menu_masterclass/stop/resume` находятся
в существующем каталоге ContentItem. Seed создаёт только отсутствующее и не
перезаписывает поздние правки владельца. Старые `tpl_menu_channel` и
`tpl_menu_contacts` в существующей базе не удаляются, но меню их не использует.
Действующие сообщения связаны с trigger в content authoring и графе входа.
К отправке допускаются только опубликованные approved Telegram HTML-слоты.

Скрытые `/masterclass` и `/contacts` сохранены как варианты `/mk` и `/contact`.
В нативном Telegram-меню нельзя использовать кириллицу в имени команды:
пожелание `/гайд` реализовано как `/guide` с русской подписью.

Текущие имена и контакты берутся по
[PROJECT_IDENTITY](../../PROJECT_IDENTITY.md); полное название Мастер-класса
сверено с активным `product-catalog/core` при подготовке текста. Персональная
ссылка на предложение использует существующий генератор исходящих ссылок.
Все ответы этого меню отправляются без превью. Общая политика прочих сообщений
не меняется. Остановка действует до `/resume`, без годового срока.

## Регистрация меню

После выпуска обработчиков штатная идемпотентная команда
`docker compose exec -T telegram-bot python -m app.public_menu` устанавливает
список Telegram-команд для default и ru и глобальную кнопку типа commands.
Параметры подключения берутся из текущих защищённых настроек бота; токен не
передаётся в CLI-аргументах. Регистрация не отправляет сообщения пользователям.
Проверка результата — `getMyCommands` и `getChatMenuButton`.
