# Публичное меню Telegram-бота

Статус: `current`. Модуль: `messaging.telegram.attribution`.
Решение владельца: 18.10.2026. Область: личный диалог основного Telegram-бота;
MAX и будущая Mini App-аналитика этим изменением не подключаются.

Последующее уточнение владельца сохранено как
[план изменения меню](../../../plans/PUBLIC_COMMAND_MENU_REVISION_20261018.md).
Ниже описано действующее поведение, до реализации этого уточнения.

## Команды и содержание

Публичный список команд содержит ровно пять пунктов. `/start` продолжает работать,
включая системную кнопку первого запуска Telegram, но отсутствует в списке меню.

| Пункт | Команда | Поведение |
|---|---|---|
| Как сделать похудение проще | `/guide` | Тот же существующий Start, с его покупательскими и стоп-исключениями; отдельной копии приветствия нет |
| Открыть канал | `/channel` | «Пишу о питании и похудении так, чтобы вы менялись.» и прямая ссылка самого канала, не закрепа; превью включено, кнопок нет |
| Мастер-класс | `/masterclass` | Согласованный заголовок, подробное описание программы и отзывы на сайте; видимый полный домен без HTTPS, активная персональная ссылка, без кнопок и превью |
| Написать мне | `/contacts` | Приглашение задать вопрос о питании, похудении или программе, личные Telegram/MAX ссылками в тексте, без кнопок и превью |
| Остановить рассылку | `/stop` | Установить stopped, завершить запланированные runs этого контакта существующим механизмом и подтвердить остановку |

Навигационные команды исполняются до временного обработчика произвольного
личного сообщения, поэтому вместе с контактом/каналом не присылается статья.
Они не снимают stopped. Команды не обрабатываются для групп и сообщений ботов.

Скрытая `/resume`, доступная из текста подтверждения остановки, возвращает
контакту active и присылает подтверждение. Она не запускает Start, не переигрывает
завершённые runs и не снимает blocked контакта или CRM-пользователя.
Это разрешение будущих сообщений действующего движка, а не включение новой
14-дневной рассылки: временная общая пауза маркетинга и другие ограничения остаются.

## Владелец текста и проекция

Редактируемые слоты `tpl_menu_channel/masterclass/contacts/stop/resume` находятся
в существующем каталоге ContentItem. Начальное содержание и таблица соответствий
задаются `app/public_menu.py`; seed только создаёт отсутствующие слоты и не
перезаписывает поздние правки владельца. Каждый слот имеет цель, writer brief,
связь с прямой командой в content authoring и отображается в графе входного модуля.
К отправке допускаются только опубликованные approved Telegram HTML-слоты.

Текущие имена и контакты берутся по
[PROJECT_IDENTITY](../../PROJECT_IDENTITY.md); полное название Мастер-класса
сверено с активным `product-catalog/core` при подготовке текста. Персональная
ссылка на предложение использует существующий генератор исходящих ссылок.
Превью включено только у `/channel` среди новых сообщений меню, глобальная
политика остальных существующих сообщений не меняется.

## Регистрация меню

После выпуска обработчиков штатная идемпотентная команда
`docker compose exec -T telegram-bot python -m app.public_menu` устанавливает
список Telegram-команд для default и ru и глобальную кнопку типа commands.
Параметры подключения берутся из текущих защищённых настроек бота; токен не
передаётся в CLI-аргументах. Регистрация не отправляет сообщения пользователям.
Проверка результата — `getMyCommands` и `getChatMenuButton`.
