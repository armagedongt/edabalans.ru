# Что можно собрать из имеющихся авторских материалов

Статус документа: `current`
Состояние подбора зафиксировано; будущие уроки ещё не приняты.
Дата: 04.10.2026. Владелец: `products.training`.
Основание: просьба Сергея разложить конкретные первоисточники по текущей программе.

Подготовлены **73 карточки фрагментов из 24 источников**: 33 допускают близкое
к тексту использование с указанными правками контекста, 40 требуют обработки
устной речи, разработки или проверки существенных утверждений. Это не 73 урока,
не процент готовности курса и не 73 независимых уникальных отрывка.

**[Открыть подборку с дословными фрагментами](../../../../work/training-course-design/source-packs/2026-10-04/README.md).**
Каждый фрагмент уже имеет место в материале, источник, версию, точные координаты
и пояснение, что с ним делать. Полные источники сохраняют прежних владельцев;
этот документ отвечает за пригодность и размещение в тренировочном курсе.

полнотекстовые запросы про тренировки, восстановление, МПК, силовые, тестостерон,

Объединение выдачи дало 543 разных URI; это поисковые кандидаты, не число
прочитанных полностью документов. Часть запросов достигла лимита выдачи 100.

Дополнительно использован локальный каталог 38 полных авторских публикаций,
существующие учебные архивы и текущие документы курса. Полные источники,
из которых взяты цитаты, прочитаны; остальные отбирались по релевантности,
дублям и границам продуктов. Инвентаризация серверной выдачи нашла 22 записи
транскриптов в редакционном контуре; все 22 полностью заново не читались.

поиск имеет смысл по конкретному пробелу из таблицы, а не повтором всего обзора.

## С чего писать

Первый материал — обзор видов и целей: есть вступление и авторская фактура,
остаётся собрать понятное объяснение. Следом — прогресс и адаптация, где уже есть
личный опыт, но нужно исправить механизм. Параллельно можно собирать общий учёт
и материал о компенсации: для них есть наиболее законченные учебные куски.

Большую карту, батарею показателей и программы ступеней нельзя объявить готовыми
на основании количества цитат. Здесь основная новая работа — сами решения,
критерии и инструкции; подборка экономит поиск и сохраняет авторский голос.
