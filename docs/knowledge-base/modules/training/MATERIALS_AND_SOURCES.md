## Опора для производства по каждому материалу

[Карта содержания](COURSE_CONTENT_MAP.md) показывает новую укрупнённую схему,
происхождение её частей и судьбу прежних 28 единиц. По уточнению Сергея
04.10 посты — вспомогательные заметки, а не основа программы. В частности,
«13 правил» не планируется переносить целиком как учебный материал: выбирать
только организационные подсказки, которые меняют действие. Старое предложение
о почти полном переносе ниже заменено этой границей.

Первый черновик сохраняется как кандидат для большой карты целей и занятий;
после пересборки он не назначен первым уроком. Большой обзор физических
показателей/здоровья, ГТО и расширенных тестов — новое задание; готового полного
авторского текста для него не найдено. Начальные научные опоры и границы
исследования сохранены в [карте](COURSE_CONTENT_MAP.md#начальные-внешние-опоры-для-новых-частей).

Указатели на авторскую фактуру для конкретной задачи собраны в
[карте контента и маркетинга](../../../../work/training-course-design/06-content-and-marketing-map.md).
Это карта поиска, не завершённое распределение источников по 28 материалам.
[Индекс внешних опор](../../../../work/training-course-design/sources/external/evidence-index.md)
и исследования — исходный бэклог. Они не подтверждают автоматически каждый
тезис. Для числа, протокола или медицинского ограничения нужна отдельная
проверка первичного исследования/рекомендации и области применения.

## Условия превращения источника в материал

Для выбранного блока фиксировать один из статусов: `exact_reuse`, `edge_edit`,
`source_based_development`, `new_gap`. Это пока следующий производственный шаг,
а не уже выполненная маркировка всех блоков.

До читательского текста открыть полные источники; отдельно выписать авторскую
историю, проверяемый тезис, протокол и медицинскую границу. В готовой карточке
материала сохранять версии/URI источников, место использования, результат
проверки и принятия. Новые источники регистрирует библиотекарь; эта карта хранит
связь с курсом, не создаёт параллельную библиотеку.
