# SEO и последовательная готовность статьи

Зафиксировано: 01.10.2026. Этот документ владеет приёмкой блога, не голосом.
Разрешения редактуры — у `platform.content`, новая редактура только через Писаря.
Смысловые замечания записывать отдельно и не применять без решения Сергея.

## Один материал — один доказанный проход

Идти по согласованным семьям. Перед каждой статьёй сверять назначение и полный
канон в `content/author-voice/source-selection/article-source-registry.json` и
решениях владельца. «Банк», «на подумать», закрытое и учебное не выпускать по
похожему заголовку. После подтверждённого выпуска блог — канон семьи; внешние
версии и ссылки Telegram сохраняются в существующем связанном каталоге.

| Проход | Что доказать |
|---|---|
| Источник | Полный текст, provenance, семья, выбранная версия и права на медиа |
| Сохранность | Diff: разрешённые удаления/минимальные правки; фактура и голос не переписаны |
| Корректура | Опечатки/пунктуация, сохранность намеренных шуток/разговорности; свежие writer validation/review pass |
| Логика/нейрослоп | Конкретные фрагменты проверены; смысловые предложения в очередь владельцу, не в текст |
| Разметка | H1 только в оболочке, H2/H3, NOTE/цитаты/списки/выделения; нет управляющих артефактов, raw HTML/JS и случайных директив |
| Площадки/CTA | Убраны просьбы плюсов/комментариев и старые акции/бот-тесты; полезные авторские призывы сохранены или адресно переведены на действующий маршрут |
| Медиа | Каждый кадр просмотрен; свой сервер, HTTP 200, alt, размеры/вес/резкость/кадрирование; обложка не дублируется автоматически в теле |
| Особое медиа | GIF сохраняет анимацию, видео проверяется только при фактическом наличии в этой статье |
| Факты | Научные/числовые утверждения и первичные источники; расхождения отдельно, без тихой правки мнения |
| Связи | Нативные ссылки, 1–2 контекстные карточки, три нижних related; без self/другой версии семьи/закрытого текста |
| SEO | Проверен отдаваемый HTML и URL по пунктам ниже, не только manifest |
| UI | Desktop/mobile, оглавление/меню/фото/плашки/cookie/тема; отсутствие перекрытия и горизонтального overflow |
| Измерения | Отдельный статус подключения общего слоя; реальные события, если включён |
| Доставка | Свежая версия редактора, version-gated publish, совпадение public текста/медиа, receipt и возможность отката |

Каждый пункт имеет хеш текста/медиа, версию и доказательство: выполнено,
ожидает, неприменимо с причиной либо вопрос владельцу. Публикация не доказывает
фактчек. После обрыва продолжать с первого незавершённого пункта. Блокирующий
риск публикации не скрывать, независимые технические правки выполнять.
После опечатки повторять diff/writer/delivery; после медиа — файл/alt/вид/HTTP;
после тезиса — факт и соседний аргумент. Новую редакцию владельца сначала читать,
не перезаписывать старым MD. Общий недоделанный слой не обнуляет корректуру.

## SEO каждой страницы

- Один основной вопрос и каноническая семья, стабильный slug, настоящий 200,
  self canonical, отсутствие ошибочного noindex публичной статьи.
- Уместные уникальные title/description, H1/H2/H3. Не набивать плотность ключевых
  слов. Недостающий ответ/раздел — предложение Сергею, не дописанный авторский текст.
- Для description применять [формат Markdown](../../BLOG_API_AUTHORING.md):
  явное поле владельца в начале MD, иначе первые два предложения текста.
  Не подменять их старым excerpt или новым пересказом. Проверять meta/OG и
  карточки по опубликованной версии, а не по ещё не выпущенному черновику.
- Article/Person, OG и изображение совпадают с видимыми фактами; абсолютный image
  URL и alt. Schema не гарантирует rich result; FAQ/HowTo только по содержанию.
- Авторство и честные даты: исходник, публикация блога и значимое обновление —
  разные факты. Не вычитать сутки и не менять дату из-за deploy; не придумывать
  квалификацию врача. Реальные даты видимы и согласованы со schema.
- robots/sitemap только для public. Приватное закрыто доступом и noindex;
  robots сам по себе не защита текста. Проверить Вебмастер/Search Console,
  sitemap, индекс, ошибки, запросы/CTR; доступ не подразумевается.
- Внутренние ссылки — `a href`; каталог 15 карточек, долгосрочная пагинация —
  адреса страниц и серверный ответ. Не ставить canonical page1 всем страницам.
- Свои медиа, неизменяемые версионные URL производных; проверка размеров, веса,
  LCP/CLS/INP и мобильной скорости. Больший/мыльный результат перекодирования
  отвергать. GIF/видео не превращать автоматически в неподвижную картинку.
- Внешние дубли в provenance; canonical блога не обязывает чужие площадки
  передать приоритет. Не уникализировать текст заменами синонимов.

Основания: [даты](https://developers.google.com/search/docs/appearance/publication-dates),
[пагинация](https://developers.google.com/search/docs/specialty/ecommerce/pagination-and-incremental-page-loading),
[Article](https://developers.google.com/search/docs/appearance/structured-data/article),
[CWV](https://developers.google.com/search/docs/appearance/core-web-vitals).

## Аналитика — общий слой, не каждый Markdown

Счётчик/цели/рекламные отчёты принадлежат `marketing.analytics`,
[канон Я.Директа](../../YANDEX_DIRECT_OPERATIONS.md). Использовать существующую
Метрику, её номер/права сверить при включении; второй счётчик не нужен.
Cookie-уведомление общее, не идентификация/CMP. Метрика не угадывает границы
авторского материала: footer не означает дочитывание.

Контракт целей: открытие; 25/50/75/100% авторского тела; CTA click с placement;
related click с target_article_id; реальные popup view/close/click. Общие поля:
article_id/slug, content_version, placement, target. Без email/телефона/CRM ID и
секретных bot-токенов. Один init/pageview, без дублей и целей на каждый процент.
Глубина — достижение участка, не доказанное чтение. Активное время исключает
скрытую вкладку/idle; «вероятное дочитывание» пока не утверждённая метрика.
Клик не равен Start/подписке/прохождению; покупку подтверждает платёжный callback.
Article/placement связывать через существующий attribution с его владельцем,
не затирая рекламные UTM/yclid и не придумывая неподдерживаемый startlink.

## Сверка рабочей реализации 01.10.2026

Это состояние проверенной ревизии, не автоматическое свидетельство production.
Есть Markdown, title/description/canonical/OG, Article с Person, robots/sitemap,
свои медиа, ручные related и API редактирования/выпуска существующих статей.
В проверенном renderer ещё нет видимых дат/datePublished/dateModified,
стабильной авторской страницы, BreadcrumbList/og:image:alt.
В blog.js нет Метрики/article-целей, нового popup и автоматического related;
локальный пример также не подключает настоящую аналитику. Пагинация на JS-кнопках.
Это открытые общие доработки, не «отличное SEO уже всё сделано».

Предложения из `work/blog-seo-analytics/` были частично не перенесены в канон;
приёмка/ограничения теперь закреплены здесь. Старые popup-интервалы брать нельзя.
Следующий проход использует существующие доказательства, а не начинает всё заново.
Общий publish-ready нельзя присвоить по одной корректуре или факту публикации.
