# Каталог административных инструментов

Единый каталог `/admin` со ссылками и краткими пояснениями.

## Функции

- открывать личный экран погоды по прямому маршруту `/weather` без отдельного
  пользователя, пароля или новой сессии;
- показывать 12-дневный прогноз, 24 часа выбранного дня и дневник фактической
  погоды за выбранный прошлый период через Open-Meteo;

- показывать CRM, самостоятельные приложения, инструменты, проектные и сервисные ссылки;
- собирать видимые карточки из `admin_catalog` в module registry;
- вести к карте, памятке, планам и техническим документам;
- показывать единый список профилей приложений с визуальным признаком уже созданного
  состояния и открывать выбранный профиль в управляемом интерфейсе приложения;

## Граница

Не хранит бизнес-правила и не редактирует module registry.

## Источники истины

`docs/modules.toml` (`admin_catalog`) — единственный источник состава каталога.
Project map только показывает производную карту, а admin session только защищает доступ.
`/control` — совместимый redirect на `/admin`.

Технические файлы, routes, таблицы, migrations и программные символы не
перечисляются вручную в карточке: они подставляются из generated inventory.
