# Публичный сайт

Собирает одно каноническое полотно главной из отдельно принимаемых блоков.

## Функции

- показывать `noindex`-предпросмотр принятой мобильной цепочки;
- хранить часто изменяемый текст продуктовых мини-страниц, FAQ и содержательных
  блоков как версионируемый Markdown;
- безопасно рендерить Markdown через общий редакционный renderer;
- читать тарифы только из канонического pricing catalog;
- создавать server checkout и передавать штатную команду заказа корзине Tilda;
- обезличенно учитывать осознанный просмотр публичного VSL;
- переиспользовать принятые блоки на других публичных страницах без копирования
  их данных;
- продолжать принятую общую подложку страницы под каноническим публичным
  подвалом без локальной копии его разметки.
- держать обычные тексты в едином Tilda-подобном `content-frame` 600/620/760 px,
  а визуальные исключения адресовать именованными режимами: рабочая область
  главного видео — до `90svh` по высоте с неизменным форматом 3:4 и
  пропорциональным уменьшением по высоте, когда ширина не помещается между
  боковыми отступами; SVG до/после и сцена с человечком следуют общей колонке до
  `760px`, история Ани начинается на левой линии общей колонки, слайдер до
  `760px`, а карточка до `80vw/608px`; сетка тарифов остаётся отдельным `wide`
  до `1180px`;
- адресовать каждый блок главной и его редактируемые поля через
  `content/public-site/homepage/block-map.json`; тарифы, Markdown-контент, видео
  и общий подвал при этом продолжают читаться из своих владельцев фактов;
- размещать принятые тексты VSL-структуры только в адресованных блоках карты,
  не публикуя нерешённые варианты, COPY SLOT и редакционные заметки;
- подставлять ссылку и подпись CTA бесплатного интенсива из канонического
  `backend/app/intensive_public_cta.py`, а не дублировать их в HTML главной;
- показывать на desktop центрированную навигацию и раскрывать из `Контактов`
  компактное меню зарегистрированных личных ссылок и каналов без подмены
  отсутствующего адреса MAX-канала личным профилем;
- прокручивать облачка поверх адаптивной сцены с человечком с максимум двумя
  видимыми репликами, фиксировать последнюю и держать блок смены подхода сразу
  под изображением без технического пустого промежутка;
- открывать принятую сцену с человечком отдельным `noindex`-маршрутом библиотеки,
  используя канонический runtime главной без второй копии блока;
- показывать канонический видеоотзыв Ани в существующем публичном плеере с
  отдельным идентификатором аналитики;
- загружать для беззвучного loop только короткие MP4 Boomstream, а длинный файл
  подключать после осознанного клика и продолжать его с позиции окончания
  точного короткого вступления;
- лениво создавать видеоплеер Ани на расстоянии одной высоты окна от блока, не
  считая свайп карусели включением видео;
- через отдельный координатор оставлять активным один источник звука среди обоих
  видеоплееров и любого числа аудиоотзывов.

## Граница

Не владеет ценами, размерами скидок, оплатой и выдачей доступа. Не владеет
авторским голосом и не переписывает тексты. `platform.commerce` поставляет цены и
checkout, `platform.content` — Markdown-диалект и версионирование, а
`platform.web_design` — дизайн-код и correction memory. Разметкой и поведением
общего подвала владеет `platform`; публичный сайт задаёт только контраст текста
относительно своей подложки.
