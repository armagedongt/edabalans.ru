# Публичный сайт

Собирает одно каноническое полотно главной из отдельно принимаемых блоков.

## Функции

- показывать `noindex`-предпросмотр принятой мобильной цепочки;
- хранить часто изменяемый текст продуктовых мини-страниц, FAQ и содержательных
  блоков как версионируемый Markdown;
- безопасно рендерить Markdown через общий редакционный renderer;
- читать тарифы только из канонического pricing catalog;
- создавать server checkout и передавать штатную команду заказа корзине Tilda;
- обезличенно учитывать осознанный просмотр публичного VSL;
- переиспользовать принятые блоки на других публичных страницах без копирования
  их данных;
- продолжать принятую общую подложку страницы под каноническим публичным
  подвалом без локальной копии его разметки.
- держать обычные тексты в едином Tilda-подобном `content-frame` 600/620/760 px,
  а визуальные исключения адресовать именованными режимами: главное видео до
  рабочая область главного видео ровно `90svh` по высоте (ширина выводится из формата 3:4), SVG до/после до `760px`, сцена с человечком до `874px`, история
  Ани начинается на левой линии общей колонки, слайдер до `760px`, а карточка до
  `80vw/608px`; сетка тарифов остаётся отдельным `wide` до `1180px`;
- адресовать каждый блок главной и его редактируемые поля через
  `content/public-site/homepage/block-map.json`; тарифы, Markdown-контент, видео
  и общий подвал при этом продолжают читаться из своих владельцев фактов;
- показывать канонический видеоотзыв Ани в существующем публичном плеере с
  отдельным идентификатором аналитики.
- зацикливать беззвучный автоплей основного VSL и видеоотзыва Ани до первого
  ручного включения звука, после которого ролик начинается с нуля без loop.

## Граница

Не владеет ценами, размерами скидок, оплатой и выдачей доступа. Не владеет
авторским голосом и не переписывает тексты. `platform.commerce` поставляет цены и
checkout, `platform.content` — Markdown-диалект и версионирование, а
`platform.web_design` — дизайн-код и correction memory. Разметкой и поведением
общего подвала владеет `platform`; публичный сайт задаёт только контраст текста
относительно своей подложки.
