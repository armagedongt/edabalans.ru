# Явно отложенные модули

Ветка модулей, которые владелец прямо решил сделать позже.

## Функции

- показывать будущие module boundaries без притворства, что они работают;
- группировать только owner-explicit планы;

## Граница

Идея или черновик не попадают сюда автоматически.

## Источники истины

`docs/plans/` с обязательными metadata.

Технические файлы, routes, таблицы, migrations и программные символы не
перечисляются вручную в карточке: они подставляются из generated inventory.
