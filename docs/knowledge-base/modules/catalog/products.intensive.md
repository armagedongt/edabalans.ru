# Бесплатный интенсив

Главная и четыре публичные страницы интенсива с единым визуалом, прогрессом и аналитикой.

## Функции

- показывать четыре дня по временным правилам для персонального входа;
- при анонимном прямом входе показывать меню и все четыре части сразу;
- встраивать публичное меню в один блок T123 через стабильный JavaScript-загрузчик
  без `iframe`, сохраняя рекламную атрибуцию в серверных ссылках частей;
- открываться тем же frontend как обычная web-страница и Telegram Mini App;
- повторно восстанавливать персональный прогресс по стабильной непрозрачной ссылке
  вида `https://go.похудение-это-есть.рф/i/<код>`; код не содержит открытых
  идентификаторов пользователя или названия мессенджера;
- сохранять в PostgreSQL время старта, открытые части, обязательные переходы и
  источник Telegram/MAX; подписанная browser cookie только восстанавливает
  серверную identity;
- брать адрес задания из серверной конфигурации и разрешать только канал,
  подписанный в персональном входе; Telegram ведёт прямо на публикацию, MAX —
  прямо в бота, который присылает утверждённую копию задания;
- сохранять разрешённые клиентские события персонального маршрута в
  `course_events` с идемпотентностью по смысловому действию;
- переносить UTM и `yclid` между страницами и отправлять цели в счётчик Метрики
  `97331502`;
- редактировать содержимое через специализированный admin flow;
- поставлять проверенный публичный CTA для внешних поверхностей проекта;
- передавать Telegram-first вход дочернему модулю `products.intensive.telegram-login`;
- в первом дне встраивать однофайловый публичный плеер с зацикленным беззвучным
  autoplay до включения звука, ручной перемоткой и анонимной аналитикой из
  `products.public-site`;

## Граница

Это web-продукт; Telegram welcome/intensive и выдача копий заданий в MAX принадлежат
соседним messaging-модулям. Web-модуль фиксирует нажатие своей кнопки и возвращает
прямой адрес нужного канала, но не создаёт промежуточные переходы между ботом и
публикацией канала.

## Источники истины

`docs/INTENSIVE_PAGES.md`, intensive routes/static, content runtime и
`backend/app/intensive_public_cta.py` для публичного CTA.

Публичная карточка интенсива на внешних поверхностях использует заголовок
«Как сделать похудение проще» и действие «Читать бесплатно»; URL и tracking key
остаются типизированными фактами runtime.

Технические файлы, routes, таблицы, migrations и программные символы не
перечисляются вручную в карточке: они подставляются из generated inventory.
