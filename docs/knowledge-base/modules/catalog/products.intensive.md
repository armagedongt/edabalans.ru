# Бесплатный интенсив

Главная и четыре публичные страницы интенсива с единым визуалом, прогрессом и аналитикой.

## Функции

- показывать четыре дня по временным правилам;
- показывать меню с открытыми и ещё закрытыми частями;
- сохранять в PostgreSQL время старта, открытые части, обязательные переходы и
  источник Telegram/MAX; подписанная browser cookie только восстанавливает
  серверную identity;
- переносить UTM и `yclid` между страницами и отправлять цели в счётчик Метрики
  `97331502`;
- редактировать содержимое через специализированный admin flow;
- поставлять проверенный публичный CTA для внешних поверхностей проекта;
- передавать Telegram-first вход дочернему модулю `products.intensive.telegram-login`;
- в первом дне встраивать однофайловый публичный плеер с зацикленным беззвучным
  autoplay до включения звука, ручной перемоткой и анонимной аналитикой из
  `products.public-site`;

## Граница

Это web-продукт; Telegram welcome/intensive является соседним messaging-модулем.
Кнопка MAX на web-страницах является измеряемым внешним переходом. Сквозная
MAX-последовательность не входит в этот модуль и до её реализации интенсив остаётся
Telegram-first.

## Источники истины

`docs/INTENSIVE_PAGES.md`, intensive routes/static, content runtime и
`backend/app/intensive_public_cta.py` для публичного CTA.

Публичная карточка интенсива на внешних поверхностях использует заголовок
«Как сделать похудение проще» и действие «Читать бесплатно»; URL и tracking key
остаются типизированными фактами runtime.

Технические файлы, routes, таблицы, migrations и программные символы не
перечисляются вручную в карточке: они подставляются из generated inventory.
