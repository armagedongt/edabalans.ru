# Личные сообщения поддержки

Позволяет администратору отправить конкретному клиенту личное сообщение и увидеть результат.

## Функции

- создавать ручное сообщение из карточки клиента;
- фиксировать доставку или ошибку в общей timeline;

## Граница

Не является массовой рассылкой или автоматической sequence.

## Источники истины

Telegram admin runtime и `INBOX_AND_BROADCASTS.md`.

Технические файлы, routes, таблицы, migrations и программные символы не
перечисляются вручную в карточке: они подставляются из generated inventory.
