# Эксплуатация платформы

Область базы, доставки версий, proxy, backups, imports, legacy и рабочих artifacts.

## Функции

- поддерживать воспроизводимый и безопасный production-контур;
- разделять эксплуатационные процессы по риску;

## Граница

Не владеет продуктовым смыслом приложений.

## Источники истины

`docs/OPERATIONS.md`, infra config и дочерние карточки.

Технические файлы, routes, таблицы, migrations и программные символы не
перечисляются вручную в карточке: они подставляются из generated inventory.
