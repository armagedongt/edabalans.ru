# Пересылка между чатами Telegram и MAX

Для каждого потока задаётся одна пара каналов и одна пара обычных чатов практики.
Публикация идёт из Telegram в MAX. Сообщения двух чатов пересылаются в обе стороны;
у копии появляется строка «Из Telegram · Имя» или «Из MAX · Имя». В тексте не
передаются username, телефон и ссылка на профиль. Когда оба исходных сообщения
известны, ответ сохраняет ответ на исходное сообщение.

## Функции

- запомнить пару площадок и карту соответствующих сообщений;
- не отправлять копию повторно при повторной доставке webhook;
- переносить текстовые сообщения, ответы и доступные правки;
- переносить удаление из MAX в Telegram;
- хранить попытку доставки отдельно, чтобы ошибку можно было увидеть и повторить;
- подписать отдельного MAX-бота на защищённый HTTPS webhook через штатный скрипт.

## Известные границы

- Telegram Bot API не присылает событие удаления чужого сообщения. Поэтому
  удаление из Telegram в MAX автоматически не синхронизируется.
- До практического теста после модерации MAX-бота не обещаются нативные MAX
  голосовые: публичная схема API допускает неполный payload такого события.
- Фото, видео, аудио, кружки и альбомы — следующий слой после приёмки
  текстового обмена на тестовой паре. Он не должен включаться без живой проверки
  формата MAX и Telegram.

## Включение тестовой пары

После одобрения MAX-бота в защищённый server `.env` добавляются только его токен
и отдельный секрет webhook. Затем один раз запускается
`telegram-bot/service/set_cross_messenger_max_webhook.py`: он сам задаёт MAX
адрес `https://edabalans.ru/api/messaging/cross-messenger/max/webhook` и три
типа событий — создание, правка и удаление сообщения. Затем
`telegram-bot/service/configure_cross_messenger_pair.py` принимает четыре ID
площадок и переводит только эту пару в `test` или `active`. Реальные каналы не
включаются в пару до проверки тестовой.

## Граница

Этот модуль не ведёт спринт, не выдаёт доступы к нему и не строит архив. Он даёт
синхронный слой живого общения, который сможет использовать модуль спринтов.
