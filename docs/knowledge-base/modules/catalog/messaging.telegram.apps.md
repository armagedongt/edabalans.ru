# Приложения в Telegram

Показывает участнику только доступные ему Mini Apps по действующим правам в
PostgreSQL.

## Функции

- принимать короткие общие `/start` payload: `apps`, `dqs`, `training`,
  `metabolism`, `recipes`;
- связывать новый контакт текущего бота с уже известным Telegram ID без создания
  второго пользователя;
- перед показом каждой кнопки проверять действующий доступ к соответствующему
  ресурсу;
- открывать тот же нативный экран как Telegram Mini App; сервер повторно проверяет
  подписанный Telegram `initData` и право на приложение;
- показывать в «Моих приложениях» только доступные человеку кнопки;
- по кнопке «Обновить» пересчитывать права и редактировать исходное сообщение, а
  не присылать новое;
- работать во время общего режима ремонта бота, не запуская welcome или другую
  маркетинговую цепочку.

## Граница

Модуль не выдаёт права и не определяет состав продукта. Он только читает активные
`user_accesses`. Массовая рассылка ссылок людям остаётся отдельной операцией и без
явного запуска владельца не выполняется.

## Источники истины

`user_accesses`, `resources`, `messenger_accounts`, Telegram runtime и продуктовые
маршруты `/dqs`, `/training`, `/metabolism`, `/recipes`.
