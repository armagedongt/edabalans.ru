# Техническая табличная админка NocoDB

Даёт ограниченный технический просмотр и ручную диагностику PostgreSQL.

## Функции

- просматривать таблицы в специализированном техническом интерфейсе;
- исправлять отдельные значения только по операционным правилам;

## Граница

Не является backend, source of truth или частью общего admin login; развитие отложено.

## Источники истины

NocoDB config/runtime и `docs/OPERATIONS.md`.

Технические файлы, routes, таблицы, migrations и программные символы не
перечисляются вручную в карточке: они подставляются из generated inventory.
