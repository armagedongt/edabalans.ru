# Веб-дизайн и дизайн-взаимодействие

Модуль сохраняет устойчивый способ совместной работы над сайтами и визуальные
предпочтения владельца так, чтобы новый чат продолжал накопленный контекст, а не
начинал интервью заново.

## Функции

- вести раздельную память визуальных предпочтений и удобного процесса работы;
- сохранять раздельные append-only журналы дизайн-коррекций и коррекций workflow;
- согласовывать сайт по одному смысловому блоку за цикл;
- показывать mobile-first варианты блока прямо в разговоре;
- отделять общие предпочтения владельца от решений конкретного сайта;
- передавать другому чату активный блок и принятые решения через общий skill.

## Граница

Модуль не владеет авторским голосом, продуктовыми фактами, юридическими условиями,
кодом конкретной страницы или публикацией в Tilda. Публичный текст проходит через
`platform.content`; факты и ограничения поставляет владеющий ими продуктовый
модуль. Реализация конкретного сайта остаётся в его проектном модуле или активном
рабочем контуре.

## Источники истины

- `content/design-workflow/skill/sergey-web-design/SKILL.md` — обязательный маршрут;
- `content/design-workflow/skill/sergey-web-design/references/design-preferences.md` —
  устойчивые визуальные предпочтения;
- `content/design-workflow/skill/sergey-web-design/references/collaboration-workflow.md` —
  правила совместной работы;
- два соседних correction log — история подтверждённых изменений этих правил.

Глобальный каталог Codex подключает проектную папку skill через directory junction,
поэтому у проекта и других чатов остаётся один источник истины без копий.
