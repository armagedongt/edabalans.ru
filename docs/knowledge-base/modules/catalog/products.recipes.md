# Калькулятор рецептов

Отдельное приложение в Tilda Members Area для владельцев доступа к рецептам или
калориям. Общий каталог продуктов принадлежит платформе; личные продукты и блюда
видны только создавшему их человеку.

## Граница

Модуль не связан с расчётом метаболизма. Он использует тот же переходный вход
Tilda и внутренний `user_id`, но хранит самостоятельные таблицы, API и экран.

## Источники истины

- PostgreSQL: общий и личный каталог, рецепты, ингредиенты и доступ `recipes`.
- `data/calorizator/calorizator.sqlite`: локальный входной файл для контролируемого
  импорта общего каталога; в нём не меняются данные этой функцией.
- `backend/scripts/import_recipe_catalog.py`: импортирует только карточки с полным
  набором Б/Ж/У/ккал.

Технические файлы, routes, таблицы и migrations перечисляет generated inventory.
