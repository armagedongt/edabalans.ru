# Telegram-бот

Telegram-канал общей messaging-системы: вход, цепочки, поддержка, рассылки и delivery.

## Функции

- принимать update и исполнять опубликованные графы;
- показывать специализированную админку без no-code редактора логики;

## Граница

CRM-факты о клиенте, покупке и доступе остаются у platform modules.

## Источники истины

`docs/TELEGRAM_BOT_CURRENT_LOGIC.md`, Telegram runtime graph и дочерние карточки.

Технические файлы, routes, таблицы, migrations и программные символы не
перечисляются вручную в карточке: они подставляются из generated inventory.
