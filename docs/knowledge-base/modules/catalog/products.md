# Продукты и клиентские приложения

Крупная ветка пользовательских продуктов edabalans.ru.

## Функции

- объединять продуктовые модули на общем backend и user_id;
- сохранять отдельный UX каждого продукта;
- давать приложениям общий дизайн-код на основе DQS и единый переход в серверный ЛК;
- использовать единую карту цветов, три радиуса и повторяемые типы карточек из
  `docs/APPLICATION_PLATFORM.md`, не вводя локальные декоративные варианты;
- показывать незавершённые продукты единым статусом «Скоро», отличая их от готовых
  продуктов без пользовательского доступа;
- показывать общий юридический подвал внутри доступной контентной области приложения;
- временно публиковать отдельные `noindex`-предпросмотры принятых блоков новой
  публичной главной до появления самостоятельного модуля публичного сайта;
- обезличенно учитывать осознанные просмотры публичного VSL, начиная только после
  первого включения звука и не связывая статистику с пользователем ЛК;

## Граница

Не является отдельным экраном или монолитной админкой. Временный preview-route не
становится production-источником главной: финальная страница собирается автономным
T123 и после регистрации принадлежит модулю публичного сайта.

## Источники истины

Дочерние карточки, `docs/APPLICATION_PLATFORM.md`, `docs/knowledge-base/PRODUCTS.md`.

Технические файлы, routes, таблицы, migrations и программные символы не
перечисляются вручную в карточке: они подставляются из generated inventory.
