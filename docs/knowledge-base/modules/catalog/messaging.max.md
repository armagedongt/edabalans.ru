# MAX: старт и атрибуция

MAX подключён как второй канал общей системы сообщений. Первый вход сохраняет
пользователя и источник, затем выдаёт персональную платформенную ссылку на
веб-интенсив. Проверка подписки, медиа и рассылки в этот модуль не входят.

Подробный канонический контракт: `docs/knowledge-base/modules/max/START_AND_ATTRIBUTION.md`.
