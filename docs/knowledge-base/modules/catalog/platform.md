# Основа платформы

Общие данные и сервисы, на которых работают продукты, админки и мессенджеры.

## Функции

- открывать политику из общего уведомления cookie через постоянный публичный
  вход `похудение-это-есть.рф/legal/privacy`;

- единый клиент и его внешние идентификаторы;
- общие коммерческие, авторизационные и контентные сервисы;
- единый публичный и приватный подвал через `site-footer.js`: фон страницы
  продолжается в подвале, разделитель совпадает с шириной основного текстового
  блока, его концы затухают, мягкая тень направлена вниз. Кегль строк одинаковый.
  На широком поле слева реквизиты, неразрывная пара ИНН с офертой и политика;
  справа контакты и запрет копирования. На узком поле реквизиты и ИНН с офертой
  идут сверху, запрет копирования — перед контактами, политика — после них.
  Приватный вариант сохраняет собственные поля и дисклеймер. Две компоновки
  переключаются по доступной ширине подвала с учётом бокового меню ЛК.
  Контакты в обоих режимах — две текстовые строки без логотипов:
  «Читать мой канал: Telegram / MAX» и «Написать мне лично: Telegram / MAX»;
  канал и личная связь имеют отдельные ссылки. Страницы используют один компонент.
- единое уведомление о cookie через `site-cookie-notice.js`: публичные страницы
  подключают один общий runtime, а принятие сохраняется на год для корневого
  домена и его субдоменов; ЛК, приложения и юридические страницы его не подключают.
  Все разделы одного host используют область `/`: отдельного согласия для
  `/blog` нет. Флаг уведомления не является сессией кабинета, подпиской на канал
  или правом на материалы. Карта cookie и границы аналитики — в
  [доменном runbook](../../../DOMAIN_CUTOVER_RUNBOOK.md#cookie-после-переноса-разделов-в-пути).
- общий контракт загрузки медиа: первый экран помечается явно, изображения и
  iframe ниже него получают lazy load в разметке или общем renderer.
- общий технический стандарт приложений курсов: минимальная первая отрисовка,
  отложенная загрузка текстов, кеширование и навигация без повторного frontend-входа.
- единый favicon бренда с розовым мозгом в чёрном контуре на прозрачном фоне для
  действующего сайта и админки; браузер или устройство само применяет квадратную
  либо круглую маску. С 18.10.2026 PNG для маленьких значков — 192×192 (37 КБ),
  ICO содержит размеры 16/32/48/64 (14 КБ); версия мозга без контура — 192×192
  (36 КБ), включая совместимый путь `homepage-preview/favicon-no-outline.png`.
  Рисунок и прозрачность сохранены; это уменьшенные версии, не сжатие без потерь
  относительно больших оригиналов. Исходники сохранены вне публичного mount:
  `/srv/edabalans-public/reviews-manifests/brand-icons-20261018/`, локальная копия —
  `D:\Codex\private\brand-icon-optimization-20261018`. URL и размеры показа сохранены.

Общие внутренние ссылки и локальные вложения сохраняют origin открытой страницы.
Сохранённые абсолютные адреса совместимо приводятся к путям без изменения истории
контента; внешние сообщения и SEO используют настройки. Подробный договор и
повторная смена домена — [доменный runbook](../../../DOMAIN_CUTOVER_RUNBOOK.md#два-домена-что-общее-что-независимо).

## Граница

Не включает пользовательские сценарии отдельных продуктов и Telegram. Тема
страницы задаёт переменные поверхности и контраста общего подвала.

## Источники истины

`ARCHITECTURE.md`, `docs/knowledge-base/COURSE_APPLICATION_STANDARD.md`, PostgreSQL,
backend config и дочерние карточки.

Технические файлы, routes, таблицы, migrations и программные символы не
перечисляются вручную в карточке: они подставляются из generated inventory.
