# Административные поверхности

Область независимых защищённых инструментов владельца и технического персонала.

## Функции

- давать единый вход и каталог маленьких админок;
- сохранять узкий UX каждого инструмента;

## Граница

Не превращается в одну монолитную админку со всей логикой проекта.

## Источники истины

`docs/ADMIN_ARCHITECTURE.md` и дочерние карточки.

Технические файлы, routes, таблицы, migrations и программные символы не
перечисляются вручную в карточке: они подставляются из generated inventory.
