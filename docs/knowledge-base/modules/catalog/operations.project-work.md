# Активная работа и документация разработки

Хранит временные research, spec, решения и checkpoints крупных изменений.

## Функции

- передавать согласованный контекст между чатами;
- архивировать результат после переноса устойчивых фактов в канонические источники;

## Граница

`work/` не является backlog, Wiki-БД или владельцем текущего production-факта.

## Источники истины

`work/`, `docs/AI_DEVELOPMENT_WORKFLOW.md`, `docs/CHAT_WORKSTREAMS.md`.

Технические файлы, routes, таблицы, migrations и программные символы не
перечисляются вручную в карточке: они подставляются из generated inventory.
