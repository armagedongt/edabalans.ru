# Telegram-лотерея

Будущий самостоятельный Telegram-процесс участия и определения результата.

## Функции

- принять отдельный вход кампании;
- выдать проверяемый результат и перейти в следующий модуль;

## Граница

Логика, данные и тексты не реализуются до отдельной задачи владельца.

## Источники истины

Явный Telegram backlog и будущий утверждённый module document.

Технические файлы, routes, таблицы, migrations и программные символы не
перечисляются вручную в карточке: они подставляются из generated inventory.
