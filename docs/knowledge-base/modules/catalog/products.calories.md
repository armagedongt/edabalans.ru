# Калорийный курс

Отдельный продуктовый runtime Калорийного курса. Использует существующий личный
кабинет и визуальную оболочку Мастер-класса, но имеет собственную структуру,
материалы, прогресс и право `ACCESS_CALORIES`.

## Функции

- показывать пять редактируемых этапов и живое количество шагов внутри них;
- хранить завершение материалов, задания и этапа;
- открывать следующий этап сразу после завершения текущего, без календарного
  таймера;
- публиковать Markdown-материалы по стабильному `step.id` с историей версий;
- записывать идемпотентные события прохождения, не отправляя сообщения сам;
- открываться из единственного кабинета Tilda без второго логина.
- оставаться закрытым до публикации всех видимых статей и отдельного включения
  готовности запуска в редакторе структуры.

## Граница

Модуль не владеет формулами калькулятора метаболизма, программой тренировок,
продажей консультации и Telegram-последовательностями. Старые видео и Tilda-
материалы являются редакционной фактурой, а не активным runtime.

## Источники истины

- active `managed_document_versions` с ключом `calories` — структура;
- `content_items`/`content_item_versions` источника
  `calories-course-materials` — опубликованные статьи;
- `content/calories/course/course.json` — seed и локальный fallback;
- `course_stage_progress`, `course_step_progress`, `course_events` с
  `course_code = calories` — прохождение;
- [исполняемый контракт](../calories/COURSE_RUNTIME.md).

Редакционные карты до публикации лежат в `work/calorie-course-rebuild/`; они не
заменяют runtime и не являются каноническими пользовательскими статьями.
