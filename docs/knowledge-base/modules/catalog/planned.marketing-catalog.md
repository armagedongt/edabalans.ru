# Каталог маркетинга и рекламы

Будущий отдельный каталог рекламных площадок, кабинетов, кампаний и креативов.

## Функции

- показать, где размещалась реклама и какие сущности связаны между собой;
- хранить безопасные ссылки, названия и статусы без паролей, токенов и ключей;

## Граница

Модуль не создаёт рекламные кабинеты, не запускает кампании и не хранит секреты.
До отдельной задачи владельца технической реализации нет.

## Источники истины

Явная короткая запись `Q-004` в `docs/plans/QUICK_NOTES.md`; после отдельного
проектирования — утверждённый документ этого модуля.

Технические файлы, routes, таблицы, migrations и программные символы не
перечисляются вручную в карточке: они подставляются из generated inventory.
