# Метаболизм и калории

Клиентское приложение для данных и материалов о метаболизме и калориях.

## Функции

- загружать и сохранять состояние пользователя;
- работать через общую Tilda-оболочку и API;

## Граница

Будущие курсы о калориях не копируют автоматически сценарии мастер-класса.
Калорийный курс может открыть это же приложение встроенным шагом. Доступ к
инструменту разрешён как по ресурсу `metabolism`, так и по действующему
`ACCESS_CALORIES`; формула и состояние при этом остаются единственными.

## Источники истины

`docs/APPLICATION_PLATFORM.md`, backend runtime и `legacy/google/metabolism/`.

Технические файлы, routes, таблицы, migrations и программные символы не
перечисляются вручную в карточке: они подставляются из generated inventory.
