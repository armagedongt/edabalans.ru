# Telegram-тесты и опросы

Будущая переиспользуемая возможность проводить самостоятельные тесты и опросы.

## Функции

- собирать ответы и рассчитывать согласованный результат;
- передавать результат, tags/variables и следующий module transition;

## Граница

Каждый тест не становится модулем автоматически; отдельный module нужен при собственном жизненном цикле.

## Источники истины

Явный Telegram backlog и будущие канонические требования.

Технические файлы, routes, таблицы, migrations и программные символы не
перечисляются вручную в карточке: они подставляются из generated inventory.
