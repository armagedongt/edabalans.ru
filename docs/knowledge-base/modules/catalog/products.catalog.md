# Каталог продуктов и тарифов

Полный контракт: [`../../PRODUCT_CATALOG.md`](../../PRODUCT_CATALOG.md).

Каталог не хранит цены и не изменяет технические права доступа. Он отдаёт
публичные формулировки в ЛК, допродажи и ценовой блок по стабильным кодам.

## Рабочий маршрут

Названия, короткие описания и редакционный контекст менять по
[контракту каталога](../../PRODUCT_CATALOG.md) через существующий редактор/API.
Текст готовит `platform.content` через Писаря; сохранённая версия каталога
поставляет формулировки потребителям. Цена и право доступа — не поля этого
редакционного маршрута: их меняет `platform.commerce`.

## Функции

- хранить утверждённые владельцем названия и дескрипшны версиями;
- разрешать утверждённый дескрипшн без обязательного начала со слова «Как»;
- не допускать локальной переформулировки одного продукта на разных поверхностях.
