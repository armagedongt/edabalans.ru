# Анкеты мастер-класса

Сохраняет входные, итоговые и служебные ответы участника как часть программы.

## Функции

- показывать анкеты в общем списке материалов;
- сохранять каждый ответ и завершение попытки;
- при отправке анкеты одной серверной транзакцией сохранять её статус и отмечать
  соответствующий открытый шаг курса завершённым; повторная отправка идемпотентна,
  а анкета вне открытого шага не обходит порядок программы;
- отдельно сохранять пол, возраст, рост и вес входной анкеты как проверенные
  структурированные ответы; оба интерфейса используют общий компонент полей;
- после нажатия кнопки сразу показывать следующий материал, но не открывать
  чек-лист дня до завершения фонового сохранения; при рассинхронизации обновлять
  серверный прогресс и возвращать к реально незавершённому материалу без показа
  внутреннего кода ошибки;
- по кнопке начальной анкеты ставить в очередь существующую пару сообщений с
  базовыми данными участника, полной анкетой и просьбой переслать их Сергею;
- по явной кнопке ставить доставку полной копии итогового саморевью самому
  участнику;

## Граница

Не владеет дальнейшей ручной консультацией или исполнением доставки в Telegram/MAX.
Сергею ответы автоматически не отправляет: они остаются в CRM, а участник при
желании пересылает полученную копию лично.

## Источники истины

Вопросы, пояснения и подписи кнопок — `content/masterclass/editorial/materials/`
с публикацией определения формы в активную структуру курса. Runtime tables
сохраняют ответы по прежним кодам; кодовые наборы вопросов — fallback старых
редакций. Публикация MD не отправляет анкеты участникам сама по себе.
Структурированные базовые поля принадлежат `questionnaire_person_service.py`,
не свободному тексту MD. Их прежние свободные ответы не преобразуются. Калькулятор
читает эти значения только для своего пользователя и заполняет ими пустые поля;
подробный договор: [калькулятор](../metabolism/APP_RUNTIME.md).

Технические файлы, routes, таблицы, migrations и программные символы не
перечисляются вручную в карточке: они подставляются из generated inventory.
