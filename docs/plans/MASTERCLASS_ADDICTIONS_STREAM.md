# Полный «Путеводитель по зависимостям» для будущего стрима

Сергей попросил сохранить полную текущую версию перед возможным сокращением для мастер-класса: большой материал пригодится для стрима.

Снимок: [полный текст](../../content/masterclass/archive/day18-20260925/addictions-guide-full.md), [происхождение и проверка](../../content/masterclass/archive/day18-20260925/README.md).

Сохранены большой разбор систем мозга, толерантности и цикла зависимости, развёрнутые примеры, иллюстрации и источники. При подготовке стрима отдельно выбрать содержание, проверить биологические объяснения и подготовить медиа. Сам стрим сейчас не создаётся; формат и дата не назначены.

Сокращение двух материалов 18-го дня обсуждается отдельно. Наличие снимка не означает согласования новой короткой редакции.
