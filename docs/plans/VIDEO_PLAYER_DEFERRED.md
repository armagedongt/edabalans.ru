# Доработки модульного видеоплеера

## Текущее состояние

В `backend/app/static/video-player-development/` сохранены две автономные версии плеера:

- режим вовлечения: автозапуск, статистика, ускоренный прогресс, без оглавления;
- стандартный режим: ручной запуск, обычный прогресс, оглавление, без статистики.

Это самостоятельная разработка для последующей интеграции. Она не заменяет автоматически действующие production-файлы `video-player.css` и `video-player.js`.

## Запланированные доработки

- Подключить реальный серверный endpoint аналитики и согласовать формат хранения событий.
- Подготовить отдельные видеофайлы разных разрешений и вернуть доступный пользователю выбор качества.
- Проверить оба режима на целевых страницах Tilda и внутри runtime Мастер-класса.
- Провести браузерную проверку на актуальных Chrome, Safari/iOS и Android.
- Решить, должна ли автономная версия заменить текущие `video-player.css` и `video-player.js` либо остаться отдельным встраиваемым вариантом.
- При интеграции убрать дублирование CSS/JS между двумя HTML-файлами, сохранив две готовые конфигурации режимов.
