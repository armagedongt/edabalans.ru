Статус: `superseded_by_implementation`

Дата фиксации: 23.08.2026.

## Что уже собрано

- Тёплый шаблон утверждён владельцем.
- В прототипе создана программа на 21 день.
- Реальные сохранённые HTML-материалы импортированы из `D:\Мастер-класс`; изображения пока используются по исходным URL Tilda.
- Для отсутствующих материалов созданы заметные карточки `Нужна редактура`.
- Подключены полноэкранные прототипы анкеты, DQS, рецептов и саморевью.

- Введены локальные структуры прогресса `steps`, `popupSeen`, `events`.
- Начата реализация строгого последовательного прохождения: следующий материал закрыт до завершения предыдущего; задание дня должно открываться только после всех обязательных материалов.
- В дни 1, 15, 17, 19 и 21 добавлены конфигурации выделенных дополнительных материалов с предложениями. Для дней 15 и 17 предусмотрен предварительный popup о завтрашних рецептах.

## Результат продолжения

Основной файл: `backend/app/static/masterclass-first-days-preview.html`.

Выполнено:

1. Статьи, анкета, приложения и предложения проходят в строгой очереди.
2. Простое открытие статьи не завершает её; завершение происходит по нижней
   кнопке «Прочитано».
3. Задание заблокировано до всех обязательных материалов дня.
4. Popup дней 15 и 17 можно закрыть, но он не засчитывает выделенный материал.
5. Добавлен локальный контракт `edabalans:masterclass-event` и hook
   `EdabalansMasterclassEventSink` для передачи событий серверной оболочке.
6. Сервер понимает новые placement дней 15, 17, 19 и 21; старые placement
   сохранены для обратной совместимости.
7. Для локального предпросмотра создан отдельный красивый экран предложений без
   клиентского источника цен: в production состав и цены получает сервер.
8. Канонические документы обновлены под рецепты дней 16 и 18 и точки предложений
   дней 1, 15, 17, 19 и 21.
9. JavaScript прошёл syntax-check. Backend-тесты: `19 passed` для пути
   Мастер-класса и `12 passed` для CRM/auth при раздельном запуске.
10. Во встроенном браузере подтверждено: оглавление содержит все 21 день, второй
    материал закрыт до завершения первого, нижняя кнопка открывает следующий, а
    возврат из незавершённой статьи не засчитывает её.

## Важное ограничение

Фактическую отправку сообщений Telegram/MAX не включать. Сайт пока только создаёт согласованные события. Исполняемый граф Telegram-модуля и тексты сообщений должны быть отдельно утверждены; `POSTPURCHASE_DISPATCH_ENABLED` остаётся выключенным.

Логика открытия следующего дня по-прежнему использует тестовые 20 часов. Идея открытия в 06:00 по местному времени обсуждена, но владелец просил пока её не применять.

## Продолжение после точки сохранения

- Добавлены серверные таблицы прогресса migration `20260823_0017`.
- Реализованы защищённые API всей 21-дневной программы, строгая очередь шагов,

- Мастер-класс подключается одной короткой вставкой T123 и использует общий вход
  приложений с проверкой `ACCESS_MASTERCLASS`.
- Статьи выдаются только после проверки сессии и доступа; прогресс не зависит от
  `localStorage` участника.
- Точки предложений получают серверные placement-token и остаются обязательными
  шагами, даже если окно было закрыто.
- Исходящие события для будущего Telegram-модуля фиксируются в
  `masterclass_events`; реальная отправка не включена.
- Каноническое описание актуального поведения перенесено в
  `docs/knowledge-base/modules/masterclass/COURSE_RUNTIME.md`.
