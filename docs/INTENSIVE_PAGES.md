# Бесплатный интенсив «Последнее похудение»

Статус: `current`

Четыре рабочие страницы доступны на `app.edabalans.ru` по адресам
`/intensive/day-1` — `/intensive/day-4`. Страницы закрыты от поисковой индексации и
оформлены как простые текстовые статьи без отдельной дизайн-системы.

На каждой странице есть одна кнопка `Edit`. Она открывает ту же статью в режиме
правки. Если административная сессия ещё не открыта, используется существующий вход
`/admin`; отдельного логина для интенсива нет. В режиме правки эта же кнопка
становится `Save`.

Сохранённый HTML проходит серверную очистку, записывается в таблицу
`intensive_pages` и сразу становится общей публичной версией. Статические файлы в
`backend/app/static/intensive/` служат начальным содержимым, пока страница ни разу
не сохранена. Номер версии защищает от незаметной перезаписи, если одну страницу
одновременно открыли в двух редакторах.

API:

- `GET /api/intensive/{day_code}` — получить общую версию страницы;
- `GET /admin/api/intensive/{day_code}` — открыть её для редактирования;
- `PUT /admin/api/intensive/{day_code}` — сохранить после проверки администратора.
