# Бесплатный интенсив «Последнее похудение»

Статус: `current`

Четыре временные страницы доступны на `app.edabalans.ru` по адресам
`/intensive/day-1` — `/intensive/day-4`. Исходники находятся в
`backend/app/static/intensive/`; страницы закрыты от поисковой индексации.

Параметр `?edit=1` включает простой режим ручной правки прямо на странице. Кнопка
«Сохранить черновик» сохраняет изменённую HTML-разметку только в `localStorage`
текущего браузера. Публичную версию для других посетителей это не меняет. После
утверждения черновик переносится в файлы проекта отдельной правкой и обычным
деплоем.

Режим временный: отдельной CMS, таблицы PostgreSQL и административного API для него
нет.
