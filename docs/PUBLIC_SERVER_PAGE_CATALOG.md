# Каталог внешних серверных страниц Eda Balance

## Как читать каталог

Это карта браузерных страниц, которые отдаёт сервер Eda Balance. Она не включает
API, JavaScript, CSS, картинки, admin-интерфейсы, webhook-и, health-checks и
внутренние фрагменты, подключаемые внутрь других страниц. Реальные маршруты остаются
источником истины: `backend/app/app_routes.py`, `account_auth_routes.py`,
`robokassa_routes.py` и `blog_routes.py`.

На 12.09.2026 в сервере **42 маршрутных экранных записи** по правилу этого
каталога: **28 пользовательских** и **14 preview, test или эксплуатационных**.
Дни интенсива, пять юридических документов и разные результаты оплаты считаются
отдельными экранными состояниями; `/training` и `/recipe-calculator` не считаются
отдельно, потому что это aliases уже перечисленных страниц. API, assets и
plain-text-фрагменты в число не входят. Несколько preview-адресов могут показывать
визуально тот же экран, что и рабочий маршрут, но остаются отдельными маршрутами,
пока существуют в сервере.

## 1. Основные точки входа и продажи

| Адрес | Роль | Состояние | Примечание |
| --- | --- | --- | --- |
| `/preview/homepage-release-candidate?embed=tilda` | исходник актуальной главной для T123 | основной источник главной | Страница визуально показывается внутри Tilda; это не самостоятельная новая главная на корне домена. Пока Сергей вносит последние тексты и голосовые, именно этот адрес остаётся единственной точкой правок. |
| `/pay` | индивидуальная оплата | рабочая | Форма свободной суммы; ведёт в Robokassa. |
| `/intensive`, `/intensive/menu` | вход в бесплатный интенсив | рабочая | Восстанавливает персональную intensive-сессию при наличии личной ссылки. |
| `/intensive/day-1` … `/intensive/day-4` | четыре части интенсива | рабочие | Без личной сессии доступны как публичные страницы; с сессией проверяется открытие дня. |
| `/preview/direct-intensive` | посадочная для Direct, вариант `instead` | тестовая/кампанийная | Нужна, пока используется текущая рекламная ветка. |
| `/preview/direct-intensive-a1` | альтернативная посадочная Direct | эксперимент | Не делать основной без отдельного решения по кампании. |

## Поведение кабинета без доступов

Это фактическое состояние на 12.09.2026, а не предложение нового дизайна.

| Кто открыл `/lk` | Что видит | Что может сделать |
| --- | --- | --- |
| Человек без сессии и без credentials | форму входа / регистрации | ввести email; сервер отправит текущий onboarding email с выбором Telegram/MAX |
| Новый зарегистрированный человек без покупок | фиксированную плашку «Пока доступы не подключены» | увидеть единый текст с двумя кнопками Telegram/MAX; закрытые карточки и «Приобрести» остаются ниже |
| Исторический человек только с группой `Добро пожаловать` | ту же фиксированную плашку | написать Сергею; карточки остаются закрытыми до ручного решения |
| Исторический человек с конфликтом/непроверенной покупкой | ту же фиксированную плашку | написать Сергею; права и покупка автоматически не выдаются до ручного решения |
| Человек с подтверждёнными правами | обычный каталог ЛК | открыть только купленные и уже готовые материалы; при необходимости сначала принять юридические документы |

Видимый сценарий один: «Пока доступы не подключены». Внутренняя причина остаётся
только в `review_status` для поддержки; у исторического спорного аккаунта она всё
же сохраняет закрытие карточек, чтобы не допустить случайную повторную покупку до
ручной проверки.

## Что не удалять и что можно подготовить к уборке

Ни одну страницу сейчас нельзя безопасно удалить только потому, что она называется
`preview`: часть из них вызывается Tilda, тестами, рекламными материалами или
операционной проверкой Robokassa. Архивный контур — это маркировка и изоляция, а не
удаление: сначала требуется убрать все реальные ссылки, изменить тесты и только затем
принимать отдельное решение об удалении маршрута и файла.

### Первая очередь на решение владельца

1. `/preview/homepage-mobile` уже помечена архивной. При будущей уборке сначала
   перенести/заменить все реальные ссылки; до этого страницу не удалять.
2. Выбрать: сохранять ли эксперимент `/preview/direct-intensive-a1` как вариант
   кампании либо убирать его после завершения сравнения.
3. `/weather` сохраняется отдельной изолированной страницей и не относится к
   архиву главной.
4. После стабилизации сделать redirect-ы `training → strength` и
   `recipe-calculator → recipes`, а не оставлять два одинаковых адреса.
5. Отдельно решить судьбу изолированных preview-блоков отзывов, recognition и
   каталога приложений: оставить как библиотеку дизайна или архивировать.

## Следующий порядок работы по главной

После этой инвентаризации остаются согласованные ранее направления:

1. привести главную и её T123-встраивание к одному каноническому источнику;
2. после последних редакторских правок Сергея выдать короткий T123-загрузчик для
   этой же канонической страницы; большой повторный аудит не является условием;
3. расширять и смотреть first-party аналитику главной отдельно от Директа;
4. сохранять архивные preview/aliases до отдельного решения об удалении.

Этот каталог не описывает внутренние страницы ЛК, админку, API и внешние Tilda
страницы: для них нужны отдельные карты, чтобы не смешивать пользовательские экраны
с техническими маршрутами.
