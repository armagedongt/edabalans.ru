# Калибровка голоса v1

Статус: `pending_owner_review`.

Паспорт считается рабочим seed уже сейчас, но не подтверждённым владельцем. Для
приёмки нужны пять **новых** задач, которые не входят в банк эталонов:

1. Познавательный Telegram-пост по сырой заметке, без продажи.
2. Познавательный пост с естественным мостом В Мастер-класс.
3. Личный или наблюдательный пост с практическим выводом.
4. Сообщение для конкретного места в цепочке бота с прямым CTA.
5. Длинная самостоятельная статья с фактурой, возражениями и оговорками.

Сергей для каждой задачи даёт только факты/заметку, назначение и обязательный CTA,
если он уже известен. Выбирать хук, эталоны и композицию заранее не нужно.

## Оценка

Каждый готовый текст оценивается по пяти вопросам:

- «я бы так построил»;
- естественность языка;
- боль, эмоция и понятное «зачем этот текст»;
- выполнение познавательной или продающей задачи;
- объём необходимой правки.

Общая оценка: `0` — нейрослоп; `1` — полезна только отдельная зацепка; `2` — нужна
большая перепись; `3` — мой текст после обычной редакторской правки; `4` — почти
готов к публикации.

Порог v1: минимум четыре текста из пяти получают `3` или `4`; минимум четыре дают
полезную зацепку; выдуманный факт автоматически проваливает задачу. Существенные
правки сохраняются в correction memory. После одного исправляющего прохода серия
останавливается и проблемные места фиксируются без кольца новых прогонов.
