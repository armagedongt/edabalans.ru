# Маршрутизатор вставок статьи
Этот документ помогает писателю выбрать человекочитаемую вставку. Он не владеет
кодом, данными или внешним видом продуктовых компонентов.

## Универсальная плашка

Переход 16.09.2026: для новых обычных MD использовать `[!NOTE]`, для
спойлера `[!NOTE]-`, для кнопок роль `[!LINK]`. Полный контракт и готовность
публикационных маршрутов — `docs/knowledge-base/MARKDOWN_MATERIAL_TRANSFER.md`.
Ниже `:::note` сохранён как legacy-совместимость, не новая авторская инструкция.
Новые соответствия пока только в локальном прототипе, не в серверном renderer.

Для короткого важного ориентира используйте закрытую Markdown-directive:

```text
:::note [Ориентир]
Текст плашки. Между абзацами можно оставить пустую строку.
:::
```

Заголовок в квадратных скобках необязателен; без него используется «Важно».

## Компоненты Мастер-класса DQS

Владелец кода, данных и оформления — `products.masterclass.course`, каталог
`content/masterclass/components/`.

- «Вставь слайдер с этими картинками» — `slider(...)`; внутри от 2 до 20 ссылок,
  по одной HTTPS- или локальной ссылке на строку.
- «Вставь таблицу DQS» — `dqs_score_table(...)`; допустимы `full`, `plants`,
  `protein`, `fats`, `side-dishes`, `unhealthy`.
- «Спрячь большую справку под спойлер» — `spoiler(...)`; первая строка внутри
  вызова становится заголовком, остальные непустые строки — абзацами раскрываемой
  части. Внутри строк разрешены обычные Markdown-выделения и ссылки.

Вызов ставится отдельным блоком. Не копируйте JavaScript, CSS или HTML компонента
в статью. Не придумывайте новые имена: неизвестный вызов публикация отклонит.

## Публичный блог

Писатель возвращает чистый Markdown без продуктовой вставки. Интегратор блога
после выбора назначения добавляет ровно один закрытый вызов:

```text
blog_cta(
intensive
)
```

Разрешённые ключи: `intensive`, `masterclass`, `telegram`. Код, тексты, ссылки и
оформление этих компонентов принадлежат `platform.blog` и его читаемым продуктовым
источникам; писатель не копирует их в материал и не вставляет произвольный HTML.
