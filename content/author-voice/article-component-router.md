# Маршрутизатор вставок статьи
Статус: `current`. Владелец: `platform.content`.

Этот документ помогает писателю выбрать человекочитаемую вставку. Он не владеет
кодом, данными или внешним видом продуктовых компонентов.

## Универсальная плашка

Для короткого важного ориентира использовать существующий Obsidian NOTE:

```text
> [!NOTE]
> Текст плашки.
>
> Второй абзац.
```

Автоматическое «Важно», иконка и декоративный заголовок не добавляются.
Legacy `:::note` использует ту же поверхность только для совместимости.
Действующие границы и поддержанное содержимое — в
[общем каталоге](../article-components/README.md) и
[стандарте статьи](../../docs/knowledge-base/ARTICLE_STANDARD.md).
Расширенный [Markdown-контракт](../../docs/knowledge-base/MARKDOWN_MATERIAL_TRANSFER.md)
остаётся draft локального прототипа: NOTE-minus, LINK и copy не обещать в
production, пока адаптер конкретной поверхности не подключён и не проверен.

## Компоненты Мастер-класса DQS

Владелец кода, данных и оформления — `products.masterclass.course`, каталог
`content/masterclass/components/`.

- «Вставь слайдер с этими картинками» — `slider(...)`; внутри от 2 до 20 ссылок,
  по одной HTTPS- или локальной ссылке на строку.
- «Вставь таблицу DQS» — `dqs_score_table(...)`; допустимы `full`, `plants`,
  `protein`, `fats`, `side-dishes`, `unhealthy`.
- «Спрячь большую справку под спойлер» — `spoiler(...)`; первая строка внутри
  вызова становится заголовком, остальные непустые строки — абзацами раскрываемой
  части. Внутри строк разрешены обычные Markdown-выделения и ссылки.

Вызов ставится отдельным блоком. Не копируйте JavaScript, CSS или HTML компонента
в статью. Не придумывайте новые имена: неизвестный вызов публикация отклонит.

## Ссылка на другой курс — согласованный маршрут, ещё не реализован

Писатель использует всю фразу мини-курс «Каноническое название» как одну
ссылку на описание продукта. Формат адреса, общий pop-up, источник описания
и состояния двух кнопок принадлежат
[§17 структурного контракта](../../docs/knowledge-base/modules/masterclass/COURSE_STRUCTURE_CONTRACT.md#17-ссылки-на-другие-курсы-внутри-материалов).
Не копировать описание/HTML окна в статью и не подменять этот маршрут ссылкой
на приложение силовых тренировок. До реализации обработчика ссылка является
редакционной заготовкой, а не работающим компонентом production.

## Публичный блог

Писатель возвращает чистый Markdown без продуктовой вставки. Интегратор блога
после выбора назначения добавляет ровно один закрытый вызов:

```text
blog_cta(
intensive
)
```

Разрешённые ключи: `intensive`, `masterclass`, `telegram`. Код, тексты, ссылки и
оформление этих компонентов принадлежат `platform.blog` и его читаемым продуктовым
источникам; писатель не копирует их в материал и не вставляет произвольный HTML.
