# Принятые образцы компонентов

## Четыре кнопки контактов

`four-contact-buttons.html` — сохранённый третий вариант из обсуждения21.10.2026.
Сергей одобрил стиль отдельных светлых кнопок: круглые логотипы Telegram/MAX,
название мессенджера и подпись назначения. Образец для других блоков, не для подвала.
В подвале выбран компактный текст: две строки «Читать мой канал: Telegram / MAX»
и «Написать мне лично: Telegram / MAX».

Файл автономный, с вложенными исходными логотипами. Адреса перед применением
проверять через `docs/knowledge-base/PROJECT_IDENTITY.md` и владельцев настроек.
