# Реестр библиотеки смысловых источников

Статус: `archived — исходный инвентарь первой партии`

Актуальный контракт: [`docs/KNOWLEDGE_LIBRARY.md`](../../docs/KNOWLEDGE_LIBRARY.md)

Исполняемый seed: [`server-source-manifest.json`](server-source-manifest.json)

Этот файл сохранён как проверяемая история первого разбора. Он больше не является
редактируемым реестром и не создаёт вторую библиотеку: актуальные карточки,
версии, связи и вопросы живут в серверном контуре `platform.knowledge`.

## Назначение

Здесь одна строка на смысловую единицу, а не на каждую физическую копию. Реестр
не содержит полный текст материала: он показывает, где его единственный дом и
как он связан с другими единицами.

## Поля реестра

| Поле | Что означает |
| --- | --- |
| `id` | Стабильный понятный ключ, не меняется при переименовании файла. |
| `kind` | `video`, `audio`, `stream`, `lesson-companion`, `commercial`, `review`, `business-card`, `external-reference`, `insight`. |
| `title` | Читаемое название источника/единицы. |
| `role` | `canonical`, `source`, `derived`, `archive`. |
| `status` | `current`, `legacy`, `reference`, `unverified`, `superseded`, `decomposed_and_retired`. |
| `home` | Единственный путь к содержанию: файл, runtime-ключ, ID поста или внешний источник. |
| `origin` | Оригинал: локальный путь, постоянный media ID, URL или документ. |
| `links` | `derived_from`, `excerpt_from`, `materialized_into`, `version_of`, `supersedes`, `duplicate_of`, `published_as`. |
| `coverage` | Весь источник или интервалы таймкодов. |
| `reviewed` | Дата последней содержательной сверки. |

## Требования к строке

1. `home` всегда один. Если смысла нет в библиотеке, а он живёт в продукте или
   плане, указывается именно этот конечный материал.
2. Полная расшифровка или карта может быть дополнительной связью, но не вторым
   `home` той же идеи.
3. Для `decomposed_and_retired` перечисляются все сохранённые части и явно
   пишется судьба отброшенного остатка.
4. Неизвестная связь остаётся `unverified`, а не додумывается.
5. Точные технические дубли не получают вторую строку; их перечисляют в `links`
   основной строки до подтверждённого удаления.
