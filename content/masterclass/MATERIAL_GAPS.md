# Зафиксированные решения и отложенные материалы

Статус: `current / intake decisions recorded`
Обновлено: 28.08.2026
Основание: сверка `PROGRAM_INVENTORY.md` с переданными материалами.

Для восстановления общей логики достаточно текущей программы Tilda и полученных
текстов. Дополнительные исходные материалы перед новой авторской структурой не
требуются.

## Решения владельца

1. **«Взгляд в будущее» и «Примеры дневников».** Сохранить по смыслу, но не
   считать обязательными отдельными разделами. Поставить в подходящее место после
   получения новой структуры.
2. **Задание №16 после конструктора питания.** Попробовать что-либо из
   предложенного конструктора. Подробный самостоятельный материал не нужен.
3. **Видео «Вредная еда».** Оставить и позднее перевести в текст. В текущем
   архиве найдено название страницы, но не отдельное оглавление с таймингами;
   повторно запрашивать его сейчас не нужно.
4. **«Дополнительные материалы».** Оставить небольшой необязательный блок из
   нескольких постов Telegram-канала. Его точный состав не важен для структуры.
5. **Финальный материал о периодизации.** Оставить; позднее он, вероятно, будет
   оформлен текстом. Подробности сейчас не требуются.
6. **Нумерация заданий.** Решить после перестройки программы; исторические
   пропуски №7 и №14 сейчас ничего не блокируют.

## Материалы, к которым можно вернуться только перед финальной редактурой

- текстовая версия видео «Вредная еда»;
- видео «Что за система DQS» — текстовая версия DQS уже имеет приоритет;
- видео о голоде и сытости;
- видео «Пять правил сокращения сладкого»;
- два аудио о чит-милах;
- видео «Конструктор питания»;
- голосовое дополнение к саморевью;
- используемая часть финального стрима.

После утверждения новой структуры нужно будет выбрать для каждого действительно
используемого видео один из вариантов: полный транскрипт или короткий авторский
пересказ. Сейчас ничего из этого досылать не нужно.

## Не блокирует работу

- старое описание DQS, заменённое версией от 11.08.2026;
- исключённый владельцем стрим с ответами на вопросы;
- точный старый текст страниц «Мои контакты» и «Программа Мастер-класса» — их
  можно собрать заново после утверждения структуры;
- таблица DQS для печати, если серверное приложение становится основным способом;
- реальные медиафайлы и изображения — сейчас достаточно реестра и описаний.

## Следующий отдельный проход после технического запуска

Техническая программа уже собрана на 21 день и не ждёт новой перестройки для
запуска. Следующий проход — только наполнение: заменить короткие заглушки,
дослать выбранные расшифровки видео, проверить авторские формулировки и заполнить
восемь Telegram-сообщений в админке. Порядок дней, доступы, цены и серверные
триггеры при этом не переписываются без отдельного решения.
