# Задание №5: правило тарелки

Статус: `source_transcription`
Источник: текст владельца от 23.08.2026

1. С этого дня старайтесь собирать тарелки по правилу тарелки — по крайней мере тогда, когда для этого есть возможность. Это поможет вам лучше контролировать пропорции в питании, а Сергею — лучше различать всё на фотографиях.

2. Проверьте, что в дневнике для каждого дня заполнены дата, вес, шаги и тренировки, если они есть.
