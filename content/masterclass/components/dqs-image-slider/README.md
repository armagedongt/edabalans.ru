# Слайдер изображений DQS

Это один универсальный слайдер. В нём **нет картинок**: картинки всегда лежат прямо в статье, чтобы их можно было увидеть и заменить в Markdown без правки кода.

В статье слайдер записывается так:

```text
slider(
https://…/первая-картинка.png
https://…/вторая-картинка.png
)
```

Человеческая команда: «вставь слайдер с этими картинками», «добавь ещё картинку в слайдер домашних блюд» или «поставь слайдер после этого абзаца». Код для всех таких случаев один и тот же: `slider.css` и `slider.js`.

Runtime course-material API принимает от 2 до 20 безопасных HTTPS- или локальных
ссылок. Неизвестный параметр или незакрытый вызов блокируется до публикации.
Страница курса загружает `slider.css` и `slider.js` напрямую через публичный
course-assets route: файлы каталога являются runtime-источником, а не примером.
