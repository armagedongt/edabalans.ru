# Спойлер для подробной справки

Компонент используется, когда подробности нужны в статье, но мешают читать
основной текст подряд. Первая строка внутри вызова становится видимым заголовком,
остальные непустые строки — абзацами раскрывающейся части.

```text
spoiler(
Составы блюд и граммовки
**Овсянка:** хлопья — 50 г; банан — 70 г; мёд — 5 г.
)
```

Человеческая команда: «убери эти подробности под спойлер», «добавь граммовки в
раскрывающуюся справку». Произвольный HTML в статью добавлять не нужно.
