[Универсальный слайдер DQS](./dqs-image-slider/README.md) — один код без картинок; ссылки на картинки остаются прямо в статье внутри `slider(...)`.

## Раскрывающаяся справка

[Спойлер для подробностей](./article-spoiler/README.md) — один сворачиваемый блок

## Видео внутри статьи

`video(...)` принимает прямую HTTPS-ссылку на MP4 и короткий заголовок:

```md
video(
https://telegra.ph/file/c614abe3c7ffdfc43b93e.mp4
Поели — подвигались!
)
```

Используется существующий учебный `/apps/video-player.html`, без автозапуска.
Под плеером не добавляются подпись или ссылка. Произвольные iframe, HTML и
скрипты автора не разрешены. Вставка принадлежит `products.masterclass.course`;
общий sanitizer допускает только этот путь плеера с единственным параметром `src`.
