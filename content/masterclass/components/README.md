## Видео внутри статьи

`video(...)` принимает прямую HTTPS-ссылку на MP4 и короткий заголовок:

```md
video(
https://telegra.ph/file/c614abe3c7ffdfc43b93e.mp4
Поели — подвигались!
)
```

Используется существующий учебный `/apps/video-player.html`, без автозапуска.
Под плеером не добавляются подпись или ссылка. Произвольные iframe, HTML и
скрипты автора не разрешены. Вставка принадлежит `products.masterclass.course`;
общий sanitizer допускает только этот путь плеера с единственным параметром `src`.

## Голосовое внутри статьи

`audio(...)` принимает четыре строки: HTTPS-ссылку на MP3/OGG/M4A,
HTTPS-ссылку на аватарку WebP/JPG/PNG, имя автора и длительность `М:СС`.
Закрытый `/course-assets/masterclass/audio-player` использует оформление
голосового с главной страницы: аватарка, воспроизведение/пауза, перемотка и
скорости 1/1,5/2. Плеер занимает ширину статьи и не запускается автоматически.
Медиа загружается только при воспроизведении или перемотке. Отдельная ссылка
под голосовым не добавляется. Произвольный iframe по-прежнему запрещён.
Файлы владельца остаются вне Git, на существующем публичном медиахранилище;
опубликованные URL версионные и не перезаписываются.
