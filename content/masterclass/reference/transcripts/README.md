# Исходные транскрипты видео МК

Статус: `archived`
Дата переноса: 28.08.2026

Здесь лежат точные копии текстовых расшифровок из
`D:\Видео — проект\Каталог транскриптов`. Папка не подключена к runtime и
не публикуется ученикам автоматически. Она нужна, чтобы после очистки локального
диска остался полный исходный текст для будущих материалов, таймкодов и монтажа.

Текст «День 09 — эфир, ответы на вопросы, 1ч43м21с» подтверждён владельцем
29.08.2026. Файл с пометкой «предыдущая копия до сверки» — техническая страховка:
он почти совпадает с каноническим текстом, но не является отдельным источником и
подлежит удалению после ручной сверки.

Для текущего дня 3 каноническим видео остаётся «Вредная еда», 29:03. Два файла
с пометкой «58:59» — рабочие фрагменты, использованные при подготовке текстов
дня 3. Их связь с конкретной записью и её длительностью не подтверждена; это не
самостоятельные ролики и не части ролика, которые можно автоматически склеивать.
