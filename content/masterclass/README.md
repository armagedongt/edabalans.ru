# Материалы мастер-класса

Статус: `draft`
Владелец содержания: Сергей Воронцов
Проверено: 23.08.2026
Каноническая логика модуля: `../../docs/knowledge-base/modules/masterclass/README.md`

Этот каталог хранит тексты и структуру мастер-класса отдельно от программного
кода. До утверждения нового оглавления материалы не переставляются и не
редактируются как финальная версия.

## Каталоги

- `source-current/` — исходные страницы и тексты в порядке поступления;
- `course/` — машинная структура 20-дневной программы со стабильными ID шагов;
- `course/course.json` — единственная каноническая программа и атрибуция всех дней;
- `PROGRAM_DRAFT.md` — архивный указатель, не источник программы;
- `PROGRAM_SOURCE_MAP.md` — карта, из каких переданных текстов собирать каждый день;
- `PROGRAM_INVENTORY.md` — полная текущая программа и контроль полученных/неполных материалов;
- `MATERIAL_GAPS.md` — только значимые пробелы и вопросы владельцу, без требования дослать весь архив;
- будущие опубликованные версии материалов будут привязаны к ID из `course/course.json`;
- будущий `recipes/` — материалы серверного рецептурного модуля.

Тяжёлые видео, персональные анкеты участников и другие персональные данные в Git
не помещаются. Для видео здесь позднее будет только безопасный реестр файлов.
