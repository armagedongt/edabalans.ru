## Решения владельца, не менять молча

- Новый материал: один главный заголовок + h2; плавающее содержание штатное.
- Обычный `>` — цитата; NOTE — единая пока жёлтая плашка без иконки/заголовка;
  NOTE-minus — закрытый белый спойлер.
- Зачёркивание того же цвета; подсветка остаётся. Только отдельные копируемые
  блоки, кнопка внизу; не inline copy.
- `[x]` зелёный ✓, `[ ]` красный ×, не input и не прогресс ученика.
- LINK: stack слева по умолчанию / row / center; на телефоне row складывается.
- Обычная таблица desktop → карточки строк mobile; это прототип выбранного
  подхода, если сменить на scroll — согласовать именно UX, не создавать копию MD.
- Оригинальные DQS/анкеты/интенсив не менялись. Их кодовые компоненты отдельно.

## Твоя интеграция

Общую библиотеку подключать один раз, не переносить CSS каждой статье.
Согласовать общий root selector, токены темы, кнопки/размеры/состояния и
сохранить семантические роли; менять LK theme можно независимо от текстов.
Не считать локальный адаптер уже установленным в API. Вынести общий renderer
из work в модуль platform.content, подключить фиксированный allowlist и CSS/JS;
проверить API publish/restore/409 и каждую оболочку отдельно.
Тексты реальных материалов не переписывать, массовый импорт не запускать.
В статье не разрешать авторские scripts/styles/classes или произвольные пути.
Название карточки пока отдельно от материального PUT — см. контракт API.

ARTICLE_STANDARD остаётся владельцем оформления. Одно новое оформление для
blog/course/intensive, особые компоненты через продуктовый adapter, не второй
постоянный канон. Публичные API, Obsidian publish button и авторизацию эта
передача не создаёт. История прежних проверок в demo/README не относится к
новой ревизии; текущие результаты — в demo/VERIFICATION.md.
