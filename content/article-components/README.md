# Повторяемые текстовые блоки

Статус: `current`. Владелец: `platform.content`.

Это каталог общих элементов текста, а не отдельных приложений и не запасных
вариантов оформления. Семантика и шрифты наследуются из
[стандарта статьи](../../docs/knowledge-base/ARTICLE_STANDARD.md).

| Блок | Запись в MD | Общая реализация |
|---|---|---|
| Абзац, заголовок, список, жирное, ссылка, изображение | Обычный Markdown | `typography.css`, безопасный `article_markup.py` |
| Жёлтая плашка, без автоматически придуманного заголовка | `> [!NOTE]`, затем строки `> Текст` | `note.css`, класс `article-note-accent` |
| Обычная цитата без заливки | `> Текст` | `typography.css`, `blockquote` |
| Обычная таблица с горизонтальной прокруткой | Markdown-таблица | `article_markup.py`, текущая оболочка статьи |

NOTE поддерживает абзацы, простые списки, жирное/курсив и ссылки. Вложенные цитаты, таблицы
и код внутри NOTE не поддержаны. Другие Obsidian-callout роли пока не внедрены в
серверный renderer: не выдавать локальный прототип за production-поддержку.

```md
> [!NOTE]
> **Авторский акцент** без нового заголовка.
>
> Второй абзац.

> Отдельная обычная цитата.
```

Старый `:::note` сохраняется для совместимости с прежними публикациями и использует
ту же жёлтую поверхность; новый материал оформляют NOTE. Старое название плашки
не удаляется из авторского текста автоматически.

Текстовые CSS отдаются через `/assets/article-typography.css` и
`/assets/article-note.css`, подключаются курсом централизованно. Текущий цвет
`--article-note-bg: #fff6c9` временный, стиль канонический. Для изменения всего
оформления меняют общий CSS и выпускают код один раз, не перепубликуют статьи.
Само изменение Markdown-паспорта CSS не меняет.

## Отдельные продуктовые компоненты

[Каталог МК](../masterclass/components/README.md): `slider(...)`,
`dqs_score_table(...)`, `spoiler(...)`. Галерея — повторяемый механизм со своим
набором изображений; DQS — специализированные данные/шкалы. Их не дублируют
универсальными Markdown-таблицами и не вставляют произвольным HTML/скриптом.
Универсального блока видео в этом каталоге пока нет: видео курса управляется
полями медиа дня/материала и существующим плеером.
