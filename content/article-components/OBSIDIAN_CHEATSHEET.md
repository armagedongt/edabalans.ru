# Obsidian: что вставлять в материал

Статус: `draft` · владелец: `platform.content`. Сейчас работает в локальном образце,
не автоматически в production. Полные правила — в
[контракте переноса](../../docs/knowledge-base/MARKDOWN_MATERIAL_TRANSFER.md).

| Что нужно | Где/что делать в Obsidian | На сайте после подключения перевода |
|---|---|---|
| Название / раздел | В начале `# Название`; далее `## Раздел` | Название; разделы в штатном содержании |
| Жирный / курсив | Выделить текст, Ctrl+B / Ctrl+I | Обычное выделение |
| Зачеркнуть / подсветить | Выделить; `~~текст~~` / `==текст==` | Тот же цвет текста / подсветка |
| Комментарий | `%%заметка%%` | Не показывается вне блока кода |
| Список | `- Пункт` / `1. Пункт` | Буллеты / номера |
| Галочка / крестик | Список задач `- [x] Да` / `- [ ] Нет`; в Obsidian можно нажать checkbox | Зелёный ✓ / красный ×, не кликаются |
| Цитата | `> Текст` | Боковая линия без фона |
| Жёлтая плашка | Ctrl+P → Insert callout («Вставить выносной блок»); оставить NOTE, тело после `>` | Плашка без заголовка и иконки |
| Спойлер | В том же callout дописать минус: `[!NOTE]- Подробнее` | Белый закрытый спойлер |
| Текст для копирования | Отдельный блок кода — тройные обратные кавычки сверху/снизу | Блок + «Скопировать» внизу |
| Разделитель | `---` отдельной строкой | Лёгкая линия |
| Таблица | Insert table («Вставить таблицу») в меню/палитре, если есть в вашей версии; иначе обычная MD-таблица | Desktop таблица, телефон карточки строк |
| Изображение | `![Описание](прямой HTTPS URL)` | Картинка здесь же, описание как alt |
| Кнопки | Templates: Insert template → «Кнопки слева», «Кнопки в строку», «Кнопки по центру» | Группа ссылок-кнопок |

Названия команд/меню зависят от языка и версии. Надёжный общий путь — Ctrl+P
и поиск команды; таблица не обещает отсутствующую кнопку правого меню.
Команда Insert callout нативная. LINK — наша роль callout, в Obsidian не кнопка сайта.
Основной синтаксис: [официальная справка](https://obsidian.md/help/syntax),
[callout](https://obsidian.md/help/callouts).

## Один раз подключить шаблоны

1. Откройте vault, содержащий эту папку. Не создавайте копию материалов.
2. Настройки → Основные плагины: включите «Шаблоны» (Templates), если выключен.
3. Настройки Templates → папка шаблонов: выберите **путь внутри вашего vault**
   к `content/article-components/obsidian-templates`. Если открыт только content,
   путь будет `article-components/obsidian-templates`, а не полный путь Windows.
4. В материале поставьте курсор; Ctrl+P → Templates: Insert template → нужное имя.
5. Замените подпись и адрес. Ненужную вторую ссылку удалите.

Это встроенный плагин, без community plugin и без настройки публикации.
В этой задаче подготовлены файлы; настройки установленного Obsidian не менялись
и его UI не проверялся. См. [официальные Templates](https://obsidian.md/help/plugins/templates).

```md
> [!LINK] В строку
> [Получить материал](https://example.com/material)
> [Вернуться](/apps/masterclass-course.html)
```

LINK без заголовка — столбец слева; «В строку» — строка на desktop, столбец
на телефоне; «По центру» — столбец по центру. До четырёх ссылок. Цвета/размеры
не задавайте в статье: их настраивает Design один раз в общем компоненте.

Для копирования целого шаблона:

````md
```text
Название категории:
Мои наблюдения:
Что хочу изменить:
```
````

Сноски, Mermaid, формулы, вложенные callout и произвольный HTML/JS не входят
в этот набор. Картинка, вставленная локальным файлом, сначала требует отдельной
загрузки и стабильной ссылки. Содержание не оформляйте спойлером: его собирает
штатная кнопка сайта по `##`. Сохранение MD ничего не публикует.
