# Как редактировать материалы

Откройте файл по ссылке из `Каталог.md`, исправьте текст и сохраните.
Публикуйте выбранные изменения через ярлык. Название файла и служебные метки
не меняйте: они связывают материал с сайтом.

| Что нужно | Как записать |
|---|---|
| Заголовок раздела | `## Название` |
| Подраздел | `### Название` |
| Жирное | `**текст**` |
| Курсив | `*текст*` |
| Зачёркнутое | `~~текст~~` |
| Ссылка | `[текст](https://адрес)` |
| Картинка | `![описание](/существующий-путь.webp)` |
| Список | Каждая строка начинается с `- ` |
| Нумерация | Каждая строка начинается с `1. ` |
| Цитата | Каждая строка начинается с `> ` |

Между абзацами оставляйте пустую строку. Ссылку на существующую картинку
сохраняйте; новую картинку подключает Codex по правилам продукта.

Жёлтая плашка:

```md
> [!NOTE]
> **Важный фрагмент.** Обычный текст и [ссылка](https://example.com).
>
> Ещё один абзац.
```

У плашки нет автоматически добавленного заголовка. Внутри допустимы абзацы,
простые списки, выделения и ссылки. Таблицы, код и вложенные цитаты внутри
плашки пока не поддерживаются. `[!NOTE!]`, `[!WARNING]` и складные плашки
не являются общим синтаксисом сайта.

Обычная таблица:

```md
| Название | Значение |
|---|---|
| Первая строка | Пример |
```

## Особые вставки

Код компонента уже находится на сервере. В файле хранится только его вызов
и данные. Сохраняйте имеющиеся вставки; менять их параметры помогает Codex.
Компоненты разных продуктов не становятся взаимозаменяемыми автоматически.

| Где | Действующие исключения |
|---|---|
| Материалы МК | `slider(...)`, `dqs_score_table(...)`, `spoiler(...)`, `video(...)`, `audio(...)`, `recipe_card(...)`; точные параметры в [каталоге компонентов](../masterclass/components/README.md) |
| Блог | `blog_cta(...)`; ключ должен совпадать с CTA статьи в manifest |
| Рецепты | Полный MD включает скрытые расчётные данные; обычная правка текста сохраняет числа, карточки, изображения и цели ссылок |
| Главная | Один файл по блокам; текст внутри `homepage`-меток. Существующие строчные элементы и `homepage_inline(...)` сохранять |
| Интенсив | Оригинальные `intensive:*`-метки и их порядок сохранять; его особое оформление остаётся |
| Сообщения бота | Тело использует Telegram HTML, например `<b>текст</b>`, а не `**текст**`; переменные сохранять |
| Письма | Оригинальные разделы темы, текста и HTML находятся в кодовых блоках. Переменные `$name` сохранять |
| Старый материал в HTML | Исправляйте текст внутри существующих тегов; расширение `.md` само по себе не переводит его в Markdown |

Названия дней и материалов, порядок, добавление и перемещение меняет Codex
по структурному контракту курса. Полный протокол публикации и конфликтов —
[EDITORIAL_VAULT.md](../../docs/knowledge-base/EDITORIAL_VAULT.md).

Рабочий пример общей разметки — [examples/common.md](examples/common.md).
