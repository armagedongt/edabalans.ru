# Код входа в приложение

Оригинал письма. ${variable} — переменная; её имя сохраняется.

Переменные по разделам (имена сохраняются):

- `subject`: без переменных
- `text`: `${code}`

## subject

```text
Код входа в ЕдаБаланс
```

## text

```text
Код входа в приложение ЕдаБаланс: ${code}

Он действует 10 минут. Если вы не запрашивали код, ничего делать не нужно.
```
