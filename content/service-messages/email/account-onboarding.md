# Темы и вступления писем с доступом

Оригинал письма. ${variable} — переменная; её имя сохраняется.

Переменные по разделам (имена сохраняются):

- `subject_paid`: без переменных
- `subject_free`: без переменных
- `intro_paid`: без переменных
- `intro_free`: без переменных

## subject_paid

```text
Доступ в личный кабинет
```

## subject_free

```text
Регистрация в личном кабинете
```

## intro_paid

```text
Оплата прошла успешно.
```

## intro_free

```text
Регистрация почти готова.
```
