# Внешние редакционные референсы

Статус: `current`
Модуль: `platform.content`

Эта папка хранит краткие, проверяемые карты чужих книг, видео и других
материалов, которые Сергей передал как сырьё для идей. Это отдельный слой от
авторского корпуса edabalans.ru.

## Как пользоваться

1. Сначала прочитать карту нужного источника и её раздел «Границы».
2. Брать из источника функцию приёма: мотивационный ход, способ упростить
   действие, конструкцию задания, наблюдение за привычкой или тип возражения.
3. Не переносить чужие формулировки, композицию целиком, фирменную систему,
   истории и голос автора.
4. Перед готовым текстом подключить обязательный
   `content/author-voice/skill/edabalans-writer/SKILL.md`, авторский корпус Сергея
   и текущие факты нужного продукта.
5. Научные, медицинские, числовые и продуктовые утверждения внешнего источника
   считать только поводом для отдельной актуальной проверки.

Полные чужие тексты и извлечённый из них текст в Git не сохраняются. Карта
содержит только библиографию, provenance, самостоятельный пересказ идей,
границы адаптации и адреса релевантных мест первоисточника.
