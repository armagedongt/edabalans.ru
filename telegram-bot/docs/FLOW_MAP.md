# Исполняемая карта Telegram-бота

## Решение

Карта в админке не является документацией, которую нужно обновлять вручную. Она
собирается API из тех же опубликованных записей PostgreSQL, которые читает
исполнитель бота.

```text
tg_bot_routes
    → системные компоненты
    → tg_sequences / tg_sequence_versions
    → tg_sequence_steps
    → tg_sequence_edges
```

## Два уровня

### Вся система

Показывает точки входа, обработку идентификации и источника, крупные цепочки,
переходы после покупки и отдельные механики. Цепочка на этом уровне является
одним свёрнутым блоком.

### Одна цепочка

Показывает каждый блок и фактические переходы: `default`, `true`, `false` либо
переход в другую цепочку. Узел содержит ссылку на таблицу и программный
обработчик, который его исполняет.

## Источник истины

- `tg_bot_routes` задаёт событие входа и стартовую цепочку.
- `tg_sequence_versions` отделяет редактируемый черновик от опубликованной
  неизменяемой версии.
- `tg_sequence_steps` хранит действия.
- `tg_sequence_edges` хранит весь порядок и ветвления.
- `service/app/graph.py::SYSTEM_COMPONENTS` регистрирует низкоуровневые операции
  и их расположение в коде. Он не содержит пользовательских маршрутов.

Новый маршрут нельзя реализовать скрытым `if` только в Python. Событие должно
быть зарегистрировано в `tg_bot_routes`, а переход — в `tg_sequence_edges`.

## Автоматическая проверка

API карты сообщает об ошибке, если:

- активная цепочка пуста;
- блок невозможно достигнуть от начала;
- у обычного блока нет продолжения;
- у условия отсутствует ветка «да» или «нет»;
- связь ведёт в отсутствующий блок или цепочку;
- сообщению не назначен контент;
- задержке не назначено время;
- найден цикл без явного `condition.allow_cycle=true`.

Следующий этап перед визуальным редактированием — отдельная команда публикации,
которая запрещает публикацию версии при наличии ошибок. Существующие настройки
контента и задержек остаются в обычном редакторе цепочки.

## Интерфейс

Раздел «Карта бота» загружается через `GET /bot-api/map`. Параметр
`sequence_code` открывает подробную схему. Схема масштабируется колёсиком,
перемещается мышью, раскрывает карточку блока и автоматически перестраивается
после изменения данных.
