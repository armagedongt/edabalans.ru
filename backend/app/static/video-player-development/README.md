# Модульный видеоплеер

Папка содержит две готовые автономные версии HTML-плеера для вставки на страницу.
Каждый HTML-файл включает разметку, стили и JavaScript и не требует отдельных CSS/JS-файлов.

Это два поддерживаемых продуктовых контракта, а не набор произвольно смешиваемых
режимов: `engagement` используется снаружи Мастер-класса, `standard` — внутри.
Третью комбинацию из их функций не создавать без отдельного решения владельца.

## Файлы

- `player-autoplay-analytics-fast-progress.html` — внешний продающий плеер: автозапуск без звука, сбор статистики, ускоренная визуальная шкала, оглавление только с названиями и без перемотки.
- `player-standard-with-contents.html` — запуск вручную, обычная шкала прогресса, оглавление, без сбора статистики.

## Как применяется в Мастер-классе

Внутри Мастер-класса не нужно копировать этот HTML в Tilda. Единый runtime
открывает его по адресу `/apps/video-player.html` только для прямой ссылки на
MP4. В редакторе дня есть два поля:

- **ссылка на видео** — короткий ID Boomstream, ссылка на страницу Boomstream или
  прямая HTTPS-ссылка на MP4;
- **ссылка на картинку / обложку** — показывается как обложка у прямого MP4, а
  при пустом видео становится самостоятельным медиа дня.
- **содержание / таймкоды** — одна строка на раздел в виде
  `00:00 — название раздела`.

Если заполнено видео, оно имеет приоритет. Пустые оба поля не показывают блок
медиа. Технический переключатель `media` редактор обновляет сам: вручную выбирать
тип медиа не нужно.

Boomstream ID или ссылка на страницу просмотра остаются в его iframe. Прямая
ссылка на файл, в том числе `cdnv.boomstream.com/...mp4`, открывается в этом
плеере. Не превращайте Google Drive-ссылку на просмотр в ссылку для плеера:
сначала загрузите финальный файл в Boomstream или объектное хранилище.

Для прямого MP4 содержание становится меню плеера с переходом по главам. Для
Boomstream те же таймкоды остаются честным раскрывающимся списком под видео:
перемотку внутри чужого iframe браузер безопасно не контролирует.

## Автономная вставка вне Мастер-класса

1. Открыть нужный HTML-файл.
2. Скопировать его содержимое целиком.
3. Вставить код в HTML-блок страницы, например Tilda T123.
4. Заменить ссылку в атрибуте `src` у тега `<video>` на прямую ссылку на MP4-файл.
5. Настроить оглавление, качество и аналитику по разделам ниже.

На одной странице по умолчанию должен использоваться один экземпляр этого кода, потому что корневой элемент имеет ID `modular-video-player`.

## Ссылка на видео

В автономной заготовке ссылка задаётся в теге:

```html
<video class="mvp__video" src="ПРЯМАЯ_ССЫЛКА_НА_MP4" playsinline preload="metadata"></video>
```

Нужна именно прямая ссылка на видеофайл, а не ссылка на страницу просмотра.

В runtime Мастер-класса ссылка передаётся параметром `src`; не вписывайте видео
в сам файл плеера.

## Два режима

Режим определяется одной строкой:

```js
const PLAYER_MODE = 'engagement';
```

Допустимые значения:

- `engagement` — внешний плеер: автозапуск без звука, аналитика, ускоренная шкала, отображается только текущее время, перемотка по шкале и главам запрещена;
- `standard` — ручной запуск, без аналитики, обычная шкала, отображаются текущее и общее время.

Оглавление включается независимо:

```js
const CONTENTS_ENABLED = true;
```

- `true` — показать оглавление;
- `false` — скрыть оглавление.

В двух готовых файлах нужные комбинации уже выставлены.

## Ускоренная шкала прогресса

Параметр действует только в режиме `engagement`:

```js
const PROGRESS_CONFIG = {
  checkpoints: [
    { real:0, shown:0 },
    { real:0.01, shown:0.10 },
    { real:0.05, shown:0.25 },
    { real:0.25, shown:0.50 },
    { real:0.60, shown:0.90 },
    { real:0.70, shown:0.96 },
    { real:1, shown:1 }
  ]
};
```

- на 1% реального просмотра шкала показывает 10%;
- на 5% — 25%;
- на 25% — 50%;
- на 60% — 90%, то есть соотношение около 1,5×;
- после 70% шкала плавно сходится с реальным окончанием и не достигает 100% раньше видео.

Ускоряется только отображение заполнения шкалы. Реальная скорость и длительность видео не меняются.

## Оглавление

Разделы задаются массивом:

```js
const chapters = [
  { at: 0, title: 'Введение' },
  { at: 42, title: 'Главная мысль' },
  { at: 118, title: 'Практический пример' }
];
```

- `at` — начало раздела в секундах;
- `title` — название раздела.

Активный раздел определяется автоматически по текущей позиции видео.

## Скорость воспроизведения

Сейчас доступны:

- x 1;
- x 1.25;
- x 1.5;
- x 1.75;
- x 2.

Список находится в массиве `speedOptions`. Значения в нём можно изменить, но обе части `v` и `l` должны соответствовать друг другу.

## Качество видео

Для переключения качества нужны отдельные прямые ссылки на физические файлы каждого разрешения:

```js
const QUALITY_OPTIONS = [
  { id:'original', label:'Исходное', url:null },
  { id:'1080', label:'1080p', url:'https://site.ru/video-1080.mp4' },
  { id:'720', label:'720p', url:'https://site.ru/video-720.mp4' }
];
```

Строки без `url` не показываются. `original` использует ссылку из тега `<video>`.

Кнопка общих настроек сейчас скрыта по утверждённому дизайну, поэтому выбор качества не выводится в интерфейс. Механизм переключения сохранён в коде для будущего возвращения кнопки.

## Аналитика

В режиме `engagement` просмотр сохраняется локально в `localStorage` и создаёт событие `mvp:analytics` на корневом элементе плеера.
Тихий автозапуск служит только превью: просмотренные интервалы, позиция и
завершение начинают считаться после первого осознанного нажатия пользователя.

Для отправки данных на сервер нужно указать endpoint:

```js
const ANALYTICS_CONFIG = {
  endpoint: 'https://api.example.ru/video-analytics',
  videoId: 'main-video-001',
  bucketSizeSec: 5,
  completionThreshold: 0.95,
  heartbeatSec: 15
};
```

Если `endpoint` пустой, сетевые запросы не отправляются. Для каждого отдельного видео нужно задавать свой стабильный `videoId`.

События:

- `video_engaged` — пользователь начал осознанное взаимодействие;
- `video_progress` — периодический прогресс;
- `video_complete` — достигнут порог завершения;
- `video_exit` — уход со страницы.

## Плашка включения звука

При автозапуске браузер запускает видео без звука. По нажатию на плашку:

- видео возвращается в начало;
- включается звук;
- воспроизведение продолжается;
- плашка скрывается.

Текст плашки находится в `.mvp__sound-text`, внешний вид — в CSS-блоках
`.mvp__sound-card`, `.mvp__sound-icon` и анимации `mvp-sound-arc`.

Иконка не использует системный emoji: динамик и две расходящиеся дуги нарисованы
inline-SVG. Корпус динамика неподвижен, дуги по очереди появляются, расширяются и
исчезают через `mvp-sound-arc`. При `prefers-reduced-motion` движение отключается.

## Цвета

Главный акцентный цвет задаётся переменными в начале CSS:

```css
--accent:#20aaf5;
--accent-soft:rgba(32,170,245,.84);
```

`--accent` управляет шкалой, активными состояниями и расходящимися волнами
плашки звука. Плашка `Содержание` использует полупрозрачный голубой фон того же
цветового семейства; отдельный фиолетовый акцент не применяется.

## Проверка после изменения

После каждого изменения нужно проверить:

1. запуск и паузу;
2. включение звука после автозапуска;
3. для внешнего плеера — отсутствие перемотки по шкале; для внутреннего — обычную перемотку;
4. все пять скоростей;
5. открытие и закрытие оглавления;
6. для внешнего плеера — информационные названия без перехода; для внутреннего — переходы по разделам;
7. активную подсветку текущего названия; цифровые таймкоды показываются только во внутреннем плеере;
8. полноэкранный режим;
9. отображение на компьютере и телефоне;
10. отсутствие ошибок JavaScript в консоли браузера.
