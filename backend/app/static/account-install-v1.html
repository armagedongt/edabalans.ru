Как установить личный кабинет

Один значок открывает весь личный кабинет: курсы, дневники и калькуляторы, к которым у вас есть доступ. Установите его один раз на каждом устройстве, которым пользуетесь.

  • На компьютере
  • На Android
  • На iPhone

На компьютере

  1. Откройте личный кабинет в Google Chrome.
  2. Нажмите значок установки справа в адресной строке. Если его нет, откройте меню ⋮ → «Транслировать, сохранить, поделиться» → «Установить страницу как приложение».
  3. Подтвердите установку. Кабинет откроется в отдельном окне.
  4. Чтобы вынести значок на рабочий стол, откройте в Chrome chrome://apps, нажмите правой кнопкой мыши на значок кабинета и выберите «Создать ярлык».

На Android

  1. Откройте личный кабинет в Google Chrome.
  2. Нажмите ⋮ рядом с адресной строкой. Выберите «Установить и создать ярлык».
  3. Нажмите «Установить». Затем откройте кабинет по значку на главном экране или в списке приложений.

На iPhone

  1. Откройте личный кабинет в Safari.
  2. Нажмите «Поделиться» (квадрат со стрелкой вверх). Если кнопка скрыта, откройте меню страницы.
  3. В списке действий выберите «На экран „Домой“». Если такого пункта нет, найдите его через «Редактировать действия» внизу списка.
  4. Оставьте включённым «Открывать как веб-приложение», если есть такой переключатель, и нажмите «Добавить».
  5. Откройте кабинет по новому значку на экране «Домой».

После установки

Откройте кабинет по значку. Если появится форма входа, войдите в свой аккаунт. Дальше открывайте нужный курс или приложение из кабинета. Для работы нужен интернет.
