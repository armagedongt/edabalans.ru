# Legacy Google: материалы для миграции

Эта папка — безопасный справочный снимок существующих приложений на Google Sheets,
Google Apps Script и Tilda T123. Она нужна для переноса поведения на PostgreSQL/FastAPI
по фактическому коду и структуре таблиц.

## Приоритет источников

При конфликте использовать источники в таком порядке:

1. `PROJECT_CONTEXT.md`, `ARCHITECTURE.md` и фактически работающий код репозитория;
2. кодовые снимки в этой папке и безопасные схемы Google Sheets;
3. продуктовые и UX-требования;
4. исторические планы и накопительные списки.

## Что здесь находится

- `dqs/PRODUCT_CATEGORIES.md` — канонические правила категорий DQS;
- `dqs/CONTEXT.md` — полный контекст DQS на 16.08.2026;
- `dqs/apps-script/Code.gs` — legacy backend DQS;
- `dqs/tilda/client-t123.html` — legacy клиент DQS;
- `dqs/tilda/admin-t123.html` — legacy админка DQS;
- `dqs/PENDING_CLIENT_CHANGES.md` — изменения, которые на момент источника не были
  внесены в production;
- `dqs/SUPERSEDED_INTEGRATIONS_PLAN.md` — устаревший план, где Google Sheets и Apps
  Script должны были стать постоянным реестром покупок;
- `strength/DATA_MODEL_AND_RULES.md` — правила и модель силовых тренировок;
- `strength/apps-script/Code.gs` — legacy backend силовых;
- `sheets/*.md` — только структура вкладок и заголовков, без пользовательских строк;
- `SOURCES.md` — реестр исходных Google-файлов и решение по каждому из них.

## Правила безопасности

- Здесь нет строк пользователей, покупок, email клиентов, Telegram ID или дампов.
- Реальный email администратора заменён на `admin@example.invalid`.
- URL развернутого Apps Script заменены на `<REDACTED_LEGACY_APPS_SCRIPT_URL>`.
- Идентификаторы самих Google Docs/Sheets сохранены как ссылки на источники; это не
  экспорт данных и не ключи доступа.
- Перед реальным импортом данных снова проверить backup и восстановление.

## Как использовать при переносе

Сначала прочитать релевантный файл требований, затем кодовый снимок и схему листов.
Переносить endpoint за endpoint и функцию за функцией, фиксируя расхождения тестами.
Не переключать production Tilda hooks и не удалять Google-данные без отдельного
подтверждения владельца.
