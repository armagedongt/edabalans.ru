# Калькулятор метаболизма: требования к переносу

Статус: актуальные требования владельца на 22.08.2026.

## Фактический исходник

`tilda/client-t123.html` — самостоятельное браузерное приложение. Оно рассчитывает
два сравниваемых варианта и сейчас сохраняет их только в `localStorage` по ключу
`metabolism_calc_v3`. Внешнего API и Apps Script в исходнике нет.

## Требуемая серверная версия

- Пользователь определяется по email текущей сессии Tilda на переходном этапе.
- Backend сопоставляет нормализованный email с общим `users.id`.
- Оба варианта расчёта автоматически сохраняются после изменения полей.
- При следующем открытии значения загружаются из PostgreSQL, в том числе на другом
  устройстве или в другом браузере.
- `localStorage` остаётся только временным offline-кэшем и не является источником истины.
- Сохраняются входные значения, версия формул, вычисленные результаты и `updated_at`.
- Повторное сохранение обновляет текущее состояние идемпотентно; история каждого
  нажатия по умолчанию не создаётся.
- В защищённой админке доступен просмотр текущих сохранённых вариантов пользователя.
- Формулы переносятся из фактического T123-кода и покрываются эталонными тестами.

## Предлагаемый API

```text
GET  /metabolism/state
PUT  /metabolism/state
GET  /admin/api/metabolism/users/{user_id}
```

Точный контракт и способ подтверждения Tilda-пользователя фиксируются до production
cutover. Один произвольно переданный email не должен давать доступ к чужому расчёту.
